Web Development Tutorial

ವೆಬ್ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಡೇಟಾ ಸೇವ್ ಮಾಡುವುದು:
localStorage ಮತ್ತು sessionStorage

ಬ್ರೌಸರ್‌ನಲ್ಲಿ (Chrome, Safari, Edge) ಬಳಕೆದಾರರ ಡೇಟಾವನ್ನು ಸೇವ್ ಮಾಡುವ ಎರಡು ಪ್ರಮುಖ "ವರ್ಚುವಲ್ ಸ್ಟೋರೇಜ್" (Virtual Storage) ಗಳೇ localStorage ಮತ್ತು sessionStorage.

1

Beginner Level (ನಾನ್-ಐಟಿ ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ)

ಇದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ನಾವು ದಿನನಿತ್ಯ ಬಳಸುವ ಎರಡು ವಸ್ತುಗಳನ್ನು ಉದಾಹರಣೆಯಾಗಿ ತೆಗೆದುಕೊಳ್ಳೋಣ: ಒಂದು ಡೈರಿ (Diary) ಮತ್ತು ಒಂದು ಶಾಲೆಯ ಬ್ಲಾಕ್‌ಬೋರ್ಡ್ (Blackboard).

localStorage (ಡೈರಿಯಂತೆ)

ನೀವು ಡೈರಿಯಲ್ಲಿ ಏನನ್ನಾದರೂ ಬರೆದರೆ, ಅದು ಅಲ್ಲಿಯೇ ಇರುತ್ತದೆ. ನೀವು ಪುಸ್ತಕವನ್ನು ಮುಚ್ಚಿ, ಒಂದು ತಿಂಗಳ ನಂತರ ಬಂದು ನೋಡಿದರೂ ಆ ಬರಹ ಅಲ್ಲಿಯೇ ಇರುತ್ತದೆ.

ಉದಾಹರಣೆ: ನೀವು ಅಮೆಜಾನ್ (Amazon) ನಲ್ಲಿ ಡಾರ್ಕ್ ಮೋಡ್ (Dark Mode) ಆನ್ ಮಾಡಿದ್ದೀರಿ. ಲ್ಯಾಪ್‌ಟಾಪ್ ಆಫ್ ಮಾಡಿ, ನಾಳೆ ಮತ್ತೆ ಅಮೆಜಾನ್ ಓಪನ್ ಮಾಡಿದರೂ ಅದು ಡಾರ್ಕ್ ಮೋಡ್ ನಲ್ಲೇ ಇರುತ್ತದೆ. ಏಕೆಂದರೆ ಆ ಮಾಹಿತಿಯನ್ನು ಬ್ರೌಸರ್ localStorage ನಲ್ಲಿ ಬರೆದಿಟ್ಟುಕೊಂಡಿರುತ್ತದೆ.

sessionStorage (ಬ್ಲಾಕ್‌ಬೋರ್ಡ್‌ ನಂತೆ)

ಶಿಕ್ಷಕರು ಬ್ಲಾಕ್‌ಬೋರ್ಡ್‌ ಮೇಲೆ ಬರೆಯುತ್ತಾರೆ. ಕ್ಲಾಸ್ ಮುಗಿದ ತಕ್ಷಣ (ಟ್ಯಾಬ್ ಕ್ಲೋಸ್ ಮಾಡಿದ ತಕ್ಷಣ) ಅದನ್ನು ಅಳಿಸಿಬಿಡುತ್ತಾರೆ.

ಉದಾಹರಣೆ: ನೀವು ಯಾವುದೋ ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ ಫಾರ್ಮ್ ತುಂಬುತ್ತಿದ್ದೀರಿ, ಅರ್ಧ ತುಂಬಿದ್ದಾಗ ರಿಫ್ರೆಶ್ (Refresh) ಮಾಡಿದರೂ ಡೇಟಾ ಹಾಗೇ ಇರುತ್ತದೆ. ಆದರೆ ನೀವು ಆ ಟ್ಯಾಬ್ (Tab) ಅನ್ನೇ ಕ್ಲೋಸ್ ಮಾಡಿದರೆ ಡೇಟಾ ಸಂಪೂರ್ಣ ಡಿಲೀಟ್ ಆಗುತ್ತದೆ.

2

Intermediate Level (ಡೆವಲಪರ್ ಬೇಸಿಕ್ಸ್)

ನೀವು ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಕಲಿಯುತ್ತಿದ್ದರೆ, ಇವೆರಡನ್ನು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ (JavaScript)ಮೂಲಕ ಹೇಗೆ ಕಂಟ್ರೋಲ್ ಮಾಡುವುದು ಎಂದು ತಿಳಿಯಬೇಕು. ಇವೆರಡೂ ಒಂದೇ ರೀತಿಯ ಕಮಾಂಡ್‌ಗಳನ್ನು (Methods) ಬಳಸುತ್ತವೆ.

ಡೇಟಾವನ್ನು ಎಲ್ಲಿ ನೋಡಬಹುದು?

ಬ್ರೌಸರ್‌ನಲ್ಲಿ: Right Click -> Inspect -> Application (ಅಥವಾ Storage) ಟ್ಯಾಬ್‌ಗೆ ಹೋದರೆ Local Storage ಮತ್ತು Session Storage ಕಾಣಿಸುತ್ತದೆ.

ಬಳಸುವ ಪ್ರಮುಖ ಕಮಾಂಡ್‌ಗಳು:

ಇವು ಕೇವಲ "Label" (Key) ಮತ್ತು "Value" ಆಧಾರದ ಮೇಲೆ ಕೆಲಸ ಮಾಡುತ್ತವೆ.

script.js 

// 1. ಡೇಟಾ ಸೇವ್ ಮಾಡಲು (Set)
localStorage.setItem("username", "Ravi");
sessionStorage.setItem("theme", "dark");

// 2. ಡೇಟಾ ಓದಲು (Get)
let name = localStorage.getItem("username");
// "Ravi" ಎಂದು ಬರುತ್ತದೆ

// 3. ಒಂದು ನಿರ್ದಿಷ್ಟ ಡೇಟಾ ಅಳಿಸಲು (Remove)
localStorage.removeItem("username");

// 4. ಇಡೀ ಸ್ಟೋರೇಜ್ ಖಾಲಿ ಮಾಡಲು (Clear)
localStorage.clear();

ನೆನಪಿಡಿ: ಸ್ಟೋರೇಜ್ ಕೇವಲ 'ಪಠ್ಯವನ್ನು' (Strings) ಮಾತ್ರ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ. Array ಅಥವಾ Object ಹಾಕಬೇಕಾದರೆ JSON.stringify() ಮತ್ತು ಓದುವಾಗ JSON.parse() ಬಳಸಲೇಬೇಕು.

3

Pro Level (ಅಡ್ವಾನ್ಸ್ಡ್ ಕಾನ್ಸೆಪ್ಟ್ಸ್)

ಒಬ್ಬ ಪ್ರೊಫೆಷನಲ್ ಡೆವಲಪರ್ ಆಗಿ ನೀವು ಕೇವಲ ಡೇಟಾ ಸೇವ್ ಮಾಡುವುದಷ್ಟೇ ಅಲ್ಲ, ಅದರ ಹಿಂದಿರುವ ಅಪಾಯಗಳು ಮತ್ತು ಮಿತಿಗಳನ್ನು ತಿಳಿದಿರಬೇಕು.

ಸೆಕ್ಯುರಿಟಿ ರಿಸ್ಕ್ (Security & XSS)

localStorage ಮತ್ತು sessionStorage ಗಳಿಗೆ ಯಾವುದೇ ಭದ್ರತೆ ಇರುವುದಿಲ್ಲ. ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಮೂಲಕ ಯಾರು ಬೇಕಾದರೂ ಇದನ್ನು ಓದಬಹುದು.

Pro Rule: ಪಾಸ್‌ವರ್ಡ್‌ಗಳು, ಕ್ರೆಡಿಟ್ ಕಾರ್ಡ್ ವಿವರಗಳು ಅಥವಾ ಸೂಕ್ಷ್ಮವಾದ API Token ಗಳನ್ನು (JWT) ಎಂದಿಗೂ ಇದರಲ್ಲಿ ಸೇವ್ ಮಾಡಬಾರದು. ಹ್ಯಾಕರ್‌ಗಳು XSS ಅಟ್ಯಾಕ್ ಮೂಲಕ ಇದನ್ನು ಸುಲಭವಾಗಿ ಕದಿಯಬಹುದು. ಇಂತಹ ಡೇಟಾಗೆ HttpOnly Cookies ಬಳಸಬೇಕು.

ಸ್ಟೋರೇಜ್ ಮಿತಿ (Storage Capacity)

ಕುಕೀಸ್ (Cookies)ಗಳಲ್ಲಿ ಕೇವಲ 4KB ಡೇಟಾ ಸೇವ್ ಮಾಡಬಹುದು. ಆದರೆ localStorage ಮತ್ತು sessionStorage ಗಳಲ್ಲಿ ಸುಮಾರು 5MB ಯಿಂದ 10MB ವರೆಗೆ ಡೇಟಾ ಸೇವ್ ಮಾಡಬಹುದು.

ಸಿಂಕ್ರೊನಸ್ ಬ್ಲಾಕಿಂಗ್ (Synchronous Nature)

ಈ ಎರಡೂ ಸ್ಟೋರೇಜ್‌ಗಳು Synchronous ಆಗಿ ಕೆಲಸ ಮಾಡುತ್ತವೆ. ಅಂದರೆ, ನೀವು ಇದರಲ್ಲಿ ಅತಿ ದೊಡ್ಡ ಡೇಟಾವನ್ನು ಸೇವ್ ಮಾಡುತ್ತಿದ್ದರೆ, ಅದು ಮುಗಿಯುವವರೆಗೆ ವೆಬ್‌ಸೈಟ್‌ನ ಇತರ ಕೆಲಸಗಳು (UI) ಫ್ರೀಜ್ (Freeze/Block)ಆಗುತ್ತವೆ.

ಸ್ಟೋರೇಜ್ ಈವೆಂಟ್

localStorage ನ ಒಂದು ಅದ್ಭುತ ಫೀಚರ್ ಎಂದರೆ, ನೀವು ಒಂದೇ ವೆಬ್‌ಸೈಟ್‌ನ 3-4 ಟ್ಯಾಬ್‌ಗಳನ್ನು ಓಪನ್ ಮಾಡಿದ್ದರೆ. ಒಂದು ಟ್ಯಾಬ್‌ನಲ್ಲಿ ಡೇಟಾ ಬದಲಾದರೆ, ಉಳಿದ ಟ್ಯಾಬ್‌ಗಳಿಗೆ ಕೂಡಲೇ ಮಾಹಿತಿ ಕಳುಹಿಸಬಹುದು.

Cross-tab communication 

window.addEventListener('storage', function(e) {
  console.log("ಬೇರೆ ಟ್ಯಾಬ್ ನಲ್ಲಿ ಡೇಟಾ ಬದಲಾಗಿದೆ!");
  console.log("ಹಳೆಯ ಡೇಟಾ: " + e.oldValue + ", ಹೊಸ ಡೇಟಾ: " + e.newValue);
});

Array ಮತ್ತು Object ಗಳನ್ನು ನಿರ್ವಹಿಸುವುದು

ಮೊದಲನೇ ಪ್ರಮುಖ ನಿಯಮ (Beginner Concept):

ಈ ಎರಡೂ ಸ್ಟೋರೇಜ್‌ಗಳು ಕೇವಲ 'ಪಠ್ಯ' (Text/String) ಗಳನ್ನು ಮಾತ್ರ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುತ್ತವೆ. ಆದರೆ ನಾವು ಪ್ರೋಗ್ರಾಮಿಂಗ್‌ನಲ್ಲಿ ಬಳಸುವ Array (ಪಟ್ಟಿ) ಮತ್ತು Object (ವಿವರಗಳ ಗುಚ್ಛ) ಗಳು ಪಠ್ಯವಲ್ಲ. ಆದ್ದರಿಂದ, ಇವುಗಳನ್ನು ಸ್ಟೋರೇಜ್‌ಗೆ ಹಾಕುವ ಮುನ್ನ ಪಠ್ಯವಾಗಿ ಬದಲಾಯಿಸಬೇಕು (JSON.stringify()), ಮತ್ತು ವಾಪಸ್ ಪಡೆಯುವಾಗ ಮೂಲ ರೂಪಕ್ಕೆ ತರಬೇಕು (JSON.parse()).

1. Array (ಪಟ್ಟಿ) ಗಳಲ್ಲಿ ಡೇಟಾ ಸೇರಿಸುವುದು

Array ಎಂದರೆ ಒಂದು ಶಾಪಿಂಗ್ ಲಿಸ್ಟ್ ಇದ್ದ ಹಾಗೆ.


// ಹಂತ 1: ಹೊಸ Array ಸೇವ್ ಮಾಡುವುದು
let fruits = ["Apple", "Banana"];
localStorage.setItem("myFruits", JSON.stringify(fruits));

// ಹಂತ 2: Array ಗೆ ಹೊಸ Value ಹಾಕುವುದು (Add)
let storedFruits = JSON.parse(localStorage.getItem("myFruits"));
storedFruits.push("Mango"); 
localStorage.setItem("myFruits", JSON.stringify(storedFruits));

// ಹಂತ 3: Array ನಿಂದ Value ತೆಗೆಯುವುದು (Remove)
let currentFruits = JSON.parse(localStorage.getItem("myFruits"));
currentFruits = currentFruits.filter(fruit => fruit !== "Banana");
localStorage.setItem("myFruits", JSON.stringify(currentFruits));

2. Object ಗಳಲ್ಲಿ ಡೇಟಾ ಸೇರಿಸುವುದು

Object ಎಂದರೆ ಒಂದು ಐಡಿ ಕಾರ್ಡ್ (ID Card) ಇದ್ದ ಹಾಗೆ.


// ಹಂತ 1: ಹೊಸ Object ಸೇವ್ ಮಾಡುವುದು
let user = { name: "Ravi", age: 25 };
sessionStorage.setItem("userData", JSON.stringify(user));

// ಹಂತ 2: Object ಗೆ ಹೊಸ Value ಹಾಕುವುದು (Add)
let storedUser = JSON.parse(sessionStorage.getItem("userData"));
storedUser.city = "Bengaluru";
sessionStorage.setItem("userData", JSON.stringify(storedUser));

// ಹಂತ 3: Object ನಿಂದ Value ತೆಗೆಯುವುದು (Remove)
let currentUser = JSON.parse(sessionStorage.getItem("userData"));
delete currentUser.age;
sessionStorage.setItem("userData", JSON.stringify(currentUser));

ಸಾರಾಂಶ (Pro Tip): ನೀವು Array ಅಥವಾ Object ಅನ್ನು ಸ್ಟೋರೇಜ್‌ನಲ್ಲಿ ಅಪ್ಡೇಟ್ ಮಾಡಬೇಕಾದರೆ:
ಹೊರಗೆ ತೆಗೆಯಿರಿ (parse) → ಬದಲಾಯಿಸಿ (push/delete) → ಮತ್ತೆ ಒಳಗೆ ಇಡಿ (stringify).
ಇದುವೇ ಇದರ ಸರಳ ಸೂತ್ರ!

JSON.stringify() ಮತ್ತು JSON.parse() (Translators)

ಊಹಿಸಿಕೊಳ್ಳಿ, ನಿಮ್ಮ ಬಳಿ ಜೋಡಿಸಿದ ಒಂದು ಸುಂದರವಾದ ಲೀಗೊ (LEGO) ಬೊಂಬೆ ಇದೆ. ಇದನ್ನು ಕೊರಿಯರ್ ಮೂಲಕ ಕಳುಹಿಸಲು ಕೇವಲ ಒಂದು ಕಾಗದವನ್ನು ಮಾತ್ರ ಕಳುಹಿಸಬಹುದು.

1. JSON.stringify() - (ಪ್ಯಾಕ್ ಮಾಡುವುದು)

ಲೀಗೊ ಬೊಂಬೆಯನ್ನು ಬಿಚ್ಚಿ, ಅದನ್ನು ಹೇಗೆ ಜೋಡಿಸಬೇಕು ಎಂಬ ವಿವರಗಳನ್ನು ಒಂದು ಕಾಗದದ ಮೇಲೆ ಬರೆಯುತ್ತೀರಿ.


let myCar = { brand: "Tata", color: "Red" }; // ಅಸಲಿ Object (ಲೀಗೊ ಬೊಂಬೆ)
let stringData = JSON.stringify(myCar); 
// ಈಗ stringData ಕೇವಲ ಒಂದು ಪಠ್ಯ: 
// '{"brand":"Tata","color":"Red"}'

2. JSON.parse() - (ಅನ್-ಪ್ಯಾಕ್ ಮಾಡುವುದು)

ನಿಮ್ಮ ಸ್ನೇಹಿತನಿಗೆ ಆ ಕಾಗದ ತಲುಪುತ್ತದೆ. ಆತ ಆ ಕಾಗದದಲ್ಲಿರುವ ಮಾಹಿತಿಯನ್ನು ಓದಿ, ಮತ್ತೆ ಅದೇ ಲೀಗೊ ಬೊಂಬೆಯನ್ನು ಹಿಂದಿದ್ದಂತೆಯೇ ಜೋಡಿಸುತ್ತಾನೆ.


let receivedText = '{"brand":"Tata","color":"Red"}';
let originalCar = JSON.parse(receivedText);
// originalCar.color = "Blue" ಎಂದು ಬದಲಾಯಿಸಬಹುದು!

ಸಾರಾಂಶ:

stringify: Object/Array ಅನ್ನು ಪಠ್ಯವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.
parse: ಪಠ್ಯವನ್ನು ಮತ್ತೆ ಅಸಲಿ Object/Array ಆಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.
