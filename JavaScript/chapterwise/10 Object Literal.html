{ }

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ (JavaScript) ನಲ್ಲಿ Objects

ಸಂಪೂರ್ಣ ಮಾರ್ಗದರ್ಶಿ (Beginner to Pro)

ಪೀಠಿಕೆ: Object ಎಂದರೇನು?

Object ಎಂದರೆ ಒಂದು ವಸ್ತುವಿನ ಗುಣಲಕ್ಷಣಗಳನ್ನು (Properties) ಮತ್ತು ಅದರ ಕಾರ್ಯಗಳನ್ನು (Methods) ಒಂದೇ ಕಡೆ ಸಂಗ್ರಹಿಸುವ ವ್ಯವಸ್ಥೆ.

Array ಗೂ Object ಗೂ ಏನು ವ್ಯತ್ಯಾಸ?
Array ಗಳಲ್ಲಿ ಡೇಟಾವನ್ನು ನಂಬರ್ (Index 0, 1, 2...) ಮೂಲಕ ಹುಡುಕುತ್ತೇವೆ. ಆದರೆ Object ನಲ್ಲಿ ಡೇಟಾವನ್ನು Key-Value pairs (ಹೆಸರು ಮತ್ತು ಅದರ ಬೆಲೆ) ಮೂಲಕ ಸಂಗ್ರಹಿಸುತ್ತೇವೆ. ಇದು ಡೇಟಾವನ್ನು ಹುಡುಕಲು ಮತ್ತು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ತುಂಬಾ ಸುಲಭವಾಗಿಸುತ್ತದೆ.

Object Literal ರಚನೆ (ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ವಿಧಾನ)

ಬ್ರಾಕೆಟ್ {} (Curly braces) ಅನ್ನು ಬಳಸಿ Object ರಚಿಸುವುದು ಅತ್ಯಂತ ಸುಲಭ ಮತ್ತು ಅತಿ ಹೆಚ್ಚು ಬಳಸುವ ವಿಧಾನವಾಗಿದೆ.

JS
let person = {
    firstName: "Ravi",  // firstName ಎಂಬುದು Key, "Ravi" ಎಂಬುದು Value
    lastName: "Kumar",
    age: 25,
    isStudent: true
};

(ಇಲ್ಲಿ ಎಡಭಾಗದಲ್ಲಿರುವುದು Key, ಬಲಭಾಗದಲ್ಲಿರುವುದು Value. ಪ್ರತಿಯೊಂದು ಲೈನ್ ನಂತರ ಕಾಮ (,) ಹಾಕಬೇಕು).

1. Beginner Level (ಮೂಲ ಹಂತ)

ಈ ಹಂತದಲ್ಲಿ Object ನ ಒಳಗಿರುವ ಡೇಟಾವನ್ನು ಪಡೆಯುವುದು, ಹೊಸ ಡೇಟಾ ಸೇರಿಸುವುದು ಮತ್ತು ಅಳಿಸುವುದನ್ನು ಕಲಿಯೋಣ.

Accessing Properties
ಡೇಟಾವನ್ನು ಪಡೆಯುವುದು (2 ವಿಧಾನಗಳು):
JS
// 1. Dot Notation (.) - (ಅತಿ ಹೆಚ್ಚು ಬಳಕೆ)
console.log(person.firstName); 
// ಫಲಿತಾಂಶ: "Ravi"

// 2. Bracket Notation ([]) - (ವಿಶೇಷ ಸಂದರ್ಭ)
// Key ಹೆಸರಿನಲ್ಲಿ space ಇದ್ದರೆ/variable ಬಳಸುವಾಗ
console.log(person["age"]); 
// ಫಲಿತಾಂಶ: 25
Add / Update
ಹೊಸ ಡೇಟಾ ಸೇರಿಸುವುದು / ಬದಲಾಯಿಸುವುದು:
JS
person.age = 26; // ಇರುವ age ಬದಲಾಯಿತು
person.city = "Bengaluru"; // ಹೊಸ city ಸೇರ್ಪಡೆಯಾಯಿತು

console.log(person); 
// {firstName: "Ravi", lastName: "Kumar", age: 26, isStudent: true, city: "Bengaluru"}
delete keyword
ಡೇಟಾವನ್ನು ಅಳಿಸುವುದು (Delete): Object ಒಳಗಿನ ಅಂಶವನ್ನು ತೆಗೆಯಲು.
JS
delete person.isStudent;

console.log(person.isStudent); 
// ಫಲಿತಾಂಶ: undefined (ಏಕೆಂದರೆ ಅದು ಡಿಲೀಟ್ ಆಗಿದೆ)

2. Intermediate Level (ಮಧ್ಯಮ ಹಂತ)

Object ಒಳಗೆ ಫಂಕ್ಷನ್ ಗಳನ್ನು ಬರೆಯುವುದು ಮತ್ತು Object ಅನ್ನು ಲೂಪ್ ಮಾಡುವುದು.

Methods & 'this'
Object ಒಳಗಿನ ಫಂಕ್ಷನ್ (Method) ಮತ್ತು this ಬಳಸುವುದು:
JS
let user = {
    name: "Kiran",
    greet: function() {
        // this ಎಂದರೆ ಇದೇ object ಎಂದರ್ಥ
        console.log("Hello, my name is " + this.name);
    }
};

user.greet(); 
// ಫಲಿತಾಂಶ: "Hello, my name is Kiran"
for...in Loop
Object ಅನ್ನು ಲೂಪ್ ಮಾಡುವುದು (ಡೇಟಾ ಹೊರತೆಗೆಯಲು):
JS
let car = { brand: "Tata", model: "Nexon", year: 2023 };

for (let key in car) {
    console.log(key + " : " + car[key]);
}
// ಫಲಿತಾಂಶ: 
// brand : Tata
// model : Nexon
// year : 2023
'in' Operator
Object ನಲ್ಲಿ ಒಂದು Key ಇದೆಯೋ ಇಲ್ಲವೋ ಎಂದು ಪರೀಕ್ಷಿಸಲು:
JS
let student = { name: "Anil", marks: 85 };

console.log("marks" in student); // true
console.log("age" in student);   // false

3. Object Built-in Methods (ಪ್ರಮುಖ ಫಂಕ್ಷನ್‌ಗಳು)

Object ನ ಒಳಗಿರುವ Keys ಮತ್ತು Values ಗಳನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ Array ಆಗಿ ಪರಿವರ್ತಿಸಲು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ 3 ಪ್ರಬಲ ಅಸ್ತ್ರಗಳನ್ನು ನೀಡಿದೆ.

JS
let laptop = { brand: "Dell", ram: "8GB", price: 50000 };
Object.keys()
ಕೇವಲ ಕೀಗಳನ್ನು ಪಡೆಯಲು:
JS
let keysArray = Object.keys(laptop);
console.log(keysArray); 
// ಫಲಿತಾಂಶ: ["brand", "ram", "price"]
Object.values()
ಕೇವಲ ಬೆಲೆಗಳನ್ನು (Values) ಪಡೆಯಲು:
JS
let valuesArray = Object.values(laptop);
console.log(valuesArray); 
// ಫಲಿತಾಂಶ: ["Dell", "8GB", 50000]
Object.entries()
ಎರಡನ್ನೂ ಒಟ್ಟಿಗೆ (Array ಒಳಗೆ Array) ಪಡೆಯಲು:
JS
let entriesArray = Object.entries(laptop);
console.log(entriesArray); 
// ಫಲಿತಾಂಶ: [["brand", "Dell"], ["ram", "8GB"], ["price", 50000]]

4. Pro Level (ಉನ್ನತ ಹಂತ - ES6+ Features)

ಆಧುನಿಕ (Modern) ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ನಲ್ಲಿ ಪ್ರತಿದಿನ ಅತಿ ಹೆಚ್ಚು ಬಳಸುವ Advance ಟೆಕ್ನಿಕ್ ಗಳು.

Destructuring
ಸುಲಭವಾಗಿ ಹೊರತೆಗೆಯುವುದು: Object ನಿಂದ ಡೇಟಾವನ್ನು ಹೊರತೆಗೆದು ಹೊಸ variable ಮಾಡುವುದನ್ನು ಇದು ಸುಲಭವಾಗಿಸುತ್ತದೆ.
JS
let employee = { empName: "Sagar", role: "Developer", salary: 40000 };

// ಹಳೆಯ ವಿಧಾನ: let empName = employee.empName;
// ಹೊಸ ES6 ವಿಧಾನ:
let { empName, role } = employee;

console.log(empName); // ಫಲಿತಾಂಶ: "Sagar"
console.log(role);    // ಫಲಿತಾಂಶ: "Developer"
Spread Operator (...)
ಕಾಪಿ (Copy) ಮತ್ತು ಮರ್ಜ್ (Merge) ಮಾಡಲು: Array ಯಂತೆಯೇ Object ನಲ್ಲೂ ಡೇಟಾವನ್ನು ಸೇರಿಸಬಹುದು.
JS
let obj1 = { a: 1, b: 2 };
let obj2 = { c: 3, d: 4 };

// 1. ಎರಡು Object ಸೇರಿಸಲು (Merge)
let combined = { ...obj1, ...obj2 };
// ಫಲಿತಾಂಶ: { a: 1, b: 2, c: 3, d: 4 }

// 2. ಕಾಪಿ ಮಾಡಿ ಹೊಸ ಡೇಟಾ ಸೇರಿಸಲು
let newObj = { ...obj1, z: 99 };
// ಫಲಿತಾಂಶ: { a: 1, b: 2, z: 99 }
Property Value Shorthand
ಶಾರ್ಟ್‌ಕಟ್: Variable ಹೆಸರೇ Object ನ Key ಹೆಸರಾಗಿದ್ದರೆ, ಅದನ್ನು ಎರಡು ಬಾರಿ ಬರೆಯುವ ಅಗತ್ಯವಿಲ್ಲ.
JS
let name = "Ramesh";
let age = 30;

// ಬರೆಯಬೇಕಾದದ್ದು: let user = { name: name, age: age };
// ಶಾರ್ಟ್‌ಕಟ್ (ES6):
let user = { name, age }; 
console.log(user); // {name: "Ramesh", age: 30}
Optional Chaining (?.)
ಎರರ್ (Error) ತಡೆಯಲು: Object ಒಳಗೆ Object ಇದ್ದಾಗ, ಡೇಟಾ ಇಲ್ಲದಿದ್ದರೂ ಕೋಡ್ Crash ಆಗದಂತೆ ತಡೆಯಲು ಬಳಸುತ್ತಾರೆ.
JS
let user = { name: "Ravi", address: { city: "Mysuru" } };

// ಒಂದು ವೇಳೆ address ಇಲ್ಲದಿದ್ದರೆ Error ಬರುತ್ತದೆ. ಅದಕ್ಕಾಗಿ:
console.log(user?.address?.zipCode); 
// ಫಲಿತಾಂಶ: undefined (Error ಬರುವುದಿಲ್ಲ, ಕೋಡ್ ಸೇಫ್)
Object.freeze()
Object ಅನ್ನು ಲಾಕ್ ಮಾಡಲು: ಡೇಟಾವನ್ನು ಬದಲಾಯಿಸಲು, ಅಳಿಸಲು ಅಥವಾ ಹೊಸದನ್ನು ಸೇರಿಸಲು ಸಾಧ್ಯವೇ ಇಲ್ಲ.
JS
let profile = { name: "Admin" };
Object.freeze(profile);

profile.name = "User"; // ಬದಲಾಗುವುದಿಲ್ಲ
console.log(profile.name); // ಫಲಿತಾಂಶ: "Admin"
Object.seal()
ಮಾರ್ಪಾಡು ಮಾತ್ರ (Seal): ಹೊಸ Key ಸೇರಿಸಲು/ಡಿಲೀಟ್ ಮಾಡಲು ಸಾಧ್ಯವಿಲ್ಲ. ಆದರೆ ಈಗಾಗಲೇ ಇರುವ ಡೇಟಾವನ್ನು ಮಾತ್ರ ಬದಲಾಯಿಸಬಹುದು.
JS
let config = { theme: "Dark" };
Object.seal(config);

config.theme = "Light"; // ಇದು ಬದಲಾಗುತ್ತದೆ!
config.fontSize = 14;   // ಇದು ಸೇರ್ಪಡೆಯಾಗುವುದಿಲ್ಲ!
delete config.theme;    // ಡಿಲೀಟ್ ಆಗುವುದಿಲ್ಲ!

console.log(config); 
// ಫಲಿತಾಂಶ: { theme: "Light" }

ನೀವು ಈಗ JavaScript Objects ನ ಎಲ್ಲಾ ಪ್ರಮುಖ ಕಾನ್ಸೆಪ್ಟ್‌ಗಳನ್ನು ಕಲಿತಿದ್ದೀರಿ. Destructuring, Spread Operator, ಮತ್ತು Optional Chaining ಗಳು ಆಧುನಿಕ ರಿಯಾಕ್ಟ್ (React) ಮತ್ತು ಇತರ ಫ್ರೇಮ್‌ವರ್ಕ್‌ಗಳಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ಬಳಕೆಯಾಗುತ್ತವೆ!
