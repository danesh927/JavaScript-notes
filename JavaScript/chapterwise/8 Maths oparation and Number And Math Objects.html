JavaScript Operators & Math Notes

JavaScript ಗಣಿತದ ಆಪರೇಟರ್‌ಗಳು

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಗಣಿತದ ಕಾರ್ಯಾಚರಣೆಗಳನ್ನು (Mathematical operations) ಮಾಡಲು ಹಲವಾರು ಆಪರೇಟರ್‌ಗಳನ್ನು (Operators) ಬಳಸಲಾಗುತ್ತದೆ. ಮೂಲಭೂತ ಲೆಕ್ಕಾಚಾರಗಳಿಂದ ಹಿಡಿದು ಸಂಕೀರ್ಣ ಕಾರ್ಯಾಚರಣೆಗಳವರೆಗೆ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ ಎಂಬುದರ ಸಂಪೂರ್ಣ ವಿವರ ಇಲ್ಲಿದೆ.

1. ಮೂಲಭೂತ ಅಂಕಗಣಿತದ ಆಪರೇಟರ್‌ಗಳು (Arithmetic Operators)

ಇವು ದಿನನಿತ್ಯದ ಲೆಕ್ಕಾಚಾರಗಳಿಗೆ ಬಳಸುವ ಸಾಮಾನ್ಯ ಆಪರೇಟರ್‌ಗಳು.

  • +
    Addition (ಸಂಕಲನ) - ಎರಡು ಸಂಖ್ಯೆಗಳನ್ನು ಕೂಡಿಸುತ್ತದೆ.
    5 + 3 = 8
  • -
    Subtraction (ವ್ಯವಕಲನ) - ಒಂದು ಸಂಖ್ಯೆಯಿಂದ ಮತ್ತೊಂದನ್ನು ಕಳೆಯುತ್ತದೆ.
    10 - 4 = 6
  • *
    Multiplication (ಗುಣಾಕಾರ) - ಎರಡು ಸಂಖ್ಯೆಗಳನ್ನು ಗುಣಿಸುತ್ತದೆ.
    5 * 4 = 20
  • /
    Division (ಭಾಗಾಕಾರ) - ಒಂದು ಸಂಖ್ಯೆಯನ್ನು ಮತ್ತೊಂದರಿಂದ ಭಾಗಿಸುತ್ತದೆ.
    20 / 4 = 5
  • %
    Modulus (ಶೇಷ) - ಭಾಗಾಕಾರ ಮಾಡಿದಾಗ ಉಳಿಯುವ ಶೇಷವನ್ನು ನೀಡುತ್ತದೆ.
    10 % 3 = 1
  • **
    Exponentiation (ಘಾತಾಂಕ) - ಒಂದು ಸಂಖ್ಯೆಯ ಘಾತವನ್ನು ಲೆಕ್ಕಹಾಕುತ್ತದೆ.
    5 ** 2 = 25

2. ಇನ್‌ಕ್ರಿಮೆಂಟ್ ಮತ್ತು ಡಿಕ್ರಿಮೆಂಟ್ (Increment & Decrement)

ವೇರಿಯೇಬಲ್‌ನ ಮೌಲ್ಯವನ್ನು 1 ರಿಂದ ಹೆಚ್ಚಿಸಲು ಅಥವಾ ಕಡಿಮೆ ಮಾಡಲು ಇವುಗಳನ್ನು ಬಳಸಲಾಗುತ್ತದೆ (ಹೆಚ್ಚಾಗಿ ಲೂಪ್‌ಗಳಲ್ಲಿ ಬಳಕೆಯಾಗುತ್ತದೆ).

  • ++
    (Increment): ಮೌಲ್ಯವನ್ನು 1 ಹೆಚ್ಚಿಸುತ್ತದೆ.
    x++ (Post-increment), ++x (Pre-increment)
  • --
    (Decrement): ಮೌಲ್ಯವನ್ನು 1 ಕಡಿಮೆ ಮಾಡುತ್ತದೆ.
    x-- (Post-decrement), --x (Pre-decrement)

3. ಗಣಿತದ ನಿಯೋಜನೆ ಆಪರೇಟರ್‌ಗಳು (Math Assignment Operators)

ಒಂದು ವೇರಿಯೇಬಲ್‌ಗೆ ಲೆಕ್ಕಾಚಾರ ಮಾಡಿ ಅದೇ ವೇರಿಯೇಬಲ್‌ನಲ್ಲಿ ಮೌಲ್ಯವನ್ನು ಸ್ಟೋರ್ ಮಾಡಲು ಶಾರ್ಟ್‌ಕಟ್ ಆಗಿ ಇವುಗಳನ್ನು ಬಳಸಲಾಗುತ್ತದೆ.

+= : x += 5 ಎಂದರೆ x = x + 5 ಎಂದರ್ಥ.
-= : x -= 5 ಎಂದರೆ x = x - 5 ಎಂದರ್ಥ.
*= : x *= 5 ಎಂದರೆ x = x * 5 ಎಂದರ್ಥ.
/= : x /= 5 ಎಂದರೆ x = x / 5 ಎಂದರ್ಥ.
%= : x %= 5 ಎಂದರೆ x = x % 5 ಎಂದರ್ಥ.
**=: x **= 2 ಎಂದರೆ x = x ** 2 ಎಂದರ್ಥ.

4. ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಗಣಿತದ ವಿಶಿಷ್ಟ ನಡವಳಿಕೆಗಳು (Tricky JS Math Behaviors)

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಡೇಟಾ ಟೈಪ್‌ಗಳು ತಾನಾಗಿಯೇ ಬದಲಾಗುವುದರಿಂದ (Type Coercion), ಕೆಲವು ಲೆಕ್ಕಾಚಾರಗಳು ವಿಭಿನ್ನವಾಗಿ ವರ್ತಿಸುತ್ತವೆ. ಇವುಗಳ ಬಗ್ಗೆ ಎಚ್ಚರವಿರಬೇಕು:

  • !
    ಸ್ಟ್ರಿಂಗ್ ಮತ್ತು ಸಂಖ್ಯೆಯ ಸಂಕಲನ (+):
    "5" + 3 ಫಲಿತಾಂಶ "53" (ಸ್ಟ್ರಿಂಗ್) ಆಗುತ್ತದೆ.
  • !
    ಸ್ಟ್ರಿಂಗ್ ಮತ್ತು ಸಂಖ್ಯೆಯ ಇತರ ಕಾರ್ಯಾಚರಣೆಗಳು (-, *, /):
    "10" - 2 ಫಲಿತಾಂಶ 8 ಆಗುತ್ತದೆ.
  • NaN
    NaN (Not a Number): ಸಂಖ್ಯೆಯಲ್ಲದ ಪಠ್ಯವನ್ನು ಸಂಖ್ಯೆಯ ಜೊತೆ ಲೆಕ್ಕಾಚಾರ ಮಾಡಲು ಪ್ರಯತ್ನಿಸಿದರೆ. ಉದಾಹರಣೆ: "Hello" / 2 = NaN.
  • ∞
    Infinity (ಅನಂತ): ಯಾವುದೇ ಸಂಖ್ಯೆಯನ್ನು ಸೊನ್ನೆಯಿಂದ (0) ಭಾಗಿಸಿದರೆ. ಉದಾಹರಣೆ: 10 / 0 = Infinity.

5. ಆಪರೇಟರ್ ಆದ್ಯತೆ (Operator Precedence / BODMAS)

ಒಂದೇ ಸಾಲಿನಲ್ಲಿ ಹಲವು ಆಪರೇಟರ್‌ಗಳಿದ್ದರೆ, ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಗಣಿತದ ನಿಯಮದಂತೆಯೇ (BODMAS/PEMDAS) ಆದ್ಯತೆ ನೀಡುತ್ತದೆ:

  1. () ಆವರಣ (Parentheses)
  2. ** ಘಾತಾಂಕ (Exponentiation)
  3. *, /, % ಗುಣಾಕಾರ, ಭಾಗಾಕಾರ ಮತ್ತು ಶೇಷ (ಎಡದಿಂದ ಬಲಕ್ಕೆ)
  4. +, - ಸಂಕಲನ ಮತ್ತು ವ್ಯವಕಲನ (ಎಡದಿಂದ ಬಲಕ್ಕೆ)
ಉದಾಹರಣೆ:
10 + 5 * 2 ರ ಫಲಿತಾಂಶ 20.
(10 + 5) * 2 ರ ಫಲಿತಾಂಶ 30.

6. ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಮ್ಯಾಥ್ ಆಬ್ಜೆಕ್ಟ್ (JavaScript Math Object) - [ಹೊಸ ಸೇರ್ಪಡೆ]

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಸಂಕೀರ್ಣ ಗಣಿತದ ಲೆಕ್ಕಾಚಾರಗಳನ್ನು ಸುಲಭಗೊಳಿಸಲು Math ಎಂಬ ಇನ್-ಬಿಲ್ಟ್ ಆಬ್ಜೆಕ್ಟ್ ಇದೆ. ಇದರ ಪ್ರಮುಖ ಕಾರ್ಯಗಳು ಇಲ್ಲಿವೆ:

  • ≈
    Math.round() - ಸಂಖ್ಯೆಯನ್ನು ಸಮೀಪದ ಪೂರ್ಣ ಸಂಖ್ಯೆಗೆ (Nearest integer) ರೌಂಡ್ ಮಾಡುತ್ತದೆ.
    Math.round(4.6) = 5 | Math.round(4.4) = 4
  • ↑
    Math.ceil() - ಸಂಖ್ಯೆಯನ್ನು ಮುಂದಿನ ಅತಿದೊಡ್ಡ ಪೂರ್ಣ ಸಂಖ್ಯೆಗೆ (Upward) ಬದಲಾಯಿಸುತ್ತದೆ.
    Math.ceil(4.1) = 5
  • ↓
    Math.floor() - ಸಂಖ್ಯೆಯನ್ನು ಹಿಂದಿನ ಅತಿಚಿಕ್ಕ ಪೂರ್ಣ ಸಂಖ್ಯೆಗೆ (Downward) ಬದಲಾಯಿಸುತ್ತದೆ.
    Math.floor(4.9) = 4
  • ?
    Math.random() - 0 ಮತ್ತು 1 ರ ನಡುವಿನ ಯಾವುದೇ ಯಾದೃಚ್ಛಿಕ (Random) ದಶಮಾಂಶ ಸಂಖ್ಯೆಯನ್ನು ನೀಡುತ್ತದೆ.
    Math.random() = 0.34982...
  • MAX
    Math.max() & Math.min() - ನೀಡಲಾದ ಸಂಖ್ಯೆಗಳಲ್ಲಿ ಅತಿ ದೊಡ್ಡ ಅಥವಾ ಅತಿ ಚಿಕ್ಕ ಸಂಖ್ಯೆಯನ್ನು ಹುಡುಕುತ್ತದೆ.
    Math.max(10, 20, 5) = 20

JavaScript Math & Number

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ (JavaScript) ಸಂಖ್ಯೆಗಳನ್ನು ನಿರ್ವಹಿಸಲು Number ಆಬ್ಜೆಕ್ಟ್ ಮತ್ತು ಗಣಿತದ ಲೆಕ್ಕಾಚಾರಗಳನ್ನು ಮಾಡಲು Math ಆಬ್ಜೆಕ್ಟ್ ಅನ್ನು ಬಳಸಲಾಗುತ್ತದೆ. ಮೂಲ (Beginner) ಹಂತದಿಂದ ವೃತ್ತಿಪರ (Pro) ಹಂತದವರೆಗಿನ ಸಂಪೂರ್ಣ ಪಟ್ಟಿ ಇಲ್ಲಿದೆ:

1. Beginner Level (ಮೂಲ ಹಂತ)

ಈ ಹಂತದಲ್ಲಿ ದಿನನಿತ್ಯದ ಪ್ರೋಗ್ರಾಮಿಂಗ್‌ಗೆ ಬೇಕಾಗುವ ಸಾಮಾನ್ಯ ಮೆಥಡ್‌ಗಳಿವೆ.

Math ಆಬ್ಜೆಕ್ಟ್:

Math.round(x)

ಸಂಖ್ಯೆಯನ್ನು ಹತ್ತಿರದ ಪೂರ್ಣ ಸಂಖ್ಯೆಗೆ ಬದಲಾಯಿಸುತ್ತದೆ.

console.log(Math.round(4.6)); // 5
console.log(Math.round(4.4)); // 4
Math.ceil(x)

ಸಂಖ್ಯೆಯನ್ನು ಮೇಲಿನ ಪೂರ್ಣ ಸಂಖ್ಯೆಗೆ ಬದಲಾಯಿಸುತ್ತದೆ.

console.log(Math.ceil(4.1)); // 5
console.log(Math.ceil(4.9)); // 5
Math.floor(x)

ಸಂಖ್ಯೆಯನ್ನು ಕೆಳಗಿನ ಪೂರ್ಣ ಸಂಖ್ಯೆಗೆ ಬದಲಾಯಿಸುತ್ತದೆ.

console.log(Math.floor(4.9)); // 4
console.log(Math.floor(4.1)); // 4
Math.random()

0 (ಸೇರಿ) ಮತ್ತು 1 (ಸೇರದೆ) ರ ನಡುವಿನ ಯಾದೃಚ್ಛಿಕ (random) ಸಂಖ್ಯೆಯನ್ನು ನೀಡುತ್ತದೆ.

console.log(Math.random()); 
// ಉದಾ: 0.384759...

// 1 ರಿಂದ 10 ರ ನಡುವಿನ ಸಂಖ್ಯೆ ಪಡೆಯಲು:
let num = Math.floor(Math.random() * 10) + 1;
Math.max(x, y, ...)

ನೀಡಲಾದ ಸಂಖ್ಯೆಗಳಲ್ಲಿ ಅತಿ ದೊಡ್ಡ ಸಂಖ್ಯೆಯನ್ನು ಹುಡುಕುತ್ತದೆ.

console.log(Math.max(10, 20, 5, 100)); // 100
Math.min(x, y, ...)

ನೀಡಲಾದ ಸಂಖ್ಯೆಗಳಲ್ಲಿ ಅತಿ ಚಿಕ್ಕ ಸಂಖ್ಯೆಯನ್ನು ಹುಡುಕುತ್ತದೆ.

console.log(Math.min(10, 20, 5, 100)); // 5

Number ಆಬ್ಜೆಕ್ಟ್:

Number(x)

ಬೇರೆ ಡೇಟಾ ಪ್ರಕಾರವನ್ನು (ಉದಾಹರಣೆಗೆ ಸ್ಟ್ರಿಂಗ್) ಸಂಖ್ಯೆಯಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.

console.log(Number("123")); // 123
console.log(Number("123.45")); // 123.45
console.log(Number("abc")); // NaN (Not a Number)
parseInt(x)

ಸ್ಟ್ರಿಂಗ್ ಅನ್ನು ಪೂರ್ಣ ಸಂಖ್ಯೆಯಾಗಿ (Integer) ಪರಿವರ್ತಿಸುತ್ತದೆ.

console.log(parseInt("10.55")); // 10
console.log(parseInt("100 years")); // 100
parseFloat(x)

ಸ್ಟ್ರಿಂಗ್ ಅನ್ನು ದಶಮಾಂಶ ಸಂಖ್ಯೆಯಾಗಿ (Float) ಪರಿವರ್ತಿಸುತ್ತದೆ.

console.log(parseFloat("10.55")); // 10.55
console.log(parseFloat("10.55 years")); // 10.55

2. Intermediate Level (ಮಧ್ಯಮ ಹಂತ)

ಈ ಹಂತದಲ್ಲಿ ಡೇಟಾವನ್ನು ಫಾರ್ಮ್ಯಾಟ್ ಮಾಡಲು ಮತ್ತು ವಿಶಿಷ್ಟ ಗಣಿತದ ಲೆಕ್ಕಾಚಾರಗಳಿಗೆ ಬಳಸುವ ಮೆಥಡ್‌ಗಳಿವೆ.

Math ಆಬ್ಜೆಕ್ಟ್:

Math.abs(x)

ಸಂಖ್ಯೆಯ ಧನಾತ್ಮಕ (absolute/positive) ಮೌಲ್ಯವನ್ನು ನೀಡುತ್ತದೆ.

console.log(Math.abs(-5)); // 5
console.log(Math.abs(5));  // 5
Math.pow(x, y)

x ನ y ಘಾತವನ್ನು (power) ಲೆಕ್ಕಾಚಾರ ಮಾಡುತ್ತದೆ.

console.log(Math.pow(2, 3)); // 8 (2*2*2)
console.log(Math.pow(5, 2)); // 25
Math.sqrt(x)

ಸಂಖ್ಯೆಯ ವರ್ಗಮೂಲವನ್ನು (square root) ಕಂಡುಹಿಡಿಯುತ್ತದೆ.

console.log(Math.sqrt(16)); // 4
console.log(Math.sqrt(81)); // 9
Math.trunc(x)

ದಶಮಾಂಶ ಭಾಗವನ್ನು ತೆಗೆದುಹಾಕಿ ಪೂರ್ಣ ಸಂಖ್ಯೆಯನ್ನು ಮಾತ್ರ ನೀಡುತ್ತದೆ.

console.log(Math.trunc(4.9)); // 4
console.log(Math.trunc(-4.9)); // -4
Math.sign(x)

ಸಂಖ್ಯೆ ಧನಾತ್ಮಕ (1), ಋಣಾತ್ಮಕ (-1) ಅಥವಾ ಸೊನ್ನೆ (0) ಎಂಬುದನ್ನು ತಿಳಿಸುತ್ತದೆ.

console.log(Math.sign(10)); // 1
console.log(Math.sign(-10)); // -1
console.log(Math.sign(0)); // 0
Math.PI

ಪೈ (π) ನ ಮೌಲ್ಯ (3.14159...).

console.log(Math.PI); 
// 3.141592653589793

Number ಆಬ್ಜೆಕ್ಟ್:

num.toFixed(x)

ದಶಮಾಂಶದ ನಂತರ ಎಷ್ಟು ಅಂಕಿಗಳು ಬೇಕು ಎಂಬುದನ್ನು ನಿರ್ಧರಿಸಿ ಸ್ಟ್ರಿಂಗ್ ಆಗಿ ನೀಡುತ್ತದೆ.

let num = 5.5678;
console.log(num.toFixed(2)); // "5.57"
console.log(num.toFixed(0)); // "6"
num.toPrecision(x)

ನಿರ್ದಿಷ್ಟ ಉದ್ದಕ್ಕೆ ಸಂಖ್ಯೆಯನ್ನು ಫಾರ್ಮ್ಯಾಟ್ ಮಾಡುತ್ತದೆ.

let num = 13.3714;
console.log(num.toPrecision(2)); // "13"
console.log(num.toPrecision(4)); // "13.37"
Number.isInteger(x)

ಮೌಲ್ಯವು ಪೂರ್ಣ ಸಂಖ್ಯೆಯೇ (Integer) ಎಂದು ಪರೀಕ್ಷಿಸುತ್ತದೆ (True/False).

console.log(Number.isInteger(10)); // true
console.log(Number.isInteger(10.5)); // false
Number.isNaN(x)

ಮೌಲ್ಯವು 'NaN' (Not-a-Number) ಆಗಿದೆಯೇ ಎಂದು ಪರೀಕ್ಷಿಸುತ್ತದೆ.

console.log(Number.isNaN(NaN)); // true
console.log(Number.isNaN(123)); // false
console.log(Number.isNaN("abc" / 2)); // true
Number.parseInt(x)

ಗ್ಲೋಬಲ್ parseInt() ನಂತೆಯೇ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ, ಆದರೆ ಇದು Number ಆಬ್ಜೆಕ್ಟ್‌ನ ಭಾಗವಾಗಿದೆ (ಹೆಚ್ಚು ಕಟ್ಟುನಿಟ್ಟಾದ ನಿರ್ವಹಣೆಗೆ).

console.log(Number.parseInt("10px")); // 10
// ಆಧುನಿಕ JS ನಲ್ಲಿ ಇದನ್ನು ಬಳಸುವುದು ಉತ್ತಮ ಅಭ್ಯಾಸ.
Math.log(x)

ಸಂಖ್ಯೆಯ ನೈಸರ್ಗಿಕ ಲಾಗರಿಥಮ್ (natural logarithm) ಅನ್ನು ನೀಡುತ್ತದೆ.

console.log(Math.log(1)); // 0
console.log(Math.log(10)); // 2.302585...

3. Pro Level (ವೃತ್ತಿಪರ ಹಂತ)

ಈ ಹಂತದಲ್ಲಿ ದೊಡ್ಡ ಡೇಟಾಸೆಟ್‌ಗಳು, ತ್ರಿಕೋನಮಿತಿ (Trigonometry) ಮತ್ತು ಅತಿ ನಿಖರವಾದ ಮೆಮೊರಿ ಲೆಕ್ಕಾಚಾರಗಳನ್ನು ನಿರ್ವಹಿಸುವ ಪ್ರಾಪರ್ಟಿಗಳಿವೆ.

Math ಆಬ್ಜೆಕ್ಟ್ (ಸುಧಾರಿತ ಗಣಿತ):

Math.cbrt(x)

ಘನಮೂಲವನ್ನು (cube root) ಕಂಡುಹಿಡಿಯುತ್ತದೆ.

console.log(Math.cbrt(8)); // 2
console.log(Math.cbrt(27)); // 3
Trigonometry: sin, cos, tan

ತ್ರಿಕೋನಮಿತಿಯ ಮೌಲ್ಯಗಳನ್ನು ರೇಡಿಯನ್‌ಗಳಲ್ಲಿ (Radians) ಲೆಕ್ಕಾಚಾರ ಮಾಡುತ್ತದೆ.

// 90 ಡಿಗ್ರಿಗಳನ್ನು ರೇಡಿಯನ್ ಗೆ ಪರಿವರ್ತಿಸಿ
let rad = 90 * Math.PI / 180;
console.log(Math.sin(rad)); // 1
console.log(Math.cos(rad)); // 0 (ಸರಿಸುಮಾರು)

Number ಆಬ್ಜೆಕ್ಟ್ (ಸುಧಾರಿತ):

Number.MAX_VALUE / MIN_VALUE

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಪ್ರತಿನಿಧಿಸಬಹುದಾದ ಅತಿದೊಡ್ಡ ಮತ್ತು ಅತಿಚಿಕ್ಕ (ಧನಾತ್ಮಕ) ಸಂಖ್ಯೆಗಳು.

console.log(Number.MAX_VALUE); 
// 1.7976931348623157e+308

console.log(Number.MIN_VALUE); 
// 5e-324
MAX_SAFE_INTEGER

ನಿಖರತೆ ಕಳೆದುಕೊಳ್ಳದೆ ಬಳಸಬಹುದಾದ ಅತಿದೊಡ್ಡ ಪೂರ್ಣ ಸಂಖ್ಯೆ.

console.log(Number.MAX_SAFE_INTEGER); 
// 9007199254740991

console.log(Number.MIN_SAFE_INTEGER);
// -9007199254740991
