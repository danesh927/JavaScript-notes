DOM ನಲ್ಲಿ ಹೊಸ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು
ಸೃಷ್ಟಿಸುವುದು ಮತ್ತು ಸೇರಿಸುವುದು

DOM (Document Object Model) ನಲ್ಲಿ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ (JavaScript) ಬಳಸಿ ಹೊಸ HTML ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಸೃಷ್ಟಿಸುವುದು (Creating) ಮತ್ತು ಅದನ್ನು ವೆಬ್‌ಪುಟದಲ್ಲಿ ಸೇರಿಸುವುದು (Appending) ವೆಬ್ ಡೆವಲಪ್‌ಮೆಂಟ್‌ನ ಅತ್ಯಂತ ಪ್ರಮುಖ ಕೌಶಲ್ಯವಾಗಿದೆ.

ಯಾವುದೇ ಮಾಹಿತಿಯನ್ನು ಬಿಡದೆ, Beginner (ಆರಂಭಿಕ) ಹಂತದಿಂದ Pro (ವೃತ್ತಿಪರ) ಹಂತದವರೆಗೆ ಪ್ರತಿಯೊಂದನ್ನೂ ಉದಾಹರಣೆಗಳೊಂದಿಗೆ ಇಲ್ಲಿ ವಿವರಿಸಲಾಗಿದೆ.

Level 1

Beginner: ಎಲಿಮೆಂಟ್ ಸೃಷ್ಟಿಸುವುದು ಮತ್ತು ಕಂಟೆಂಟ್ ಸೇರಿಸುವುದು

ಹೊಸ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಸೃಷ್ಟಿಸಲು document.createElement(tagName) ಅನ್ನು ಬಳಸಲಾಗುತ್ತದೆ.

ಗಮನಿಸಿ: ನೀವು ಎಲಿಮೆಂಟ್ ಅನ್ನು ಸೃಷ್ಟಿಸಿದಾಗ ಅದು ಕೇವಲ ಬ್ರೌಸರ್‌ನ ಮೆಮೊರಿಯಲ್ಲಿ (Memory) ಇರುತ್ತದೆ. ಅದನ್ನು ನಾವು ಮ್ಯಾನುಯಲ್ ಆಗಿ ವೆಬ್‌ಪುಟಕ್ಕೆ (DOM ಗೆ) ಸೇರಿಸುವವರೆಗೂ ಅದು ಸ್ಕ್ರೀನ್ ಮೇಲೆ ಕಾಣಿಸುವುದಿಲ್ಲ.

A. ಎಲಿಮೆಂಟ್ ಸೃಷ್ಟಿ ಮತ್ತು ಟೆಕ್ಸ್ಟ್ ಸೇರಿಸುವಿಕೆ

// 1. ಹೊಸ <div> ಎಲಿಮೆಂಟ್ ಸೃಷ್ಟಿಸುವುದು
const newDiv = document.createElement("div");

// 2. ಅದಕ್ಕೆ ಟೆಕ್ಸ್ಟ್ (Content) ಸೇರಿಸುವುದು
newDiv.innerText = "ನಮಸ್ಕಾರ, ಇದು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಿಂದ ಬಂದಿದೆ!";
// ಅಥವಾ newDiv.textContent ಅನ್ನು ಕೂಡ ಬಳಸಬಹುದು.

// 3. ಮೆಮೊರಿಯಲ್ಲಿರುವ ಈ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಬಾಡಿ(body) ಗೆ ಸೇರಿಸುವುದು
document.body.appendChild(newDiv);

B. innerText, textContent ಮತ್ತು innerHTML ನಡುವಿನ ವ್ಯತ್ಯಾಸ

innerText

ಇದು ಕೇವಲ ಬಳಕೆದಾರರಿಗೆ ಕಾಣುವ ಟೆಕ್ಸ್ಟ್ ಅನ್ನು ಮಾತ್ರ ಪರಿಗಣಿಸುತ್ತದೆ (CSS ಮೂಲಕ hide ಆಗಿರುವ ಟೆಕ್ಸ್ಟ್ ಅನ್ನು ಬಿಡುತ್ತದೆ).

textContent

ಇದು ಎಲಿಮೆಂಟ್‌ನ ಒಳಗಿರುವ ಎಲ್ಲಾ ಟೆಕ್ಸ್ಟ್ ಅನ್ನು (hide ಆಗಿದ್ದರೂ) ತರುತ್ತದೆ. ಇದು innerText ಗಿಂತ ವೇಗವಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

innerHTML

ಟೆಕ್ಸ್ಟ್ ಜೊತೆಗೆ HTML ಟ್ಯಾಗ್‌ಗಳನ್ನು ಸೇರಿಸಲು ಇದನ್ನು ಬಳಸುತ್ತಾರೆ.

Pro Tip: ಬಳಕೆದಾರರು ನೀಡುವ ಡೇಟಾವನ್ನು innerHTML ಮೂಲಕ ಸೇರಿಸಬೇಡಿ, ಇದು XSS (Cross-Site Scripting) ಹ್ಯಾಕಿಂಗ್‌ಗೆ ಕಾರಣವಾಗಬಹುದು.

Level 2

Intermediate: ಆಟ್ರಿಬ್ಯೂಟ್ಸ್ ಮತ್ತು ಕ್ಲಾಸ್‌ಗಳನ್ನು ಸೇರಿಸುವುದು

ಬರೀ ಎಲಿಮೆಂಟ್ ಸೃಷ್ಟಿಸಿದರೆ ಸಾಲದು, ಅದಕ್ಕೆ ಸ್ಟೈಲ್ (CSS Classes), ID, ಮತ್ತು Attributes ಸೇರಿಸಬೇಕು.

A. Class ಮತ್ತು ID ಸೇರಿಸುವುದು

const myButton = document.createElement("button");
myButton.textContent = "Click Me";

// 1. ID ಸೇರಿಸುವುದು
myButton.id = "submit-btn";

// 2. Class ಸೇರಿಸುವುದು (ಹಳೆಯ ವಿಧಾನ)
myButton.className = "btn btn-primary";

// 3. ClassList ಬಳಸುವುದು (ಉತ್ತಮ/Pro ವಿಧಾನ)
myButton.classList.add("active"); // ಸೇರಿಸಲು
myButton.classList.remove("btn"); // ತೆಗೆಯಲು
myButton.classList.toggle("hidden"); // ಟಾಗಲ್ ಮಾಡಲು

B. Attributes ಸೇರಿಸುವುದು

src, href, alt, type ಮುಂತಾದ ಆಟ್ರಿಬ್ಯೂಟ್‌ಗಳನ್ನು ಸೇರಿಸಲು:

const newImage = document.createElement("img");

// setAttribute(name, value)
newImage.setAttribute("src", "profile.jpg");
newImage.setAttribute("alt", "ಬಳಕೆದಾರರ ಫೋಟೋ");

// ಕೆಲವು ಆಟ್ರಿಬ್ಯೂಟ್‌ಗಳನ್ನು ನೇರವಾಗಿ ಸೇರಿಸಬಹುದು
newImage.src = "profile.jpg";
Level 3

Advanced: DOM ಗೆ ಸೇರಿಸುವ ವಿವಿಧ ವಿಧಾನಗಳು

ಮೆಮೊರಿಯಲ್ಲಿ ಸಿದ್ಧಪಡಿಸಿದ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಯಾವ ಜಾಗದಲ್ಲಿ ಸೇರಿಸಬೇಕು ಎಂಬುದಕ್ಕೆ ಹಲವು ವಿಧಾನಗಳಿವೆ.

A. append() vs appendChild()

  • appendChild(): ಇದು ಕೇವಲ ಒಂದೇ ಒಂದು Node (ಎಲಿಮೆಂಟ್) ಅನ್ನು ಮಾತ್ರ ಕೊನೆಯಲ್ಲಿ ಸೇರಿಸುತ್ತದೆ. ಟೆಕ್ಸ್ಟ್ ಅನ್ನು ನೇರವಾಗಿ ಸೇರಿಸಲು ಬರುವುದಿಲ್ಲ.
  • append(): ಇದು ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಮತ್ತು ಸಾಮಾನ್ಯ ಟೆಕ್ಸ್ಟ್ ಎರಡನ್ನೂ ಒಟ್ಟಿಗೆ ಸೇರಿಸಬಲ್ಲದು. (ಇದು ಹೆಚ್ಚು ಆಧುನಿಕ).
const parent = document.getElementById("container");
const child1 = document.createElement("p");
child1.textContent = "ಪ್ಯಾರಾಗ್ರಾಫ್ 1";

// 1. appendChild (ಕೊನೆಯಲ್ಲಿ ಸೇರಿಸುತ್ತದೆ)
parent.appendChild(child1);

// 2. append (ಟೆಕ್ಸ್ಟ್ ಮತ್ತು ಎಲಿಮೆಂಟ್ ಎರಡನ್ನೂ ಒಟ್ಟಿಗೆ ಸೇರಿಸಬಹುದು)
parent.append("ಇದು ಸಾಮಾನ್ಯ ಟೆಕ್ಸ್ಟ್ ", child1);

B. prepend()

ಒಂದು ಕಂಟೇನರ್‌ನ ಮೊದಲ ಎಲಿಮೆಂಟ್ ಆಗಿ (ಆರಂಭದಲ್ಲಿ) ಸೇರಿಸಲು prepend() ಬಳಸುತ್ತಾರೆ.

const title = document.createElement("h1");
title.textContent = "ಸ್ವಾಗತ";
// ಇದು ಕಂಟೇನರ್‌ನ ಮೇಲ್ಭಾಗದಲ್ಲಿ ಸೇರುತ್ತದೆ
parent.prepend(title);

C. insertBefore()

ಒಂದು ನಿರ್ದಿಷ್ಟ ಎಲಿಮೆಂಟ್‌ನ ಹಿಂದೆ (ನಿಖರವಾದ ಜಾಗದಲ್ಲಿ) ಸೇರಿಸಲು ಇದನ್ನು ಬಳಸುತ್ತಾರೆ.

// ರಚನೆ: parent.insertBefore(ಹೊಸ, ಯಾವ_ಎಲಿಮೆಂಟ್‌ನ_ಹಿಂದೆ)
const newItem = document.createElement("li");
newItem.textContent = "ಹೊಸ ಐಟಂ";

const list = document.getElementById("myList");
const secondItem = list.children[1]; // 2ನೇ ಐಟಂ

list.insertBefore(newItem, secondItem);
Level 4

Pro Level: ಅತ್ಯಾಧುನಿಕ ತಂತ್ರಗಳು (Optimization)

ನೀವು ಪ್ರೊಫೆಷನಲ್ ಡೆವಲಪರ್ ಆದಾಗ, 100 ಅಥವಾ 1000 ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಒಂದೇ ಬಾರಿಗೆ ಲೂಪ್ (Loop) ಮೂಲಕ ಸೇರಿಸಬೇಕಾದ ಪರಿಸ್ಥಿತಿ ಬರುತ್ತದೆ. ಆಗ ಮೇಲಿನ ವಿಧಾನಗಳನ್ನು ಬಳಸಿದರೆ ವೆಬ್‌ಸೈಟ್ ಸ್ಲೋ ಆಗುತ್ತದೆ (ಕಾರಣ: ಪ್ರತಿ ಬಾರಿ DOM ಬದಲಾದಾಗ ಬ್ರೌಸರ್ ರೀ-ರೆಂಡರ್ ಆಗುತ್ತದೆ).

A. DocumentFragment ಮೆಮೊರಿ ಆಪ್ಟಿಮೈಸೇಶನ್ - The Pro Way

DocumentFragment ಎಂಬುದು ಒಂದು ಅದೃಶ್ಯ ಕಂಟೇನರ್ (Invisible Container). ನೀವು 1000 ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಈ Fragment ಒಳಗೆ ಸೇರಿಸಿ, ಆಮೇಲೆ ಆ Fragment ಅನ್ನು ಒಂದೇ ಬಾರಿಗೆ DOM ಗೆ ಸೇರಿಸಬಹುದು. ಇದರಿಂದ ಬ್ರೌಸರ್ ಕೇವಲ ಒಮ್ಮೆ ಮಾತ್ರ ರಿಫ್ರೆಶ್/ರೆಂಡರ್ ಆಗುತ್ತದೆ. ಪರ್ಫಾರ್ಮೆನ್ಸ್ ಅದ್ಭುತವಾಗಿರುತ್ತದೆ. 

const ul = document.getElementById("myList");

// 1. ಒಂದು Fragment ಸೃಷ್ಟಿಸುವುದು
const fragment = document.createDocumentFragment();

// 2. 1000 <li> ಗಳನ್ನು ಸೃಷ್ಟಿಸಿ fragment ಗೆ ಸೇರಿಸುವುದು
for (let i = 1; i <= 1000; i++) {
  const li = document.createElement("li");
  li.textContent = `ಐಟಂ ಸಂಖ್ಯೆ ${i}`;
  fragment.appendChild(li); // DOM ಗೆ ಅಲ್ಲ, fragment ಗೆ ಸೇರಿಸುತ್ತಿದ್ದೇವೆ
}

// 3. ಕೊನೆಗೆ ಒಂದೇ ಬಾರಿಗೆ fragment ಅನ್ನು DOM ಗೆ ಸೇರಿಸುವುದು
ul.appendChild(fragment);

B. insertAdjacentElement() ಸರ್ಜಿಕಲ್ ಪ್ಲೇಸ್‌ಮೆಂಟ್

ಇದು ಅತ್ಯಂತ ನಿಖರವಾಗಿ, ಒಂದು ಎಲಿಮೆಂಟ್‌ನ ಸುತ್ತ 4 ಜಾಗಗಳಲ್ಲಿ ಎಲ್ಲಿ ಬೇಕಾದರೂ ಹೊಸ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಸೇರಿಸಲು ಅನುಮತಿಸುತ್ತದೆ. 

const box = document.getElementById("box");
const newSpan = document.createElement("span");
newSpan.textContent = "ಹೊಸ ಸ್ಪ್ಯಾನ್";

// 1. ಎಲಿಮೆಂಟ್‌ನ ಮುಂಚೆ (ಹೊರಗಡೆ)
box.insertAdjacentElement("beforebegin", newSpan);

// 2. ಎಲಿಮೆಂಟ್‌ನ ಒಳಗೆ, ಮೊದಲನೇ ಮಗುವಾಗಿ
box.insertAdjacentElement("afterbegin", newSpan);

// 3. ಎಲಿಮೆಂಟ್‌ನ ಒಳಗೆ, ಕೊನೆಯ ಮಗುವಾಗಿ
box.insertAdjacentElement("beforeend", newSpan);

// 4. ಎಲಿಮೆಂಟ್‌ನ ನಂತರ (ಹೊರಗಡೆ)
box.insertAdjacentElement("afterend", newSpan);

C. ಎಲಿಮೆಂಟ್ ಕಾಪಿ ಮಾಡುವುದು (cloneNode)

ಒಂದು ಎಲಿಮೆಂಟ್ ಅನ್ನು ಮತ್ತೆ ಮತ್ತೆ ಹೊಸದಾಗಿ ಸೃಷ್ಟಿಸುವ ಬದಲು, ಇರುವ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಕಾಪಿ (Clone) ಮಾಡಬಹುದು. 

const originalDiv = document.getElementById("myCard");

// cloneNode(true) ಎಂದರೆ ಅದರ ಒಳಗಿರುವ ಟೆಕ್ಸ್ಟ್ ಮತ್ತು ಮಕ್ಕಳನ್ನೂ ಸೇರಿಸಿ ಕಾಪಿ ಮಾಡುತ್ತದೆ.
// false ಕೊಟ್ಟರೆ ಕೇವಲ ಖಾಲಿ <div> ಮಾತ್ರ ಕಾಪಿ ಆಗುತ್ತದೆ.
const clonedDiv = originalDiv.cloneNode(true);

document.body.appendChild(clonedDiv);
