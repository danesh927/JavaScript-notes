DOM Traversing Masterclass

DOM (Document Object Model) ಅನ್ನು ಒಂದು Tree Structure (ಮರದ ಆಕಾರದ ರಚನೆ) ಎಂದು ಪರಿಗಣಿಸಲಾಗುತ್ತದೆ. ಬ್ರೌಸರ್ HTML ಕೋಡ್ ಅನ್ನು ಓದಿದಾಗ, ಅದು ಪ್ರತಿಯೊಂದು ಟ್ಯಾಗ್, ಟೆಕ್ಸ್ಟ್ ಮತ್ತು ಕಾಮೆಂಟ್ ಅನ್ನು ಒಂದೊಂದು Node ಆಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ. ಈ ನೋಡ್‌ಗಳ ನಡುವೆ ಚಲಿಸುವುದನ್ನೇ DOM Traversing ಎನ್ನುತ್ತಾರೆ.

Node ಮತ್ತು Element ನಡುವಿನ ವ್ಯತ್ಯಾಸ

ತಾಂತ್ರಿಕವಾಗಿ ಇದನ್ನು ಸರಿಯಾಗಿ ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಮೊದಲು Node ಮತ್ತು Element ನಡುವಿನ ವ್ಯತ್ಯಾಸ ತಿಳಿಯುವುದು ಅತಿಮುಖ್ಯ:

Node

HTML ನಲ್ಲಿನ ಪ್ರತಿಯೊಂದೂ ಒಂದು Node ಆಗಿರುತ್ತದೆ.

  • ಎಂಟರ್ ಹೊಡೆದಾಗ ಬರುವ ಖಾಲಿ ಜಾಗ (Text Node)
  • ಕಾಮೆಂಟ್‌ಗಳು (Comment Node)
  • ಮತ್ತು HTML ಟ್ಯಾಗ್‌ಗಳು (Element Node)

Element

ಇದು ಕೇವಲ HTML ಟ್ಯಾಗ್‌ಗಳನ್ನು <div>, <p>, <li> ಮಾತ್ರ ಸೂಚಿಸುತ್ತದೆ.

(ಇದು Node ನ ಒಂದು ನಿರ್ದಿಷ್ಟ ವಿಧ).

ಮಾದರಿ HTML ಸ್ಟ್ರಕ್ಚರ್ (Reference Code)

index.html

ಕೆಳಗಿನ ಮಾದರಿ HTML ಸ್ಟ್ರಕ್ಚರ್ ಅನ್ನು ಆಧಾರವಾಗಿಟ್ಟುಕೊಂಡು ಪ್ರತಿಯೊಂದು ಟ್ರಾವರ್ಸಿಂಗ್ ವಿಧಾನವನ್ನು ತಾಂತ್ರಿಕವಾಗಿ ವಿವರಿಸಲಾಗಿದೆ:

<!-- HTML Structure -->
<div id="wrapper" class="container">
    <!-- List of items -->
    <ul id="myList">
        <li class="item-1">ಮೊದಲನೇ ಐಟಂ</li>
        <li class="item-2">ಎರಡನೇ ಐಟಂ</li>
        <li class="item-3">ಮೂರನೇ ಐಟಂ</li>
    </ul>
</div>

1. Downward Traversing

(ಮಕ್ಕಳನ್ನು ಹುಡುಕುವುದು / Child Traversing)

ಒಂದು ಪೇರೆಂಟ್ ಎಲಿಮೆಂಟ್‌ನ ಒಳಗಿರುವ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಪ್ರವೇಶಿಸಲು ಇದನ್ನು ಬಳಸಲಾಗುತ್ತದೆ.

A. childNodes vs children

childNodes

ಇದು ಎಲಿಮೆಂಟ್‌ನ ಒಳಗಿರುವ ಎಲ್ಲಾ ರೀತಿಯ ನೋಡ್‌ಗಳನ್ನು (Text nodes, Comments, ಮತ್ತು Elements) ಒಳಗೊಂಡಿರುವ ಒಂದು NodeList ಅನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತದೆ.

children

ಇದು ಕೇವಲ HTML ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಮಾತ್ರ ಒಳಗೊಂಡಿರುವ ಒಂದು HTMLCollection ಅನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತದೆ. (ಇದು ಖಾಲಿ ಜಾಗ ಮತ್ತು ಕಾಮೆಂಟ್‌ಗಳನ್ನು ನಿರ್ಲಕ್ಷಿಸುತ್ತದೆ).

const list = document.getElementById("myList");

// 1. childNodes
console.log(list.childNodes); 
// Output: NodeList(7) [text, li.item-1, text, li.item-2, text, li.item-3, text]
// (ಇಲ್ಲಿ 'text' ಎಂದರೆ HTML ನಲ್ಲಿರುವ 'Enter' (line-break) ಮತ್ತು ಖಾಲಿ ಜಾಗಗಳು)

// 2. children
console.log(list.children); 
// Output: HTMLCollection(3) [li.item-1, li.item-2, li.item-3]

B. firstChild vs firstElementChild

  • firstChild: ಪೇರೆಂಟ್‌ನ ಮೊದಲನೇ ನೋಡ್ ಅನ್ನು ಕೊಡುತ್ತದೆ (ಅದು ಕಾಮೆಂಟ್ ಅಥವಾ ಖಾಲಿ ಜಾಗ ಆಗಿರಬಹುದು).
  • firstElementChild: ಪೇರೆಂಟ್‌ನ ನಿಖರವಾದ ಮೊದಲನೇ HTML ಎಲಿಮೆಂಟ್ ಅನ್ನು ಕೊಡುತ್ತದೆ.
console.log(list.firstChild); 
// Output: #text (ಏಕೆಂದರೆ <ul> ಮತ್ತು ಮೊದಲನೇ <li> ನಡುವೆ Enter ಹೊಡೆಯಲಾಗಿದೆ)

console.log(list.firstElementChild); 
// Output: <li class="item-1">ಮೊದಲನೇ ಐಟಂ</li>

C. lastChild vs lastElementChild

  • lastChild: ಕೊನೆಯ ನೋಡ್ ಅನ್ನು ಕೊಡುತ್ತದೆ.
  • lastElementChild: ಕೊನೆಯ HTML ಎಲಿಮೆಂಟ್ ಅನ್ನು ಕೊಡುತ್ತದೆ.
console.log(list.lastElementChild); 
// Output: <li class="item-3">ಮೂರನೇ ಐಟಂ</li>

2. Upward Traversing

(ಪೇರೆಂಟ್ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಹುಡುಕುವುದು)

ಪ್ರಸ್ತುತ ಎಲಿಮೆಂಟ್‌ನಿಂದ ಮೇಲ್ಮುಖವಾಗಿ (DOM ಟ್ರೀಯಲ್ಲಿ ಮೇಲಕ್ಕೆ) ಚಲಿಸಲು ಇವುಗಳನ್ನು ಬಳಸಲಾಗುತ್ತದೆ.

A. parentNode vs parentElement

ಇವೆರಡೂ ಪ್ರಸ್ತುತ ಎಲಿಮೆಂಟ್‌ನ ನೇರ ಪೇರೆಂಟ್ ಅನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತವೆ. ತಾಂತ್ರಿಕವಾಗಿ ಇವೆರಡರ ನಡುವೆ ಇರುವ ಏಕೈಕ ವ್ಯತ್ಯಾಸವೆಂದರೆ, ಪೇರೆಂಟ್ ಒಂದು ವೇಳೆ Element ಆಗಿಲ್ಲದಿದ್ದರೆ parentElement null ಅನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತದೆ. (ಉದಾ: document.documentElement.parentElement null ಆಗಿರುತ್ತದೆ, ಆದರೆ parentNode document ಆಗಿರುತ್ತದೆ). 

const item2 = document.querySelector(".item-2");

console.log(item2.parentElement); 
// Output: <ul id="myList">...</ul>

B. closest(selector) (ಅತ್ಯಂತ ಪ್ರಮುಖ ತಾಂತ್ರಿಕ ವಿಧಾನ)

ಇದು ಕೇವಲ ಒಂದು ಹೆಜ್ಜೆ ಮೇಲಕ್ಕೆ ಹೋಗುವುದಿಲ್ಲ. ಬದಲಾಗಿ, ನೀವು ನೀಡಿದ CSS ಸೆಲೆಕ್ಟರ್‌ಗೆ ಮ್ಯಾಚ್ ಆಗುವ ಪೇರೆಂಟ್ (ಅಥವಾ ಗ್ರ್ಯಾಂಡ್-ಪೇರೆಂಟ್) ಸಿಗುವವರೆಗೂ DOM ಟ್ರೀಯಲ್ಲಿ ಮೇಲ್ಮುಖವಾಗಿ (Ancestors) ಹುಡುಕುತ್ತಲೇ ಹೋಗುತ್ತದೆ. ಮ್ಯಾಚ್ ಆಗುವ ಮೊದಲ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತದೆ. ಇದು Event Delegation ನಲ್ಲಿ ಬಹಳ ಉಪಯುಕ್ತ. 

// item-2 ನಿಂದ ಹುಡುಕುತ್ತಾ ಹೋಗಿ, .container ಕ್ಲಾಸ್ ಇರುವ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಹಿಡಿಯುವುದು
const containerDiv = item2.closest(".container");

console.log(containerDiv); 
// Output: <div id="wrapper" class="container">...</div>

3. Sideways Traversing

(ಸಿಬ್ಲಿಂಗ್ಸ್ / ಅಕ್ಕಪಕ್ಕದ ಚಲನೆ)

ಒಂದೇ ಪೇರೆಂಟ್‌ನ ಒಳಗೆ ಇರುವ ಎಲಿಮೆಂಟ್‌ಗಳ ನಡುವೆ ಚಲಿಸಲು (ಉದಾ: ಒಂದು <li> ಇಂದ ಮತ್ತೊಂದು <li> ಗೆ) ಇವುಗಳನ್ನು ಬಳಸಲಾಗುತ್ತದೆ.

A. nextSibling
vs nextElementSibling

  • nextSibling: ಮುಂದಿನ ನೋಡ್ (ಖಾಲಿ ಜಾಗ ಇರಬಹುದು) ಅನ್ನು ಕೊಡುತ್ತದೆ.
  • nextElementSibling: ಮುಂದಿನ ನಿಖರವಾದ HTML ಎಲಿಮೆಂಟ್ ಅನ್ನು ಕೊಡುತ್ತದೆ.
const currentItem = document.querySelector(".item-2");

console.log(currentItem.nextSibling); 
// Output: #text (ಖಾಲಿ ಜಾಗ)

console.log(currentItem.nextElementSibling); 
// Output: <li class="item-3">ಮೂರನೇ ಐಟಂ</li>

B. previousSibling
vs previousElementSibling

  • previousSibling: ಹಿಂದಿನ ನೋಡ್ ಅನ್ನು ಕೊಡುತ್ತದೆ.
  • previousElementSibling: ಹಿಂದಿನ HTML ಎಲಿಮೆಂಟ್ ಅನ್ನು ಕೊಡುತ್ತದೆ.
console.log(currentItem.previousElementSibling); 
// Output: <li class="item-1">ಮೊದಲನೇ ಐಟಂ</li>

ತಾಂತ್ರಿಕ ಸಾರಾಂಶ (Technical Best Practice)

ಆಧುನಿಕ ವೆಬ್ ಡೆವಲಪ್ಮೆಂಟ್‌ನಲ್ಲಿ, childNodes, firstChild, nextSibling ಗಳನ್ನು ಬಳಸುವುದು ಬಹಳ ಅಪರೂಪ. ಏಕೆಂದರೆ, HTML ಕೋಡ್‌ನಲ್ಲಿ ನಾವು ಎಂಟರ್ (Enter/Line-break) ಹೊಡೆದಾಗ ಅಥವಾ ಸ್ಪೇಸ್ (Space) ಕೊಟ್ಟಾಗ ಬ್ರೌಸರ್ ಅದನ್ನು ಒಂದು 'Text Node' ಆಗಿ ಪರಿಗಣಿಸಿ ಬಗ್‌ಗಳಿಗೆ (Bugs) ಕಾರಣವಾಗುತ್ತದೆ.

ಆದ್ದರಿಂದ, ಪ್ರೊಫೆಷನಲ್ ಡೆವಲಪರ್‌ಗಳು ಯಾವಾಗಲೂ ಕೇವಲ ಎಲಿಮೆಂಟ್‌ಗಳ ಮೇಲೆ ಕೆಲಸ ಮಾಡುವ ಇವುಗಳನ್ನು ಮಾತ್ರ ಬಳಸುತ್ತಾರೆ:

children firstElementChild lastElementChild nextElementSibling closest()
