DOM Manipulation Series

DOM ನಲ್ಲಿ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು
ತೆಗೆದುಹಾಕುವುದು (Removing) & ಬದಲಾಯಿಸುವುದು (Replacing)

DOM (Document Object Model) ನಲ್ಲಿ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ (JavaScript) ಬಳಸಿ ಇರುವ HTML ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ತೆಗೆದುಹಾಕುವುದು ಮತ್ತು ಒಂದು ಎಲಿಮೆಂಟ್‌ನ ಜಾಗದಲ್ಲಿ ಬೇರೊಂದು ಎಲಿಮೆಂಟ್ ಅನ್ನು ಬದಲಾಯಿಸುವುದು ವೆಬ್ ಡೆವಲಪ್‌ಮೆಂಟ್‌ನ ಪ್ರಮುಖ ಭಾಗವಾಗಿದೆ.

ನೀವು ಕೇಳಿದಂತೆ, Beginner (ಆರಂಭಿಕ) ಹಂತದಿಂದ Pro (ವೃತ್ತಿಪರ/ತಜ್ಞ) ಹಂತದವರೆಗೆ ಯಾವುದೇ ತಾಂತ್ರಿಕ ಮಾಹಿತಿಯನ್ನು ಬಿಡದೆ, ಆಳವಾಗಿ (Under the hood) ಮತ್ತು ಉದಾಹರಣೆಗಳೊಂದಿಗೆ ಇಲ್ಲಿ ವಿವರಿಸಲಾಗಿದೆ.

Level 1

Beginner: ಎಲಿಮೆಂಟ್ ಅನ್ನು ತೆಗೆದುಹಾಕುವುದು (Remove)

ಒಂದು ಎಲಿಮೆಂಟ್ ಅನ್ನು DOM (ಸ್ಕ್ರೀನ್) ನಿಂದ ಡಿಲೀಟ್ ಮಾಡಲು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಎರಡು ಮುಖ್ಯ ವಿಧಾನಗಳಿವೆ.

A. remove() ಆಧುನಿಕ ಮತ್ತು ಸುಲಭ

ಇದು ಅತ್ಯಂತ ಸರಳವಾದ ವಿಧಾನ. ಯಾವ ಎಲಿಮೆಂಟ್ ಅನ್ನು ನೀವು ತೆಗೆದುಹಾಕಬೇಕೋ, ನೇರವಾಗಿ ಆ ಎಲಿಮೆಂಟ್ ಮೇಲೆಯೇ remove() ಫಂಕ್ಷನ್ ಅನ್ನು ಕರೆಯಬಹುದು. 

// 1. ಯಾವ ಎಲಿಮೆಂಟ್ ಅನ್ನು ತೆಗೆಯಬೇಕೋ ಅದನ್ನು ಸೆಲೆಕ್ಟ್ ಮಾಡುವುದು
const myBox = document.getElementById("box");

// 2. ನೇರವಾಗಿ ಅದನ್ನು ತೆಗೆದುಹಾಕುವುದು
myBox.remove();

B. removeChild() ಹಳೆಯ / Parent ಆಧಾರಿತ

ಹಳೆಯ ಬ್ರೌಸರ್‌ಗಳಲ್ಲಿ remove() ಇರಲಿಲ್ಲ. ಆಗ ಒಂದು ಎಲಿಮೆಂಟ್ ಅನ್ನು ಡಿಲೀಟ್ ಮಾಡಲು, ಮೊದಲು ಅದರ ತಂದೆ (Parent) ಯನ್ನು ಹುಡುಕಿ, ಆಮೇಲೆ "ನಿನ್ನ ಮಗನನ್ನು ಡಿಲೀಟ್ ಮಾಡು" ಎಂದು ಹೇಳಬೇಕಿತ್ತು. 

// 1. ಪೇರೆಂಟ್ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಸೆಲೆಕ್ಟ್ ಮಾಡುವುದು
const parent = document.getElementById("container");

// 2. ಡಿಲೀಟ್ ಮಾಡಬೇಕಾದ ಮಗುವನ್ನು ಸೆಲೆಕ್ಟ್ ಮಾಡುವುದು
const childToDelete = document.getElementById("item-1");

// 3. ಪೇರೆಂಟ್ ಮೂಲಕ ಮಗುವನ್ನು ಡಿಲೀಟ್ ಮಾಡುವುದು
parent.removeChild(childToDelete);
Level 2

Intermediate: ಎಲಿಮೆಂಟ್ ಅನ್ನು ಬದಲಾಯಿಸುವುದು (Replace)

ಒಂದು ಹಳೆಯ ಎಲಿಮೆಂಟ್ ಅನ್ನು ತೆಗೆದು, ಅದೇ ಜಾಗದಲ್ಲಿ ಹೊಸ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಕೂರಿಸಲು (Replace) ಕೂಡ ಎರಡು ವಿಧಾನಗಳಿವೆ.

A. replaceWith() ಆಧುನಿಕ ವಿಧಾನ

ಹಳೆಯ ಎಲಿಮೆಂಟ್‌ನ ಜಾಗದಲ್ಲಿ ಹೊಸ ಎಲಿಮೆಂಟ್ ಅಥವಾ ಕೇವಲ ಟೆಕ್ಸ್ಟ್ ಅನ್ನು ನೇರವಾಗಿ ಬದಲಾಯಿಸಲು ಇದು ಅತ್ಯುತ್ತಮ. 

const oldElement = document.getElementById("old-para");

// ಹೊಸ ಎಲಿಮೆಂಟ್ ಸೃಷ್ಟಿಸುವುದು
const newElement = document.createElement("h2");
newElement.textContent = "ಇದು ಹೊಸ ಹೆಡ್ಡಿಂಗ್!";

// ಹಳೆಯ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಹೊಸದರೊಂದಿಗೆ ರಿಪ್ಲೇಸ್ ಮಾಡುವುದು
oldElement.replaceWith(newElement);

B. replaceChild() ಪೇರೆಂಟ್ ಮೂಲಕ

ಇದು ಕೂಡ removeChild ತರಹವೇ ಪೇರೆಂಟ್ ಅನ್ನು ಅವಲಂಬಿಸಿದೆ.
(ರಚನೆ: parent.replaceChild(ಹೊಸ_ಎಲಿಮೆಂಟ್, ಹಳೆಯ_ಎಲಿಮೆಂಟ್)) 

const parentList = document.getElementById("myList");
const oldItem = document.getElementById("item-2"); // ಹಳೆಯದು

const newItem = document.createElement("li"); // ಹೊಸದು
newItem.textContent = "ರಿಪ್ಲೇಸ್ ಆದ ಹೊಸ ಐಟಂ";

// ಪೇರೆಂಟ್ ಮೂಲಕ ಬದಲಾಯಿಸುವುದು
parentList.replaceChild(newItem, oldItem);
Level 3

Advanced: ಕಂಟೇನರ್ ಅನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಖಾಲಿ ಮಾಡುವುದು (Emptying)

ನೀವು ಒಂದು <div> ಅಥವಾ <ul> ಒಳಗಿರುವ ಎಲ್ಲಾ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಒಟ್ಟಿಗೆ ಕ್ಲಿಯರ್ ಮಾಡಬೇಕಾದರೆ ಏನು ಮಾಡುತ್ತೀರಿ? ಇಲ್ಲಿ ಡೆವಲಪರ್‌ಗಳು ಮಾಡುವ ತಪ್ಪುಗಳು ಮತ್ತು ಸರಿಯಾದ ವಿಧಾನಗಳನ್ನು ನೋಡೋಣ:

A. innerHTML = ""

ಬೇಡದ ವಿಧಾನ - The Bad Way

ಸಮಸ್ಯೆ: ಇದು ಸುಲಭ, ಆದರೆ ಬ್ರೌಸರ್‌ಗೆ ಇದು ಭಾರೀ ಕೆಲಸ (Performance issue). ಜೊತೆಗೆ ಇದು ಭದ್ರತೆಗೆ (XSS Attacks) ಅಪಾಯಕಾರಿ. 

const container = document.getElementById("container");
container.innerHTML = ""; // ಇದು ಎಲ್ಲವನ್ನೂ ಖಾಲಿ ಮಾಡುತ್ತದೆ

B. replaceChildren()

The Modern Pro Way - ಅತ್ಯುತ್ತಮ ವಿಧಾನ

ಇದು ಆಧುನಿಕ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನ ಅತ್ಯಂತ ವೇಗವಾದ ವಿಧಾನ. ಇದು ಕಂಟೇನರ್ ಒಳಗಿನ ಎಲ್ಲವನ್ನೂ ಒಮ್ಮೆಲೆ ಕ್ಲಿಯರ್ ಮಾಡುತ್ತದೆ. 

const container = document.getElementById("container");

// ಒಳಗಿರುವ ಎಲ್ಲವನ್ನೂ ಡಿಲೀಟ್ ಮಾಡಲು ಇದನ್ನೇ ಬಳಸಿ!
container.replaceChildren(); 

// ಅಥವಾ ಕ್ಲಿಯರ್ ಮಾಡಿ ಹೊಸ ಎಲಿಮೆಂಟ್ ಸೇರಿಸಲು:
const newSpan = document.createElement("span");
newSpan.textContent = "ಎಲ್ಲಾ ಡಿಲೀಟ್ ಆಗಿ ನಾನು ಬಂದೆ!";
container.replaceChildren(newSpan);

C. While Loop The Legacy High-Performance Way

ಹಳೆಯ ಬ್ರೌಸರ್‌ಗಳಿಗೆ ಸಪೋರ್ಟ್ ನೀಡಬೇಕಾದರೆ ಮತ್ತು ಅತ್ಯಂತ ವೇಗವಾಗಿ ಡಿಲೀಟ್ ಮಾಡಬೇಕಾದರೆ ಈ ಲೂಪ್ ಬಳಸುತ್ತಾರೆ: 

const container = document.getElementById("container");

// ಪೇರೆಂಟ್ ಒಳಗೆ ಮೊದಲನೇ ಮಗು ಇರುವವರೆಗೂ ಡಿಲೀಟ್ ಮಾಡುತ್ತಲೇ ಇರು
while (container.firstChild) {
  container.removeChild(container.firstChild);
}
Expert Level

ಮೆಮೊರಿ ಲೀಕ್ಸ್ ಮತ್ತು ಅಂಡರ್-ದ-ಹುಡ್ (Under the Hood)

ವೃತ್ತಿಪರ ಮಟ್ಟದಲ್ಲಿ ನೀವು ಕೇವಲ ಕೋಡ್ ಬರೆದರೆ ಸಾಲದು, ಬ್ರೌಸರ್‌ನ ಮೆಮೊರಿ (RAM) ಅನ್ನು ಹೇಗೆ ನಿರ್ವಹಿಸಬೇಕು ಎಂದು ತಿಳಿಯಬೇಕು.

A. Detached DOM (ಡಿಲೀಟ್ ಆದರೂ ಬದುಕಿರುವ ಎಲಿಮೆಂಟ್!)

ನೀವು remove() ಅಥವಾ removeChild() ಮಾಡಿದಾಗ, ಆ ಎಲಿಮೆಂಟ್ ಕೇವಲ ವೆಬ್‌ಪುಟದ ಸ್ಕ್ರೀನ್ (DOM Tree) ನಿಂದ ಮರೆಯಾಗುತ್ತದೆ ಅಷ್ಟೇ. ಆದರೆ, ಆ ಎಲಿಮೆಂಟ್ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನ ವೇರಿಯೇಬಲ್ ಒಳಗೆ ಇನ್ನೂ ಜೀವಂತವಾಗಿರುತ್ತದೆ! 

const box = document.getElementById("myBox");

// ಸ್ಕ್ರೀನ್ ನಿಂದ ಡಿಲೀಟ್ ಮಾಡಿದೆವು
box.remove(); 

console.log(box); // ಆದರೂ ಕನ್ಸೋಲ್ ನಲ್ಲಿ ಎಲಿಮೆಂಟ್ ಪ್ರಿಂಟ್ ಆಗುತ್ತದೆ!

// ಬೇಕಿದ್ದರೆ ಡಿಲೀಟ್ ಆದ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಮತ್ತೆ ಬೇರೆ ಕಡೆ ಸೇರಿಸಬಹುದು!
document.body.appendChild(box);

Pro Tip: ಒಂದು ವೇಳೆ ಎಲಿಮೆಂಟ್ ಡಿಲೀಟ್ ಆದ ಮೇಲೆ ಅದು ನಿಮಗೆ ಭವಿಷ್ಯದಲ್ಲಿ ಬೇಡವೇ ಬೇಡ ಎಂದಾದರೆ, ಆ ವೇರಿಯೇಬಲ್‌ಗೆ null ಎಂದು ಸೆಟ್ ಮಾಡಬೇಕು. ಆಗ ಬ್ರೌಸರ್‌ನ Garbage Collector ಆ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಮೆಮೊರಿಯಿಂದ ಶಾಶ್ವತವಾಗಿ ಅಳಿಸುತ್ತದೆ. (box = null;)

B. Memory Leaks (Event Listeners ಬಿಡುವಿಕೆ)

ಅತ್ಯಂತ ಅನುಭವಿ ಡೆವಲಪರ್‌ಗಳು ಮಾಡುವ ದೊಡ್ಡ ತಪ್ಪು ಎಂದರೆ, ಎಲಿಮೆಂಟ್ ಅನ್ನು ಡಿಲೀಟ್ ಮಾಡುವ ಮುನ್ನ ಅದಕ್ಕಿರುವ ಈವೆಂಟ್‌ಗಳನ್ನು (Events) ತೆಗೆಯದಿರುವುದು.
ಒಂದು ಬಟನ್ ಅನ್ನು ಡಿಲೀಟ್ ಮಾಡಿದರೂ, ಅದಕ್ಕೆ ಅಟ್ಯಾಚ್ ಆಗಿರುವ onclick ಫಂಕ್ಷನ್ ಮೆಮೊರಿಯಲ್ಲಿಯೇ ಉಳಿದು, ವೆಬ್‌ಸೈಟ್ ಸ್ಲೋ ಆಗಲು (Memory Leak) ಕಾರಣವಾಗುತ್ತದೆ.

ಸರಿಯಾದ ಮತ್ತು ಸುರಕ್ಷಿತ ವಿಧಾನ (The Absolute Pro Way):

const myButton = document.getElementById("submitBtn");

// 1. ಫಂಕ್ಷನ್ ಅನ್ನು ಹೊರಗಡೆ ಬರೆಯಿರಿ
function handleClick() {
  console.log("ಬಟನ್ ಕ್ಲಿಕ್ ಆಯ್ತು");
}

// 2. ಈವೆಂಟ್ ಸೇರಿಸುವುದು
myButton.addEventListener("click", handleClick);

// --- ಕೆಲವು ಸಮಯದ ನಂತರ ಬಟನ್ ಡಿಲೀಟ್ ಮಾಡಬೇಕಾದ ಪರಿಸ್ಥಿತಿ ಬಂದಾಗ ---

// 3. ಮೊದಲು ಈವೆಂಟ್ ಅನ್ನು ಡಿಲೀಟ್ ಮಾಡಬೇಕು! (Preventing Memory Leak)
myButton.removeEventListener("click", handleClick);

// 4. ಆಮೇಲೆ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಡಿಲೀಟ್ ಮಾಡಬೇಕು
myButton.remove();

// 5. ಮೆಮೊರಿಯಿಂದ ಸಂಪೂರ್ಣ ಮುಕ್ತಗೊಳಿಸಲು (Garbage collection) null ಮಾಡಬೇಕು
// (ಒಂದು ವೇಳೆ let ವೇರಿಯೇಬಲ್ ಬಳಸಿದ್ದರೆ)
// myButton = null;

ಈ ಮೇಲಿನ ಎಲ್ಲಾ ತಂತ್ರಗಳನ್ನು ಬಳಸುವುದರಿಂದ, ನೀವು ಬರೆಯುವ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಕೋಡ್ ಅತ್ಯಂತ ವೇಗವಾಗಿ (Optimized) ಮತ್ತು ದೋಷಮುಕ್ತವಾಗಿ (Bug-free) ಇರುತ್ತದೆ!
