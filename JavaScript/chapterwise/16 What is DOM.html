DOM ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ನೋಟ್ಸ್

Document Object Model & DOM Properties - ಸಮಗ್ರ ವಿವರಣೆ (Clean Code Version)

ಖಂಡಿತ, ನೀವು ನೀಡಿದ ಅದ್ಭುತವಾದ ಮತ್ತು ವಿವರವಾದ ನೋಟ್ಸ್‌ನಿಂದ ಒಂದೇ ಒಂದು ಅಕ್ಷರವನ್ನೂ ಬಿಡದೆ, ಜೊತೆಗೆ ಇನ್ನುಳಿದ ಪ್ರಮುಖ DOM ಪ್ರಾಪರ್ಟಿಗಳನ್ನು (Properties) ಸೇರಿಸಿ, ಪ್ರತಿಯೊಂದು ಕೋಡ್‌ಅನ್ನೂ ಸಂಪೂರ್ಣವಾಗಿ ವಿವರಿಸಿದ ಸಮಗ್ರ ನೋಟ್ಸ್ ಇಲ್ಲಿದೆ:

DOM ಎಂದರೇನು?

DOM (Document Object Model) ಎಂದರೆ, ಒಂದು ವೆಬ್‌ಸೈಟ್‌ನ ಒಳಗಿರುವ ಎಲ್ಲಾ ಅಂಶಗಳನ್ನು (ಪಠ್ಯ, ಚಿತ್ರಗಳು, ಬಟನ್‌ಗಳು) ಬ್ರೌಸರ್ ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಮತ್ತು ನಿರ್ವಹಿಸಲು ರಚಿಸಿಕೊಳ್ಳುವ ಒಂದು 'ನೀಲನಕ್ಷೆ' (Blueprint) ಅಥವಾ 'ಮರದ ವಿನ್ಯಾಸ' (Tree structure).

ಒಂದು ಸರಳ ಉದಾಹರಣೆ (ಮನೆಯ ನೀಲನಕ್ಷೆ):

ನೀವು ಒಂದು ಮನೆಯನ್ನು ಕಟ್ಟಿದ್ದೀರಿ ಎಂದು ಕಲ್ಪಿಸಿಕೊಳ್ಳಿ. ಮನೆ ಕಟ್ಟಿದ ಮೇಲೆ, "ಅಡುಗೆಮನೆಯ ಕಿಟಕಿಯ ಬಣ್ಣವನ್ನು ಕೆಂಪು ಮಾಡಬೇಕು" ಎಂದು ನೀವು ಪೇಂಟರ್‌ಗೆ ಹೇಳಿದರೆ, ಆತ ಮೊದಲು ಮನೆಯ ನೀಲನಕ್ಷೆಯಲ್ಲಿ (Blueprint) ಅಡುಗೆಮನೆ ಎಲ್ಲಿದೆ ಮತ್ತು ಕಿಟಕಿ ಎಲ್ಲಿದೆ ಎಂದು ಹುಡುಕುತ್ತಾನೆ.

ಇದೇ ರೀತಿ, ನಿಮ್ಮ ಬ್ರೌಸರ್ (Chrome, Firefox) ಒಂದು ವೆಬ್‌ಸೈಟ್ ಅನ್ನು ತೆರೆದಾಗ, ಆ ವೆಬ್‌ಸೈಟ್‌ನ ಒಂದು 'ನೀಲನಕ್ಷೆ'ಯನ್ನು ಸೃಷ್ಟಿಸುತ್ತದೆ. ಈ ನೀಲನಕ್ಷೆಯನ್ನೇ DOM ಎಂದು ಕರೆಯುತ್ತೇವೆ.

DOM ನ ವಿಸ್ತೃತ ರೂಪ ಮತ್ತು ಅರ್ಥ

Document (ಡಾಕ್ಯುಮೆಂಟ್)

ನಿಮ್ಮ ಕಣ್ಣಮುಂದೆ ಕಾಣುವ ವೆಬ್‌ಸೈಟ್‌ನ ಇಡೀ ಪುಟ (Web page).

Object (ಆಬ್ಜೆಕ್ಟ್)

ಆ ಪುಟದಲ್ಲಿರುವ ಪ್ರತಿಯೊಂದು ಬಿಡಿ ಭಾಗ (ಉದಾಹರಣೆಗೆ: ಒಂದು ಪ್ಯಾರಾಗ್ರಾಫ್, ಒಂದು ಚಿತ್ರ, ಒಂದು ಬಟನ್).

Model (ಮಾಡೆಲ್)

ಇವೆಲ್ಲವನ್ನೂ ಒಂದಕ್ಕೊಂದು ಸಂಬಂಧ ಕಲ್ಪಿಸಿ, ಒಂದು ಮರದ ಆಕಾರದಲ್ಲಿ (Tree structure) ವ್ಯವಸ್ಥಿತವಾಗಿ ಜೋಡಿಸಿರುವ ವಿನ್ಯಾಸ.

DOM ಯಾವ ರೀತಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ?

ಬ್ರೌಸರ್ ಒಂದು ವೆಬ್‌ಸೈಟ್ ಅನ್ನು ಲೋಡ್ ಮಾಡುವಾಗ ನಡೆಯುವ ಪ್ರಕ್ರಿಯೆ ಹೀಗಿರುತ್ತದೆ:

  1. HTML ಕೋಡ್ ಸ್ವೀಕಾರ: ನೀವು ವೆಬ್‌ಸೈಟ್ ವಿಳಾಸ ಟೈಪ್ ಮಾಡಿದಾಗ, ಸರ್ವರ್‌ನಿಂದ ಬ್ರೌಸರ್‌ಗೆ ಕೇವಲ HTML ಕೋಡ್ (ಟೆಕ್ಸ್ಟ್ ರೂಪದಲ್ಲಿ) ಬರುತ್ತದೆ.
  2. ಮರದ ರಚನೆ (Tree Construction): ಆ ಕೋಡ್ ಅನ್ನು ಓದಿ, ಬ್ರೌಸರ್ ತಕ್ಷಣವೇ ಒಂದು DOM ಮರವನ್ನು ಕಟ್ಟುತ್ತದೆ.
    • ಇದರಲ್ಲಿ Document ಎಂಬುದು ಬೇರು (Root).
    • <html>, <head>, <body> ಟ್ಯಾಗ್‌ಗಳು ಕೊಂಬೆಗಳು (Branches).
    • ಪಠ್ಯ (Text), ಚಿತ್ರಗಳು, ಮತ್ತು ಲಿಂಕ್‌ಗಳು ಆ ಕೊಂಬೆಗಳ ಕೊನೆಯಲ್ಲಿರುವ ಎಲೆಗಳು (Leaves).
  3. ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಸಂಪರ್ಕ (JavaScript Connection): ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ (JavaScript) ಎಂಬ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಭಾಷೆ ಈ DOM ಮರವನ್ನು ಬಳಸಿಕೊಂಡು, ವೆಬ್‌ಸೈಟ್‌ನ ಯಾವುದೇ ನಿರ್ದಿಷ್ಟ ಭಾಗವನ್ನು (ಉದಾಹರಣೆಗೆ: ಒಂದು ಬಟನ್ ಅನ್ನು) ಸುಲಭವಾಗಿ ಹುಡುಕುತ್ತದೆ ಮತ್ತು ಅದಕ್ಕೆ ಬೇಕಾದ ಬದಲಾವಣೆಗಳನ್ನು ಮಾಡುತ್ತದೆ.

DOM ನ ಉಪಯೋಗವೇನು?

DOM ಇಲ್ಲದಿದ್ದರೆ, ವೆಬ್‌ಸೈಟ್‌ಗಳು ಕೇವಲ ಪತ್ರಿಕೆಯ ಪುಟಗಳಂತೆ ನಿಶ್ಚಲವಾಗಿರುತ್ತಿದ್ದವು (Static). DOM ಇರುವುದರಿಂದಲೇ ವೆಬ್‌ಸೈಟ್‌ಗಳು 'ಜೀವಂತ'ವಾಗಿವೆ (Dynamic).

  • ಪೇಜ್ ರಿಫ್ರೆಶ್ ಆಗದೆ ಬದಲಾವಣೆ: ಫೇಸ್‌ಬುಕ್‌ನಲ್ಲಿ ಅಥವಾ ಇನ್ಸ್‌ಟಾಗ್ರಾಮ್‌ನಲ್ಲಿ ನೀವು 'ಲೈಕ್' (Like) ಒತ್ತಿದಾಗ, ಇಡೀ ಪೇಜ್ ರಿಫ್ರೆಶ್ ಆಗುವುದಿಲ್ಲ. ಕೇವಲ ಆ ಬಟನ್‌ನ ಬಣ್ಣ ಮಾತ್ರ ಕೆಂಪು ಅಥವಾ ನೀಲಿಯಾಗುತ್ತದೆ. ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ DOM ಮೂಲಕ ಆ ನಿರ್ದಿಷ್ಟ ಬಟನ್‌ನ 'ಆಬ್ಜೆಕ್ಟ್' ಅನ್ನು ಮಾತ್ರ ಹುಡುಕಿ ಬಣ್ಣ ಬದಲಾಯಿಸುವುದರಿಂದ ಇದು ಸಾಧ್ಯವಾಗುತ್ತದೆ.
  • ಹೊಸ ಅಂಶಗಳನ್ನು ಸೇರಿಸುವುದು: ವಾಟ್ಸಾಪ್ ವೆಬ್‌ನಲ್ಲಿ (WhatsApp Web) ಹೊಸ ಮೆಸೇಜ್ ಬಂದಾಗ, ನೀವು ಪೇಜ್ ರಿಲೋಡ್ ಮಾಡದಿದ್ದರೂ ಅದು ಪರದೆಯ ಮೇಲೆ ಬಂದು ಕೂರುತ್ತದೆ. ಇಲ್ಲಿ ಬ್ರೌಸರ್ DOM ಮರಕ್ಕೆ ಹೊಸ ಮೆಸೇಜ್‌ನ 'ಕೊಂಬೆ'ಯನ್ನು ಸೇರಿಸುತ್ತದೆ.
  • ವಿನ್ಯಾಸ (Style) ಬದಲಾವಣೆ: ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ 'ಡಾರ್ಕ್ ಮೋಡ್' (Dark Mode) ಬಟನ್ ಒತ್ತಿದ ತಕ್ಷಣ ಇಡೀ ಹಿನ್ನೆಲೆ ಕಪ್ಪಾಗುತ್ತದೆ.
  • ಬಳಕೆದಾರರ ಕ್ರಿಯೆಗಳಿಗೆ ಸ್ಪಂದನೆ (Events): ನೀವು ಮೌಸ್ ಮೂವ್ ಮಾಡಿದಾಗ, ಫಾರ್ಮ್‌ನಲ್ಲಿ ಟೈಪ್ ಮಾಡಿದಾಗ, ಅಥವಾ ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ಬ್ರೌಸರ್ ಆ ಕ್ರಿಯೆಗಳನ್ನು DOM ಮೂಲಕವೇ ಅರಿತುಕೊಳ್ಳುತ್ತದೆ.
ಸರಳವಾಗಿ ಹೇಳಬೇಕೆಂದರೆ, HTML ಎಂಬುದು ಮನುಷ್ಯನ 'ಅಸ್ಥಿಪಂಜರ'ವಿದ್ದಂತೆ. DOM ಎಂಬುದು ಬ್ರೌಸರ್ ಆ ಅಸ್ಥಿಪಂಜರವನ್ನು ಅರ್ಥಮಾಡಿಕೊಂಡು, ಅದಕ್ಕೆ ಜೀವತುಂಬಿ ಕೆಲಸ ಮಾಡಲು ಮಾಡಿಕೊಂಡಿರುವ 'ನರಮಂಡಲ ವ್ಯವಸ್ಥೆ' (Nervous system).

DOM Property ಎಂದರೇನು?

DOM (Document Object Model) ಎಂದರೆ ಒಂದು ವೆಬ್‌ಪುಟದ (HTML ಡಾಕ್ಯುಮೆಂಟ್) ಪ್ರತಿಯೊಂದು ಟ್ಯಾಗ್ ಅನ್ನು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವಂತಹ ಒಂದು ಆಬ್ಜೆಕ್ಟ್ (Object) ಆಗಿ ಪರಿವರ್ತಿಸುವ ವ್ಯವಸ್ಥೆ.

DOM Property (ಪ್ರಾಪರ್ಟಿ): ಪ್ರಾಪರ್ಟಿ ಎಂದರೆ ಆ ಆಬ್ಜೆಕ್ಟ್‌ನ ಗುಣಲಕ್ಷಣ ಅಥವಾ ಮೌಲ್ಯ (Value). ವೆಬ್‌ಪುಟದಲ್ಲಿರುವ ಒಂದು ಎಲಿಮೆಂಟ್‌ನ (ಉದಾಹರಣೆಗೆ <p>, <div>, <a>) ಮಾಹಿತಿ, ಟೆಕ್ಸ್ಟ್, ಬಣ್ಣ, ಅಥವಾ ಅದರ ಒಳಗೆ ಏನಿದೆ ಎಂಬುದನ್ನು ಓದಲು (Read) ಮತ್ತು ಬದಲಾಯಿಸಲು (Write/Update) ಬಳಸುವ ವೇರಿಯೇಬಲ್‌ಗಳನ್ನು DOM Properties ಎನ್ನುತ್ತಾರೆ. ಉದಾಹರಣೆಗೆ: ಒಂದು ಬಟನ್‌ನ ಬಣ್ಣ, ಲಿಂಕ್‌ನ ವಿಳಾಸ (href), ಅಥವಾ ಇನ್‌ಪುಟ್ ಬಾಕ್ಸ್‌ನಲ್ಲಿರುವ ಅಕ್ಷರಗಳನ್ನು ತಿಳಿಯುವುದು DOM ಪ್ರಾಪರ್ಟಿಗಳ ಮೂಲಕವೇ ನಡೆಯುತ್ತದೆ.

1. DOM ಪ್ರಾಪರ್ಟಿಗಳ ಪರೀಕ್ಷೆ (DOM Examination)

ಒಂದು ಸಾಮಾನ್ಯ ವೆಬ್‌ಪುಟದಲ್ಲಿ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ರನ್ ಮಾಡಿದಾಗ ಈ ಕೆಳಗಿನ ಪ್ರಾಪರ್ಟಿಗಳು ಏನನ್ನು ಕೊಡುತ್ತವೆ ಎಂದು ನೋಡೋಣ:

1. document

ಇಡೀ HTML ಡಾಕ್ಯುಮೆಂಟ್ ಅನ್ನು ತೋರಿಸುತ್ತದೆ.

console.log(document);
#document (ಇಡೀ HTML ಕೋಡ್)

2. document.all

ಪೇಜ್‌ನಲ್ಲಿರುವ ಎಲ್ಲಾ HTML ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಒಂದು HTMLCollection ರೂಪದಲ್ಲಿ ಕೊಡುತ್ತದೆ.

console.log(document.all);
HTMLCollection(50) [html, head, meta...]

3. document.all[0]

ಮೇಲಿನ ಲಿಸ್ಟ್‌ನಲ್ಲಿರುವ ಮೊದಲನೇ ಎಲಿಮೆಂಟ್ ಅನ್ನು ತೋರಿಸುತ್ತದೆ.

console.log(document.all[0]);
<html lang="en">...</html>

4. document.all.length

ಆ ವೆಬ್‌ಪುಟದಲ್ಲಿ ಒಟ್ಟು ಎಷ್ಟು HTML ಎಲಿಮೆಂಟ್‌ಗಳಿವೆ (ಟ್ಯಾಗ್‌ಗಳು) ಎಂಬ ಸಂಖ್ಯೆಯನ್ನು ಹೇಳುತ್ತದೆ.

console.log(document.all.length);
50 (ಎಲಿಮೆಂಟ್‌ಗಳ ಸಂಖ್ಯೆ)

5. document.head

ಪುಟದ <head> ಭಾಗವನ್ನು ಮಾತ್ರ ತೋರಿಸುತ್ತದೆ (ಇದರಲ್ಲಿ ಟೈಟಲ್, ಲಿಂಕ್‌ಗಳು ಇರುತ್ತವೆ).

console.log(document.head);
<head>...</head>

6. document.body

ಪುಟದ <body> ಭಾಗವನ್ನು (ಪರದೆಯ ಮೇಲೆ ಕಾಣುವ ಮುಖ್ಯ ಭಾಗ) ತೋರಿಸುತ್ತದೆ.

console.log(document.body);
<body>...</body>

7. document.doctype

ಡಾಕ್ಯುಮೆಂಟ್‌ನ ಪ್ರಕಾರವನ್ನು ತಿಳಿಸುತ್ತದೆ. (ಗಮನಿಸಿ: ಕ್ಯಾಪಿಟಲ್ D ಅಲ್ಲ, ಸ್ಮಾಲ್ d)

console.log(document.doctype);
<!DOCTYPE html>

8. document.URL

ನೀವು ಪ್ರಸ್ತುತ ಇರುವ ವೆಬ್‌ಸೈಟ್‌ನ ಪೂರ್ಣ ವಿಳಾಸ (Link) ಕೊಡುತ್ತದೆ. (ಗಮನಿಸಿ: ಕ್ಯಾಪಿಟಲ್ URL)

console.log(document.URL);
"https://www.google.com/"

9. document.characterSet

ವೆಬ್‌ಪುಟವು ಯಾವ ಕ್ಯಾರೆಕ್ಟರ್ ಎನ್‌ಕೋಡಿಂಗ್ ಬಳಸುತ್ತಿದೆ ಎಂದು ಹೇಳುತ್ತದೆ.

console.log(document.characterSet);
"UTF-8"

10. document.contentType

ಕಂಟೆಂಟ್ ಪ್ರಕಾರ ಯಾವುದು ಎಂದು ತಿಳಿಸುತ್ತದೆ.

console.log(document.contentType);
"text/html"

11. document.forms

ಪೇಜ್‌ನಲ್ಲಿರುವ ಎಲ್ಲಾ ಫಾರ್ಮ್‌ಗಳ (<form> ಟ್ಯಾಗ್) ಪಟ್ಟಿಯನ್ನು ಕೊಡುತ್ತದೆ.

console.log(document.forms);
HTMLCollection [form#login...]

12. document.forms[0]

ಪೇಜ್‌ನ ಮೊದಲನೇ ಫಾರ್ಮ್ ಅನ್ನು ಮಾತ್ರ ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ.

console.log(document.forms[0]);
<form id="login">...</form>

13. document.forms[0].id

ಮೊದಲನೇ ಫಾರ್ಮ್‌ಗೆ ನೀವು ಕೊಟ್ಟಿರುವ 'id' ಹೆಸರನ್ನು ಕೊಡುತ್ತದೆ.

console.log(document.forms[0].id);
"loginForm"

14. document.links

ಪೇಜ್‌ನಲ್ಲಿರುವ ಎಲ್ಲಾ ಲಿಂಕ್‌ಗಳ (<a> ಟ್ಯಾಗ್‌ಗಳು - href ಇದ್ದರೆ ಮಾತ್ರ) ಪಟ್ಟಿ.

console.log(document.links);
HTMLCollection(10) [a, a.btn...]

15. document.links[0].className

ಮೊದಲನೇ ಲಿಂಕ್‌ಗೆ ಯಾವೆಲ್ಲಾ CSS ಕ್ಲಾಸ್‌ಗಳಿವೆ ಎಂದು ನೋಡಲು (classList ಕೂಡ ಬಳಸಬಹುದು).

console.log(document.links[0].className);
console.log(document.links[0].classList);
"btn btn-primary"

16. document.title

ವೆಬ್‌ಪುಟದ ಶೀರ್ಷಿಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ. ಇದನ್ನು ಬಳಸಿ ಶೀರ್ಷಿಕೆಯನ್ನು ಬದಲಾಯಿಸಲೂಬಹುದು.

console.log(document.title);
document.title = "New Title";
"My JavaScript Notes"

17. document.images

3. HTML Collection ಎಂದರೇನು? (Beginner Concept)

ಮೇಲೆ ನಾವು document.all, document.forms ಇತ್ಯಾದಿ ಬಳಸಿದಾಗ ನಮಗೆ ಬರುವ ರಿಸಲ್ಟ್ HTMLCollection.

  • HTMLCollection ಎಂದರೆ: ಇದು ಒಂದು ಅರೇ (Array) ತರಹವೇ ಕಾಣುವ, ಆದರೆ ನಿಜವಾದ ಅರೇ ಅಲ್ಲದ ಒಂದು ಪಟ್ಟಿ (Array-like object).
ಸಮಸ್ಯೆ ಏನು?: ನಿಜವಾದ ಅರೇಗಳಲ್ಲಿ ನಾವು forEach() ನಂತಹ ಲೂಪ್‌ಗಳನ್ನು ಬಳಸಬಹುದು. ಆದರೆ HTMLCollection ಮೇಲೆ ನೇರವಾಗಿ forEach ಬಳಸಿದರೆ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಎರರ್ (Error) ಕೊಡುತ್ತದೆ.
html_collection_error.js 
let myLinks = document.links;

myLinks.forEach(function(link) {
    console.log(link);
});

4. HTML Collection ಅನ್ನು Array ಗೆ ಬದಲಾಯಿಸುವುದು (Pro Concept)

ಈ ಸಮಸ್ಯೆಯನ್ನು ಬಗೆಹರಿಸಲು ನಾವು HTMLCollectionಅನ್ನು ನಿಜವಾದ Array ಆಗಿ ಪರಿವರ್ತಿಸಬೇಕು. ಇದಕ್ಕೆ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ Array.from() ಎಂಬ ಫಂಕ್ಷನ್ ಇದೆ.

  1. ಮೊದಲು ಲಿಂಕ್‌ಗಳನ್ನು ಪಡೆಯಿರಿ (ಇದು HTMLCollection ಆಗಿರುತ್ತದೆ).
  2. ಅದನ್ನು Array.from() ಬಳಸಿ Array ಆಗಿ ಕನ್ವರ್ಟ್ ಮಾಡಿ.
  3. ಈಗ forEach ಬಳಸಿ ಪ್ರತಿಯೊಂದು ಲಿಂಕ್ ಅನ್ನು ಪ್ರಿಂಟ್ ಮಾಡಿ (ಬೇಕಿದ್ದರೆ ಬಣ್ಣವನ್ನೂ ಬದಲಾಯಿಸಬಹುದು).
convert_to_array.js 
let allLinks = document.links;
let linksArray = Array.from(allLinks);

linksArray.forEach(function(link) {
    console.log(link);
    link.style.color = "red"; 
});

5. Pro Tip (ಆಧುನಿಕ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್)

ನೈಜ ಪ್ರಪಂಚದ ಪ್ರಾಜೆಕ್ಟ್‌ಗಳಲ್ಲಿ, ಡೆವಲಪರ್‌ಗಳು ಈಗ document.all ಅನ್ನು ಹೆಚ್ಚಾಗಿ ಬಳಸುವುದಿಲ್ಲ. ಅದರ ಬದಲು ನಿರ್ದಿಷ್ಟ ಅಂಶಗಳನ್ನು ಹುಡುಕಲು ಆಧುನಿಕ ವಿಧಾನಗಳನ್ನು ಬಳಸುತ್ತಾರೆ.
  • document.querySelector('a'): ಇದು ಪೇಜ್‌ನ ಮೊದಲನೇ ಲಿಂಕ್ ಅನ್ನು ಮಾತ್ರ ಕೊಡುತ್ತದೆ.
  • document.querySelectorAll('a'): ಇದು ಪೇಜ್‌ನ ಎಲ್ಲಾ ಲಿಂಕ್‌ಗಳನ್ನು ಕೊಡುತ್ತದೆ. ಇದರ ವಿಶೇಷತೆ ಎಂದರೆ ಇದು ಕೊಡುವುದು HTMLCollection ಅಲ್ಲ, ಬದಲಾಗಿ NodeList ಎಂಬ ಪಟ್ಟಿಯನ್ನು ಕೊಡುತ್ತದೆ.

NodeList ನ ಮೇಲೆ ನೀವು ಯಾವುದೇ ಕನ್ವರ್ಶನ್ ಮಾಡದೆ ನೇರವಾಗಿ forEach ಲೂಪ್ ಅನ್ನು ಬಳಸಬಹುದು! ಕೆಳಗಿನ ಕೋಡ್ ಗಮನಿಸಿ:

modern_js_nodelist.js 
let allLinksNodeList = document.querySelectorAll('a');

allLinksNodeList.forEach(function(link) {
    console.log(link.href);
});
