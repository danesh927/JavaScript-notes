Multiple Element Selectors

ಗುಂಪಿನಲ್ಲಿ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡುವ ಕಲೆ

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಕೇವಲ ಒಂದು ಎಲಿಮೆಂಟ್ ಅನ್ನು ಆಯ್ಕೆ ಮಾಡುವುದರ ಬದಲು, ಒಂದೇ ಬಾರಿಗೆ ಅನೇಕ ಎಲಿಮೆಂಟ್‌ಗಳ ಗುಂಪನ್ನು (ಉದಾಹರಣೆಗೆ: ಎಲ್ಲಾ ಲಿಸ್ಟ್ ಐಟಂಗಳು, ಎಲ್ಲಾ ಬಟನ್‌ಗಳು) ಆಯ್ಕೆ ಮಾಡಲು Multiple Element Selectors ಗಳನ್ನು ಬಳಸುತ್ತೇವೆ.

ಬಿಗಿನರ್ ಹಂತದಿಂದ ಪ್ರೊ ಹಂತದವರೆಗಿನ ಸಂಪೂರ್ಣ ಮಾಹಿತಿ ಇಲ್ಲಿದೆ
Beginner Level

1. getElementsByClassName()

ಇದು ಒಂದು ನಿರ್ದಿಷ್ಟ 'class' ಹೊಂದಿರುವ ಎಲ್ಲಾ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಒಟ್ಟಿಗೆ ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ. ಇದು ನಮಗೆ ಒಂದು HTMLCollection (ಒಂದು ರೀತಿಯ ಅರೇ/ಪಟ್ಟಿ) ಅನ್ನು ನೀಡುತ್ತದೆ.

HTML
<ul>
    <li class="item">ಕಾಫಿ</li>
    <li class="item">ಟೀ</li>
    <li class="item">ಹಾಲು</li>
</ul>
JavaScript
// 'item' ಕ್ಲಾಸ್ ಇರುವ ಎಲ್ಲವನ್ನು ಆಯ್ಕೆ ಮಾಡುವುದು
const allItems = document.getElementsByClassName('item');

ಎಚ್ಚರಿಕೆ:

ಇದು ಒಂದು ಗುಂಪು (Collection). ಹೀಗಾಗಿ allItems.style.color = "red" ಎಂದು ನೇರವಾಗಿ ಬರೆದರೆ ಕೆಲಸ ಮಾಡುವುದಿಲ್ಲ! ಬದಲಿಗೆ, for loop ಬಳಸಿ ಒಂದೊಂದಾಗಿ ಬದಲಾಯಿಸಬೇಕು:

for (let i = 0; i < allItems.length; i++) {
    allItems[i].style.color = "red"; 
}
Beginner/Intermediate

2. getElementsByTagName()

ಇದು ಕ್ಲಾಸ್ ಬದಲಿಗೆ, HTML ನ 'ಟ್ಯಾಗ್' (ಉದಾ: p, div, a, li) ಮೂಲಕ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಹುಡುಕುತ್ತದೆ. ಇದು ಕೂಡ HTMLCollection ಅನ್ನು ನೀಡುತ್ತದೆ. 

// ಪೇಜ್‌ನಲ್ಲಿರುವ ಎಲ್ಲಾ <p> (ಪ್ಯಾರಾಗ್ರಾಫ್) ಟ್ಯಾಗ್‌ಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ
const allParagraphs = document.getElementsByTagName('p');

for (let i = 0; i < allParagraphs.length; i++) {
    allParagraphs[i].style.fontSize = "18px";
}
Pro Level (Modern)

3. querySelectorAll()

ಇದು ಇಂದಿನ ದಿನಗಳಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ಬಳಸುವ ಮತ್ತು ಅತ್ಯಂತ ಶಕ್ತಿಶಾಲಿ ವಿಧಾನ. querySelector ಕೇವಲ ಮೊದಲನೇ ಎಲಿಮೆಂಟ್ ಅನ್ನು ಹಿಡಿದರೆ, querySelectorAll ಮ್ಯಾಚ್ ಆಗುವ ಎಲ್ಲಾ ಎಲಿಮೆಂಟ್‌ಗಳನ್ನು ಹಿಡಿದು ಒಂದು NodeList ಅನ್ನು ನೀಡುತ್ತದೆ.

ಇದರ ಅತಿದೊಡ್ಡ ಪ್ಲಸ್ ಪಾಯಿಂಟ್ ಎಂದರೆ, ಇದರಲ್ಲಿ ನೇರವಾಗಿ .forEach() ಲೂಪ್ ಅನ್ನು ಬಳಸಬಹುದು (ಹಳೆಯ for ಲೂಪ್ ಬರೆಯುವ ಅಗತ್ಯವಿಲ್ಲ).

HTML
<button class="btn">ಬಟನ್ 1</button>
<button class="btn">ಬಟನ್ 2</button>
<button class="btn">ಬಟನ್ 3</button>
JavaScript
// CSS ಸೆಲೆಕ್ಟರ್ ಮೂಲಕ ಎಲ್ಲಾ ಬಟನ್‌ಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡುವುದು
const buttons = document.querySelectorAll('.btn');

// forEach ಬಳಸಿ ಪ್ರತಿಯೊಂದು ಬಟನ್‌ಗೂ ಸ್ಟೈಲ್ ಅಪ್ಲೈ ಮಾಡುವುದು
buttons.forEach(function(btn) {
    btn.style.backgroundColor = "blue";
    btn.style.color = "white";
});
Expert Level Knowledge

4. HTMLCollection vs NodeList

ಇವೆರಡರ ನಡುವಿನ ವ್ಯತ್ಯಾಸವು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಇಂಟರ್ವ್ಯೂಗಳಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳಲ್ಲಿ ಒಂದಾಗಿದೆ. ಇದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ನಾವು ಒಂದು ನೈಜ ಉದಾಹರಣೆ ಮತ್ತು ಕಾಲ್ಪನಿಕ ಕಥೆಯನ್ನು ಬಳಸೋಣ.

ಊಹಿಸಿಕೊಳ್ಳಿ, ನಿಮ್ಮ ಬಳಿ ಒಂದು ಬುಟ್ಟಿ ಇದೆ ಮತ್ತು ಅದರಲ್ಲಿ 2 ಸೇಬುಗಳಿವೆ.

<ul id="fruit-basket">
    <li class="apple">ಸೇಬು 1</li>
    <li class="apple">ಸೇಬು 2</li>
</ul>

ಈಗ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಮೂಲಕ ಈ ಸೇಬುಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡೋಣ.

1. HTMLCollection

LIVE (CCTV ಇದ್ದಂತೆ)

ನೀವು getElementsByClassName ಬಳಸಿದಾಗ ಅದು ಒಂದು CCTV ಕ್ಯಾಮೆರಾ ತರಹ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಅದು ಪೇಜ್ ಅನ್ನು ಸದಾ ಕಾಲ ಗಮನಿಸುತ್ತಲೇ ಇರುತ್ತದೆ. ನೀವು ಪೇಜ್‌ಗೆ ಹೊಸ ಎಲಿಮೆಂಟ್ ಸೇರಿಸಿದರೆ, ಇದು ತಕ್ಷಣವೇ ಅದನ್ನು ತನ್ನ ಲಿಸ್ಟ್‌ಗೆ ಸೇರಿಸಿಕೊಳ್ಳುತ್ತದೆ (Auto-update). 

// CCTV ಕ್ಯಾಮೆರಾ ಆನ್ ಮಾಡೋಣ (Live Collection)
const liveBasket = document.getElementsByClassName('apple');
console.log(liveBasket.length); // ಔಟ್‌ಪುಟ್: 2

// ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಮೂಲಕ ಬುಟ್ಟಿಗೆ ಹೊಸ ಸೇಬು ಸೇರಿಸೋಣ
const newApple = document.createElement('li');
newApple.className = "apple";
newApple.innerText = "ಸೇಬು 3";
document.getElementById('fruit-basket').appendChild(newApple);

// ಈಗ ಮತ್ತೆ ಚೆಕ್ ಮಾಡೋಣ
console.log(liveBasket.length); 
// ಔಟ್‌ಪುಟ್: 3 (ಮ್ಯಾಜಿಕ್! ತಾನಾಗಿಯೇ ಅಪ್‌ಡೇಟ್ ಆಗಿದೆ)

ಸಮಸ್ಯೆ (The forEach problem): ಇದು ಅಪ್ಪಟ ಅರೇ (Array) ಅಲ್ಲ, ಇದೊಂದು "Array-like Object". ಹೀಗಾಗಿ ಹಳೆಯ ಬ್ರೌಸರ್ ನಿಯಮಗಳ ಪ್ರಕಾರ ಇದರಲ್ಲಿ .forEach() ಲೂಪ್ ಅನ್ನು ನೇರವಾಗಿ ಬಳಸಲು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಬಿಡುವುದಿಲ್ಲ. ಬಳಸಿದರೆ TypeError ಬರುತ್ತದೆ.

2. NodeList

STATIC (ಫೋಟೋ ತೆಗೆದಂತೆ)

ನೀವು querySelectorAll ಬಳಸಿದಾಗ ಅದು ಒಂದು ಕ್ಯಾಮೆರಾದಲ್ಲಿ ಫೋಟೋ (Snapshot) ಕ್ಲಿಕ್ ಮಾಡಿದಂತೆ. ಆ ಕ್ಷಣದಲ್ಲಿ ಪೇಜ್‌ನಲ್ಲಿ ಎಷ್ಟಿವೆಯೋ ಅಷ್ಟನ್ನು ಮಾತ್ರ ಹಿಡಿಯುತ್ತದೆ. ಫೋಟೋ ತೆಗೆದ ನಂತರ ನೀವು ಬುಟ್ಟಿಗೆ 100 ಸೇಬುಗಳನ್ನು ಸೇರಿಸಿದರೂ, ಫೋಟೋದಲ್ಲಿರುವ ಸೇಬುಗಳ ಸಂಖ್ಯೆ ಬದಲಾಗುವುದಿಲ್ಲ. 

// ಫೋಟೋ ಕ್ಲಿಕ್ ಮಾಡೋಣ (Static Collection)
const staticBasket = document.querySelectorAll('.apple');
console.log(staticBasket.length); // ಔಟ್‌ಪುಟ್: 2

// ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಮೂಲಕ ಬುಟ್ಟಿಗೆ ಮತ್ತೊಂದು ಸೇಬು ಸೇರಿಸೋಣ
const newApple2 = document.createElement('li');
newApple2.className = "apple";
newApple2.innerText = "ಸೇಬು 4";
document.getElementById('fruit-basket').appendChild(newApple2);

// ಈಗ ಮತ್ತೆ ಚೆಕ್ ಮಾಡೋಣ
console.log(staticBasket.length); 
// ಔಟ್‌ಪುಟ್: 2 (ಎಣಿಕೆ ಅಪ್‌ಡೇಟ್ ಆಗಿಲ್ಲ)

ಲಾಭ (The forEach advantage): ಇದು ಫಿಕ್ಸ್ (Static) ಆಗಿರುವುದರಿಂದ, ಆಧುನಿಕ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಇದರಲ್ಲಿ ನೇರವಾಗಿ .forEach() ಬಳಸಲು ಅನುಮತಿ ನೀಡುತ್ತದೆ. ಇದು ಕೋಡ್ ಬರೆಯಲು ಅತ್ಯಂತ ಸುಲಭ ಮತ್ತು ಸೇಫ್ (ಯಾವುದೇ ಅನಿರೀಕ್ಷಿತ ಅಪ್‌ಡೇಟ್‌ಗಳು ಆಗುವುದಿಲ್ಲ).

ಪ್ರೊಫೆಷನಲ್ ಡೆವಲಪರ್‌ಗಳು ಏನು ಮಾಡುತ್ತಾರೆ?

ಇಂದಿನ ಮಾಡರ್ನ್ ವೆಬ್ ಡೆವಲಪ್ಮೆಂಟ್‌ನಲ್ಲಿ (React, Angular ಅಥವಾ ಶುದ್ಧ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್) ಡೆವಲಪರ್‌ಗಳು ಯಾವಾಗಲೂ querySelectorAll (NodeList) ಅನ್ನೇ ಬಳಸುತ್ತಾರೆ. ಏಕೆಂದರೆ:

  • ಕೋಡ್ ಬರೆಯುವಾಗ ಇದು ಅನಿರೀಕ್ಷಿತವಾಗಿ ಬದಲಾಗುವುದಿಲ್ಲ (No surprise updates).
  • forEach ಬಳಸಲು ಸುಲಭ.
  • CSS ನ ಎಲ್ಲಾ ಸಂಕೀರ್ಣ ಸೆಲೆಕ್ಟರ್‌ಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ.

💡 Pro Tip: HTMLCollection ಗೆ forEach ಬಳಸುವುದು ಹೇಗೆ?

ನಿಮ್ಮ ಬಳಿ HTMLCollection ಇದ್ದು, ಅದಕ್ಕೆ forEach ಬಳಸಲೇಬೇಕು ಎಂದಿದ್ದರೆ, ಅದನ್ನು ಮೊದಲು ಅರೇ (Array) ಆಗಿ ಕನ್ವರ್ಟ್ ಮಾಡಬೇಕು. ಅದಕ್ಕೆ Array.from() ಅಥವಾ Spread Syntax [...] ಬಳಸಬಹುದು:

Spread Operator & Array.from Magic 
const myItems = document.getElementsByClassName('item'); // ಇದು HTMLCollection

// 1. Array.from() ಬಳಸಿ ಕನ್ವರ್ಟ್ ಮಾಡುವುದು:
Array.from(myItems).forEach(item => {
    item.style.fontWeight = "bold";
});

// 2. ಅಥವಾ Spread Syntax ಬಳಸುವುದು (ಇದು ಇತ್ತೀಚಿನ ಟ್ರೆಂಡ್ 🔥):
[...myItems].forEach(item => {
    item.style.border = "1px solid black";
});
