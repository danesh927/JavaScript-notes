ಪರಿವಿಡಿ (Index)

  • 1. ವೇರಿಯೇಬಲ್ ಎಂದರೇನು?
  • 2. ಹೆಸರಿಸುವ ನಿಯಮಗಳು
  • 3. var, let, const ಮಾಹಿತಿ
  • 🏆 4: ಸುವರ್ಣ ನಿಯಮಗಳು

1. ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ವೇರಿಯೇಬಲ್ (Variables) ಎಂದರೇನು?

ವೇರಿಯೇಬಲ್ ಎಂದರೆ ಡೇಟಾ ಅಥವಾ ಮಾಹಿತಿಯನ್ನು ಶೇಖರಿಸಿಡಲು ಕಂಪ್ಯೂಟರ್ ಮೆಮೊರಿಯಲ್ಲಿ (Memory) ರಚಿಸುವ ಒಂದು ಜಾಗ (Container). ಒಂದು ವೇರಿಯೇಬಲ್ 3 ಹಂತಗಳನ್ನು ಹೊಂದಿರುತ್ತದೆ:

  • Declaration (ಘೋಷಣೆ): ಡಬ್ಬಿಯನ್ನು ರೆಡಿ ಮಾಡುವುದು (ಉದಾ: let age;)
  • Initialization (ಪ್ರಾರಂಭಿಸುವಿಕೆ): ಮೆಮೊರಿಯಲ್ಲಿ ಜಾಗ ಕಾಯ್ದಿರಿಸುವುದು.
  • Assignment (ಮೌಲ್ಯ ನಿಯೋಜನೆ): ಡಬ್ಬಿಯೊಳಗೆ ವಸ್ತುವನ್ನು ಹಾಕುವುದು (ಉದಾ: age = 25;)

2. ವೇರಿಯೇಬಲ್ ಹೆಸರಿಸುವ ನಿಯಮಗಳು

  • ಸರಿ: myAge, price_100, $totalAmount
  • ತಪ್ಪು: 1player (ಅಂಕಿಯಿಂದ ಶುರುವಾಗುವಂತಿಲ್ಲ), my first name (Space ಬಿಡುವಂತಿಲ್ಲ).
  • ಕಾಯ್ದಿರಿಸಿದ ಪದಗಳನ್ನು (Reserved Keywords - ಉದಾ: let, function) ಬಳಸುವಂತಿಲ್ಲ.
  • ಕ್ಯಾಮೆಲ್ ಕೇಸ್ (Camel Case) ಬಳಸುವುದು ಉತ್ತಮ ಅಭ್ಯಾಸ (ಉದಾ: userBankAccoutNumber).

3. var, let, ಮತ್ತು const ತಾಂತ್ರಿಕ ಮಾಹಿತಿ

1. Scope (ಮಿತಿ)

var ಕೇವಲ Function Scope ಹೊಂದಿದೆ. ಇದು ಬ್ಲಾಕ್ ({ }) ನಿಂದ ಹೊರಗೆ ಸೋರಿಕೆಯಾಗುತ್ತದೆ. ಆದರೆ let ಮತ್ತು const ಕಟ್ಟುನಿಟ್ಟಾದ Block Scope ಹೊಂದಿವೆ.

2. Hoisting ಮತ್ತು TDZ

var ಮೇಲೇರಿ undefined ಮೌಲ್ಯ ಪಡೆಯುತ್ತದೆ. ಆದರೆ let/const ಮೇಲೇರಿದರೂ ಮೌಲ್ಯ ಕೊಡುವವರೆಗೆ TDZ (Temporal Dead Zone) ನಲ್ಲಿರುತ್ತವೆ, ಮುಟ್ಟಿದರೆ Error ಬರುತ್ತದೆ.

3. const Mutation (ಒಳಗಿನ ಗುಟ್ಟು)

const colors = ["Red", "Green"];
colors.push("Blue"); // ಡಬ್ಬಿಯೊಳಗೆ ಹೊಸ ವಸ್ತು ಹಾಕಬಹುದು (ಸರಿ)
// colors = ["Yellow"]; // ❌ ತಪ್ಪು (ಇಡೀ ಡಬ್ಬಿಯನ್ನು ಮರುಹೊಂದಿಸುವಂತಿಲ್ಲ)

4. Variable Shadowing

ಬ್ಲಾಕ್ ಒಳಗಿನ ವೇರಿಯೇಬಲ್, ಹೊರಗಿನ ಅದೇ ಹೆಸರಿನ ವೇರಿಯೇಬಲ್ ಅನ್ನು ಮರೆಮಾಡುತ್ತದೆ. (Legal Shadowing).

4. ವೃತ್ತಿಪರರ ಸುವರ್ಣ ನಿಯಮಗಳು

  1. 🥇 ಯಾವಾಗಲೂ const ಬಳಸಿ: ಮೌಲ್ಯ ಬದಲಾಗದಿದ್ದರೆ ನಿಮ್ಮ ಮೊದಲ ಆಯ್ಕೆ ಇದೇ ಆಗಿರಲಿ.
  2. 🥈 ಅನಿವಾರ್ಯವಿದ್ದರೆ let ಬಳಸಿ: ಫಾರ್ ಲೂಪ್, ಸ್ಕೋರ್‌ನಂತಹ ಬದಲಾಗುವ ಮೌಲ್ಯಗಳಿಗೆ.
  3. 🚫 var ಬಳಸಬೇಡಿ: ಆಧುನಿಕ ಡೆವಲಪ್ಮೆಂಟ್‌ನಲ್ಲಿ var ಬಳಕೆಯನ್ನು ಕೈಬಿಡಲಾಗಿದೆ.
