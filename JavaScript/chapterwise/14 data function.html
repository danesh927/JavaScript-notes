JavaScript Date Object (ದಿನಾಂಕ)

ಶೂನ್ಯದಿಂದ ವೃತ್ತಿಪರ ಹಂತದವರೆಗೆ (Beginner to Pro) ಸಂಪೂರ್ಣ ಕೈಪಿಡಿ.

Concept ಎಂದರೇನು? (Definition)

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ Date Object ಎಂದರೆ ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನ "ಡಿಜಿಟಲ್ ಗಡಿಯಾರ ಮತ್ತು ಕ್ಯಾಲೆಂಡರ್" ಇದ್ದಂತೆ. ವರ್ಷ, ತಿಂಗಳು, ದಿನ, ಗಂಟೆ, ನಿಮಿಷ ಮತ್ತು ಸೆಕೆಂಡ್‌ಗಳನ್ನು ಪಡೆಯಲು, ಲೆಕ್ಕಾಚಾರ ಮಾಡಲು (ಉದಾ: ವಯಸ್ಸು ಕಂಡುಹಿಡಿಯಲು) ಮತ್ತು ಬದಲಾಯಿಸಲು ಇದನ್ನು ಬಳಸಲಾಗುತ್ತದೆ.

ಏಕೆ ಬೇಕು? (Why do we need it?)

ಬಳಕೆದಾರರು ಯಾವಾಗ ಪೋಸ್ಟ್ ಮಾಡಿದರು? ಆಫರ್ ಎಷ್ಟು ಗಂಟೆಗೆ ಮುಗಿಯುತ್ತದೆ? ಇಂದು ಯಾವ ವಾರ? ಇಂತಹ ಎಲ್ಲಾ ಸಮಯ-ಆಧಾರಿತ ಲೆಕ್ಕಾಚಾರಗಳನ್ನು ಮಾಡಲು Date ಆಬ್ಜೆಕ್ಟ್ ಅನಿವಾರ್ಯ.

ನೈಜ ಜೀವನದ ಉದಾಹರಣೆ (Live Example)

Date ಆಬ್ಜೆಕ್ಟ್ ಅನ್ನು ಬಳಸಿ ಮಾಡಲಾದ ಲೈವ್ ಡಿಜಿಟಲ್ ಗಡಿಯಾರವನ್ನು ಇಲ್ಲಿ ನೋಡಿ. ಇದು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್/ಮೊಬೈಲ್‌ನ ಪ್ರಸ್ತುತ ಸಮಯವನ್ನು ಓದುತ್ತಿದೆ.

ಈಗಿನ ಸಮಯ (Live Clock)

00:00:00
ದಿನಾಂಕ ಲೋಡ್ ಆಗುತ್ತಿದೆ...

new Date() ಬಳಸಿ ಈ ಗಡಿಯಾರವನ್ನು ಮಾಡಲಾಗಿದೆ.

Date ಸೃಷ್ಟಿಸುವ 4 ವಿಧಾನಗಳು (4 Ways to Create)

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ದಿನಾಂಕವನ್ನು ಸೃಷ್ಟಿಸಲು ನಾವು new Date() ಕೀವರ್ಡ್ ಬಳಸುತ್ತೇವೆ. ಇದನ್ನು 4 ವಿಭಿನ್ನ ರೀತಿಯಲ್ಲಿ ಬಳಸಬಹುದು.

JavaScript - Creating Dates 
// 1. ಪ್ರಸ್ತುತ ಸಮಯ (Current Time) - ಆವರಣ ಖಾಲಿ ಬಿಟ್ಟರೆ ಈಗಿನ ಸಮಯ ಬರುತ್ತದೆ
let now = new Date(); 
console.log(now);

// 2. ನಿರ್ದಿಷ್ಟ ಸಂಖ್ಯೆಗಳು (Year, Month, Day, Hours, Min, Sec, ms)
// ಗಮನಿಸಿ: ಇಲ್ಲಿ 11 ಎಂದರೆ ಡಿಸೆಂಬರ್! (ತಿಂಗಳು 0 ಯಿಂದ ಶುರು)
let customDate = new Date(2026, 11, 25, 10, 30, 0);

// 3. Date String (ಟೆಕ್ಸ್ಟ್ ಮೂಲಕ) - ಇದು ಓದಲು ಸುಲಭ
let stringDate = new Date("October 17, 2026 10:30:00");

// 4. Milliseconds (ಮಿಲಿಸೆಕೆಂಡ್‌ಗಳು - 1970 ಜನವರಿ 1 ರಿಂದ)
let epochDate = new Date(100000000000);

🚨 ಅತಿ ದೊಡ್ಡ ಎಚ್ಚರಿಕೆ (The 0-Index Trap)

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ತಿಂಗಳುಗಳು (Months) 0 ಯಿಂದ ಶುರುವಾಗುತ್ತವೆ!

  • 0 = ಜನವರಿ (January)
  • 1 = ಫೆಬ್ರವರಿ (February)
  • ...
  • 11 = ಡಿಸೆಂಬರ್ (December)

ನೀವು new Date(2026, 3, 10) ಎಂದು ಬರೆದರೆ, ಅದು ಮಾರ್ಚ್ ಅಲ್ಲ, ಏಪ್ರಿಲ್ 10 ಆಗಿರುತ್ತದೆ! ಬಹುತೇಕ ಎಲ್ಲಾ Beginners ಮಾಡುವ ಅತಿ ದೊಡ್ಡ ತಪ್ಪು ಇದು.

ಸಮಯ ಪಡೆಯುವುದು (Getters Methods)

ಸೃಷ್ಟಿಸಿದ Date ಇಂದ ಕೇವಲ ವರ್ಷ ಅಥವಾ ಕೇವಲ ದಿನವನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ಪಡೆಯಲು get ವಿಧಾನಗಳನ್ನು ಬಳಸುತ್ತೇವೆ.

JavaScript - Getter Methods 
let d = new Date("2026-10-17");

let year = d.getFullYear(); // 2026 (ಯಾವಾಗಲೂ getFullYear ಬಳಸಿ, getYear ಅಲ್ಲ!)
let month = d.getMonth();   // 9 (ಅಂದರೆ 10ನೇ ತಿಂಗಳು ಅಕ್ಟೋಬರ್)
let date = d.getDate();     // 17 (ತಾರೀಖು)
let day = d.getDay();       // 6 (ವಾರದ ದಿನ: ಭಾನುವಾರ = 0, ಸೋಮವಾರ = 1... ಶನಿವಾರ = 6)

console.log("ವರ್ಷ: " + year); // 2026

ಸಮಯ ಬದಲಾಯಿಸುವುದು (Setters Methods)

ಇರುವ ದಿನಾಂಕವನ್ನು ಬದಲಾಯಿಸಲು set ವಿಧಾನಗಳನ್ನು ಬಳಸುತ್ತೇವೆ.

JavaScript - Setter Methods 
let myDate = new Date();
console.log("ಹಳೆಯ ವರ್ಷ: " + myDate.getFullYear());

// ವರ್ಷವನ್ನು 2030 ಕ್ಕೆ ಬದಲಾಯಿಸೋಣ
myDate.setFullYear(2030);

// ತಿಂಗಳನ್ನು ಮಾರ್ಚ್ (2) ಕ್ಕೆ ಬದಲಾಯಿಸೋಣ
myDate.setMonth(2); 

console.log("ಹೊಸ ವರ್ಷ: " + myDate.getFullYear()); // 2030

ಸುಂದರ ವಿನ್ಯಾಸ (Formatting Methods - Pro Level)

ಗ್ರಾಹಕರಿಗೆ ದಿನಾಂಕವನ್ನು ಸುಂದರವಾಗಿ ತೋರಿಸಲು toLocaleDateString() ಅನ್ನು ಬಳಸಲಾಗುತ್ತದೆ. ಇದನ್ನು ನಾವು ಕನ್ನಡದಲ್ಲಿಯೂ ತೋರಿಸಬಹುದು!

JavaScript - Formatting 
let today = new Date();

// 1. ಸಾಮಾನ್ಯ ಓದುವಿಕೆ (Standard local format)
console.log(today.toLocaleDateString()); // ಉದಾ: 17/10/2026

// 2. ವೃತ್ತಿಪರ ಕಸ್ಟಮ್ ವಿನ್ಯಾಸ (Pro Custom format)
let options = { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' };
console.log(today.toLocaleDateString('kn-IN', options)); 
// ಔಟ್‌ಪುಟ್: ಶನಿವಾರ, 17 ಅಕ್ಟೋಬರ್, 2026

// 3. ಡೇಟಾಬೇಸ್ ವಿನ್ಯಾಸ (ISO format for Servers)
console.log(today.toISOString()); // 2026-10-17T08:09:00.000Z
