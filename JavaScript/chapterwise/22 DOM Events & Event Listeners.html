Interactive Web Secrets

DOM Events & Event Listeners

DOM ನಲ್ಲಿ Event Listener ಮತ್ತು Event Object ಗಳು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನ ಹೃದಯವಿದ್ದಂತೆ. ವೆಬ್‌ಪುಟವನ್ನು ಬಳಕೆದಾರರೊಂದಿಗೆ ಸಂವಹನ ನಡೆಸುವಂತೆ (Interactive) ಮಾಡಲು ಇವು ಅತ್ಯಗತ್ಯ.

ಯಾವುದೇ ಮಾಹಿತಿಯನ್ನು ಬಿಡದೆ, Beginner (ಆರಂಭಿಕ) ಹಂತದಿಂದ Pro (ತಜ್ಞ) ಹಂತದವರೆಗೆ ಪ್ರತಿಯೊಂದನ್ನೂ ಆಳವಾಗಿ ಉದಾಹರಣೆಗಳೊಂದಿಗೆ ಇಲ್ಲಿ ವಿವರಿಸಲಾಗಿದೆ.

Level 1

Event ಮತ್ತು Event Listener ಎಂದರೇನು?

Event (ಈವೆಂಟ್)

ವೆಬ್‌ಪುಟದಲ್ಲಿ ನಡೆಯುವ ಯಾವುದೇ ಕ್ರಿಯೆ. ಉದಾಹರಣೆಗೆ: ಮೌಸ್ ಕ್ಲಿಕ್ ಮಾಡುವುದು (click), ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ ಟೈಪ್ ಮಾಡುವುದು (keyup), ಸ್ಕ್ರಾಲ್ ಮಾಡುವುದು (scroll).

Event Listener

ಇದು ಒಂದು "ಕಾವಲುಗಾರ" (Watchman) ಇದ್ದಂತೆ. ನಿರ್ದಿಷ್ಟ ಎಲಿಮೆಂಟ್ ಮೇಲೆ ಆ ಕ್ರಿಯೆ ನಡೆಯುವವರೆಗೂ ಕಾಯುತ್ತಿರುತ್ತದೆ. ಕ್ರಿಯೆ ನಡೆದ ತಕ್ಷಣ ನೀವು ಹೇಳಿದ ಕೆಲಸವನ್ನು (Function) ಮಾಡುತ್ತದೆ.

ಎಲಿಮೆಂಟ್‌ಗೆ Event ಸೇರಿಸುವ 3 ವಿಧಾನಗಳು:

1. ಹಳೆಯ ವಿಧಾನ (Inline Events - ಬಳಸಬಾರದು):

HTML ಒಳಗೇ ಬರೆಯುವುದು.

<button onclick="alert('ಕ್ಲಿಕ್ ಆಯ್ತು!')">ಕ್ಲಿಕ್ ಮಾಡಿ</button>

2. DOM Property ವಿಧಾನ (ಒಂದು ಲಿಮಿಟ್ ಇದೆ):

const btn = document.getElementById("myBtn");
btn.onclick = function() {
  console.log("ಮೊದಲನೇ ಕ್ಲಿಕ್");
};
ಸಮಸ್ಯೆ: ನೀವು ಇನ್ನೊಂದು onclick ಬರೆದರೆ ಹಳೆಯದು ಅಳಿಸಿಹೋಗುತ್ತದೆ!

3. addEventListener ಆಧುನಿಕ ಮತ್ತು ಸರಿಯಾದ ವಿಧಾನ

ಇದು ಅತ್ಯುತ್ತಮ ವಿಧಾನ. ಒಂದೇ ಎಲಿಮೆಂಟ್‌ಗೆ ಎಷ್ಟೇ ಈವೆಂಟ್‌ಗಳನ್ನು ಬೇಕಾದರೂ ಸೇರಿಸಬಹುದು.
ರಚನೆ: element.addEventListener(ಈವೆಂಟ್_ಹೆಸರು, ಮಾಡಬೇಕಾದ_ಫಂಕ್ಷನ್)

const btn = document.getElementById("myBtn");

// 'click' ಆದಾಗ ಏನು ಮಾಡಬೇಕು ಎಂದು ಹೇಳುತ್ತಿದ್ದೇವೆ
btn.addEventListener("click", function() {
  console.log("ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಲಾಗಿದೆ!");
});
Level 2

Event Object (e ಅಥವಾ event)

ನೀವು ಯಾವುದೇ Event Listener ಬರೆದಾಗ, ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಆ ಫಂಕ್ಷನ್‌ಗೆ ಒಂದು ಉಡುಗೊರೆಯನ್ನು (Object) ಕಳುಹಿಸುತ್ತದೆ. ಅದನ್ನೇ Event Object ಎನ್ನುತ್ತಾರೆ. ಅದರಲ್ಲಿ ಆ ಕ್ರಿಯೆಯ ಬಗ್ಗೆ ಎಲ್ಲಾ ಮಾಹಿತಿಯೂ ಇರುತ್ತದೆ (ಯಾರು ಕ್ಲಿಕ್ ಮಾಡಿದರು, ಎಲ್ಲಿ ಕ್ಲಿಕ್ ಮಾಡಿದರು, ಯಾವ ಕೀ ಒತ್ತಿದರು ಇತ್ಯಾದಿ). ಸಾಮಾನ್ಯವಾಗಿ ಇದನ್ನು e ಅಥವಾ event ಎಂಬ ಹೆಸರಿನಿಂದ ಸ್ವೀಕರಿಸುತ್ತಾರೆ. 

const box = document.getElementById("box");

box.addEventListener("click", function(e) {
  console.log(e); // ಇದು ಸಂಪೂರ್ಣ Event Object ಅನ್ನು ಪ್ರಿಂಟ್ ಮಾಡುತ್ತದೆ
});

Event Object ನ ಪ್ರಮುಖ ಪ್ರಾಪರ್ಟಿಗಳು:

e.type

ಯಾವ ರೀತಿಯ ಈವೆಂಟ್ ನಡೆಯಿತು? (ಉದಾ: "click", "keydown").

e.target (ಬಹಳ ಮುಖ್ಯ)

ನಿಖರವಾಗಿ ಯಾವ ಎಲಿಮೆಂಟ್ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಲಾಯಿತು?

e.clientX / e.clientY

ಸ್ಕ್ರೀನ್ ಮೇಲೆ ಮೌಸ್ ಕ್ಲಿಕ್ ಆದ ನಿಖರವಾದ X ಮತ್ತು Y ಜಾಗ (Coordinates).

e.key

ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ ಯಾವ ಕೀ ಒತ್ತಲಾಗಿದೆ? (ಉದಾ: "Enter", "A").

ಉದಾಹರಣೆ
const inputField = document.getElementById("nameInput");

inputField.addEventListener("keyup", function(e) {
  console.log("ನೀವು ಒತ್ತಿದ ಕೀ: " + e.key);
});
Level 3

Default Behavior ತಡೆಯುವುದು ಮತ್ತು Bubbling

ಇಲ್ಲಿಂದ ವೃತ್ತಿಪರ ಕಾನ್ಸೆಪ್ಟ್‌ಗಳು ಶುರುವಾಗುತ್ತವೆ.

A. e.preventDefault() (ಡೀಫಾಲ್ಟ್ ಕೆಲಸವನ್ನು ತಡೆಯುವುದು)

ಕೆಲವು HTML ಎಲಿಮೆಂಟ್‌ಗಳಿಗೆ ಹುಟ್ಟಿನಿಂದಲೇ ಕೆಲವು ಗುಣಗಳಿರುತ್ತವೆ. ಉದಾಹರಣೆಗೆ, <a> ಲಿಂಕ್ ಕ್ಲಿಕ್ ಮಾಡಿದರೆ ಬೇರೆ ಪೇಜ್‌ಗೆ ಹೋಗುವುದು, <form> ಸಬ್ಮಿಟ್ ಮಾಡಿದರೆ ಪೇಜ್ ರಿಫ್ರೆಶ್ ಆಗುವುದು. ಇದನ್ನು ತಡೆಯಲು preventDefault() ಬಳಸುತ್ತಾರೆ. 

const myForm = document.getElementById("loginForm");

myForm.addEventListener("submit", function(e) {
  e.preventDefault(); // ಪೇಜ್ ರಿಫ್ರೆಶ್ ಆಗುವುದನ್ನು ತಡೆಯುತ್ತದೆ!
  console.log("ಫಾರ್ಮ್ ಡೇಟಾವನ್ನು ಈಗ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಮೂಲಕ ಕಳುಹಿಸಬಹುದು.");
});

B. Event Propagation (Event Bubbling)

DOM ನಲ್ಲಿ ಒಂದು ನಿಯಮವಿದೆ: ನೀವು ಒಂದು ಮಗುವಿನ (Child) ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿದರೆ, ಆ ಕ್ಲಿಕ್ ಅದರ ತಂದೆಗೂ (Parent), ಅಜ್ಜನಿಗೂ (Grandparent) ಮತ್ತು ಕೊನೆಗೆ document ಗೂ ತಲುಪುತ್ತದೆ. ಇದು ನೀರಿನಲ್ಲಿ ಗುಳ್ಳೆಗಳು ಮೇಲಕ್ಕೆ ಬರುವಂತೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಇದನ್ನೇ Event Bubbling ಎನ್ನುತ್ತಾರೆ.

Visual Concept
#parent 
<div id="parent" style="padding: 50px; background: red;">
  <button id="child">ಕ್ಲಿಕ್ ಮಾಡಿ</button>
</div>
document.getElementById("parent").addEventListener("click", () => console.log("Parent ಕ್ಲಿಕ್ ಆಯ್ತು!"));
document.getElementById("child").addEventListener("click", () => console.log("Child ಕ್ಲಿಕ್ ಆಯ್ತು!"));

// Child ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ಔಟ್‌ಪುಟ್:
// 1. Child ಕ್ಲಿಕ್ ಆಯ್ತು!
// 2. Parent ಕ್ಲಿಕ್ ಆಯ್ತು! (ಇದೇ Bubbling)

C. e.stopPropagation() (ಬಬ್ಲಿಂಗ್ ಅನ್ನು ನಿಲ್ಲಿಸುವುದು)

ಮಗುವಿನ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ಅದು ಪೇರೆಂಟ್‌ಗೆ ಹೋಗಬಾರದು ಎಂದರೆ ಇದನ್ನು ಬಳಸಬೇಕು.

document.getElementById("child").addEventListener("click", function(e) {
  e.stopPropagation(); // ಇಲ್ಲಿಗೆ ಗುಳ್ಳೆ ಒಡೆಯುತ್ತದೆ, ಮೇಲಕ್ಕೆ ಹೋಗುವುದಿಲ್ಲ!
  console.log("ಕೇವಲ Child ಮಾತ್ರ ಕ್ಲಿಕ್ ಆಯ್ತು.");
});
Expert Level

Event Delegation ಮತ್ತು Options

ವೃತ್ತಿಪರ ಡೆವಲಪರ್‌ಗಳು ಕೋಡ್ ಅನ್ನು ಅತ್ಯಂತ ವೇಗವಾಗಿ (Optimized) ಕೆಲಸ ಮಾಡುವಂತೆ ಬರೆಯುತ್ತಾರೆ.

A. Event Delegation The Master Technique

ನಿಮ್ಮ ಬಳಿ 1000 <li> ಐಟಂಗಳಿವೆ. ಪ್ರತಿಯೊಂದಕ್ಕೂ 1000 addEventListener ಹಾಕಿದರೆ ಬ್ರೌಸರ್ ಹ್ಯಾಂಗ್ ಆಗುತ್ತದೆ.
ಇದಕ್ಕೆ ಪರಿಹಾರ: Event Bubbling ಅನ್ನು ನಮಗೆ ಬೇಕಾದಂತೆ ಬಳಸಿಕೊಳ್ಳುವುದು. ಕೇವಲ ಒಂದು ಲಿಸನರ್ ಅನ್ನು ಪೇರೆಂಟ್‌ಗೆ <ul> ಹಾಕುವುದು! 

<ul id="myList">
  <li>ಐಟಂ 1</li>
  <li>ಐಟಂ 2</li>
  <li>ಐಟಂ 3</li>
</ul>

ಲಾಭ:

ಮೆಮೊರಿ ಉಳಿತಾಯವಾಗುತ್ತದೆ ಮತ್ತು ಹೊಸ <li> ಗಳನ್ನು ಸೇರಿಸಿದರೂ ಈ ಕೋಡ್ ಕೆಲಸ ಮಾಡುತ್ತದೆ!

e.target: ನಿಖರವಾಗಿ ಕ್ಲಿಕ್ ಆದ ಮಗು (ಉದಾ: li).
e.currentTarget: ನಾವು ಲಿಸನರ್ ಹಾಕಿದ ಪೇರೆಂಟ್ (ಉದಾ: ul). 

const list = document.getElementById("myList");

// ನಾವು <li> ಬದಲಾಗಿ <ul> ಗೆ ಲಿಸನರ್ ಹಾಕುತ್ತಿದ್ದೇವೆ!
list.addEventListener("click", function(e) {

  // e.target ಎಂದರೆ ನಿಖರವಾಗಿ ಎಲ್ಲಿ ಕ್ಲಿಕ್ ಆಗಿದೆ
  if (e.target.tagName === "LI") {
    console.log("ನೀವು ಕ್ಲಿಕ್ ಮಾಡಿದ್ದು: " + e.target.textContent);
    e.target.style.backgroundColor = "yellow";
  }
});

B. Event Listener Options (ಮೂರನೇ ಪ್ಯಾರಾಮೀಟರ್)

addEventListener ಕೇವಲ 2 ಅಲ್ಲ, 3 ಪ್ಯಾರಾಮೀಟರ್‌ಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳಬಲ್ಲದು.

  • { once: true }: ಕೇವಲ ಒಮ್ಮೆ ಮಾತ್ರ ಕೆಲಸ ಮಾಡಬೇಕು. ಎರಡನೇ ಬಾರಿ ಕ್ಲಿಕ್ ಮಾಡಿದರೆ ಕೆಲಸ ಮಾಡುವುದಿಲ್ಲ.
  • { capture: true }: Event ಬಬ್ಲಿಂಗ್ (ಕೆಳಗಿನಿಂದ ಮೇಲೆ) ಆಗುವ ಬದಲು, ಮೇಲಿನಿಂದ ಕೆಳಗೆ (Trickling/Capturing) ಬರಲು ಬಳಸುತ್ತಾರೆ.
const myButton = document.getElementById("oneTimeBtn");

myButton.addEventListener("click", function() {
  console.log("ನಾನು ಕೇವಲ ಒಮ್ಮೆ ಮಾತ್ರ ರನ್ ಆಗುತ್ತೇನೆ!");
}, { once: true }); // ಈ ಸೆಟ್ಟಿಂಗ್ Pro ಲೆವೆಲ್ ನದ್ದು!

C. Memory Leaks ತಡೆಯುವುದು (removeEventListener)

ನೀವು ಡಿಲೀಟ್ ಮಾಡುವ ಎಲಿಮೆಂಟ್‌ಗಳಿಗೆ ಈವೆಂಟ್ ಅನ್ನು ತೆಗೆಯದಿದ್ದರೆ ಮೆಮೊರಿ ಲೀಕ್ ಆಗುತ್ತದೆ. ಆನಾಮಧೇಯ (Anonymous / Arrow) ಫಂಕ್ಷನ್‌ಗಳನ್ನು ರಿಮೂವ್ ಮಾಡಲು ಸಾಧ್ಯವಿಲ್ಲ. ಯಾವಾಗಲೂ ಹೆಸರಿರುವ ಫಂಕ್ಷನ್ (Named Function) ಬಳಸಿ. 

const btn = document.getElementById("saveBtn");

// 1. ಹೆಸರಿರುವ ಫಂಕ್ಷನ್ (Named Function)
function saveData(e) {
  console.log("ಡೇಟಾ ಸೇವ್ ಆಯ್ತು!");
}

btn.addEventListener("click", saveData);

// 2. ಕೆಲಸ ಮುಗಿದ ಮೇಲೆ ಈವೆಂಟ್ ಅನ್ನು ತೆಗೆಯುವುದು
btn.removeEventListener("click", saveData);
