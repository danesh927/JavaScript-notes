1. JavaScript (ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್) ಎಂದರೇನು?

ಇದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ನಾವು ಒಂದು ಮಾನವನ ದೇಹದ ಉದಾಹರಣೆ ತೆಗೆದುಕೊಳ್ಳೋಣ:

  • HTML (ಮೂಳೆಗಳು): ಇದು ವೆಬ್‌ಸೈಟ್‌ಗೆ ಒಂದು ಆಕಾರ ಮತ್ತು ರಚನೆಯನ್ನು (Structure) ಕೊಡುತ್ತದೆ. (ಉದಾಹರಣೆಗೆ: ಪಠ್ಯ, ಚಿತ್ರಗಳನ್ನು ಹಾಕುವುದು).
  • CSS (ಚರ್ಮ ಮತ್ತು ಬಟ್ಟೆ): ಇದು ವೆಬ್‌ಸೈಟ್ ಸುಂದರವಾಗಿ ಕಾಣುವಂತೆ ಮಾಡುತ್ತದೆ. (ಬಣ್ಣ, ವಿನ್ಯಾಸ).
  • JavaScript (ಮೆದುಳು ಮತ್ತು ಸ್ನಾಯುಗಳು): ಇದು ವೆಬ್‌ಸೈಟ್‌‌ಗೆ ಜೀವ ತುಂಬುತ್ತದೆ! ಮನುಷ್ಯ ಹೇಗೆ ನಡೆಯುತ್ತಾನೆ, ಮಾತನಾಡುತ್ತಾನೆ ಅದೇ ರೀತಿ ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿರುವ ಒಂದು ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ಏನಾಗಬೇಕು, ಅನಿಮೇಷನ್ ಹೇಗೆ ಬರಬೇಕು ಎಂಬುದನ್ನು JavaScript ನಿರ್ಧರಿಸುತ್ತದೆ.

ಸರಳವಾಗಿ ಹೇಳಬೇಕೆಂದರೆ, ವೆಬ್‌ಸೈಟ್ ಅನ್ನು ಇಂಟರಾಕ್ಟಿವ್ (ಜನರ ಜೊತೆ ಸಂವಹನ ನಡೆಸುವಂತೆ) ಮಾಡುವ ಒಂದು ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಭಾಷೆಯೇ JavaScript.

ಚಿತ್ರ 1: ಮಾನವನ ದೇಹಕ್ಕೆ HTML, CSS ಮತ್ತು JavaScript ಹೋಲಿಕೆ

2. ಅದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ?

ನೀವು ಬ್ರೌಸರ್‌ನಲ್ಲಿ (Chrome, Firefox) ಒಂದು ವೆಬ್‌ಸೈಟ್ ತೆರೆದಾಗ, JavaScript ಹೀಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ:

  • ಡೌನ್‌ಲೋಡ್: ಮೊದಲು ಇಂಟರ್ನೆಟ್‌ನಿಂದ HTML, CSS ಜೊತೆಗೆ JavaScript ಕೋಡ್ ನಿಮ್ಮ ಬ್ರೌಸರ್‌ಗೆ ಬರುತ್ತದೆ.
  • ಓದುವುದು (Parsing): ಬ್ರೌಸರ್‌ನಲ್ಲಿರುವ ಒಂದು 'ಎಂಜಿನ್' ಆ ಕೋಡ್ ಅನ್ನು ಓದುತ್ತದೆ.
  • ಅನುವಾದ (Compilation): ಕಂಪ್ಯೂಟರ್‌ಗೆ ಇಂಗ್ಲಿಷ್ ಅರ್ಥವಾಗುವುದಿಲ್ಲ, ಅದಕ್ಕೆ ಕೇವಲ 0 ಮತ್ತು 1 (ಮಷಿನ್ ಭಾಷೆ) ಮಾತ್ರ ಅರ್ಥವಾಗುತ್ತದೆ. ಎಂಜಿನ್ ನಮ್ಮ ಕೋಡ್ ಅನ್ನು ಮಷಿನ್ ಭಾಷೆಗೆ ಕ್ಷಣಾರ್ಧದಲ್ಲಿ ಬದಲಾಯಿಸುತ್ತದೆ.
  • ಕಾರ್ಯಾಚರಣೆ (Execution): ತಕ್ಷಣವೇ ಆ ಕೋಡ್ ರನ್ ಆಗಿ, ನೀವು ಬಟನ್ ಒತ್ತಿದಾಗ ಪೇಜ್ ರಿಫ್ರೆಶ್ ಆಗದೆ ಹೊಸ ಮಾಹಿತಿ ಬರುವಂತೆ ಮಾಡುತ್ತದೆ.
ಚಿತ್ರ 2: ಬ್ರೌಸರ್‌ನಲ್ಲಿ JavaScript ಕೋಡ್ ರನ್ ಆಗುವ 4 ಹಂತಗಳು

3. ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಬಳಸುವ JavaScript ಎಂಜಿನ್ ಯಾವುದು?

ಪ್ರತಿಯೊಂದು ಬ್ರೌಸರ್‌ಗೂ ಅದರದ್ದೇ ಆದ ಒಂದು "ಮೆದುಳು" ಇರುತ್ತದೆ. ಅದನ್ನೇ ನಾವು JavaScript Engine ಎನ್ನುತ್ತೇವೆ. ಇದು ಕೋಡ್ ಅನ್ನು ಓದಿ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುತ್ತದೆ.

ಬ್ರೌಸರ್ (Browser) ಎಂಜಿನ್ ಹೆಸರು (Engine Name) ವಿಶೇಷತೆ
Google Chrome V8 Engine ಪ್ರಪಂಚದಲ್ಲೇ ಅತಿ ವೇಗವಾದ ಎಂಜಿನ್. (ಇದನ್ನು ಬಳಸಿ Node.js ಅನ್ನು ಕೂಡ ಮಾಡಲಾಗಿದೆ).
Mozilla Firefox SpiderMonkey ಇದು ಜಗತ್ತಿನ ಮೊಟ್ಟಮೊದಲ JavaScript ಎಂಜಿನ್.
Apple Safari JavaScriptCore ಆಪಲ್ ಸಾಧನಗಳಲ್ಲಿ (Mac, iPhone) ಇದು ಕೆಲಸ ಮಾಡುತ್ತದೆ.
ಚಿತ್ರ 3: ಪ್ರಮುಖ ಬ್ರೌಸರ್‌‌ಗಳು ಮತ್ತು ಅವುಗಳ JavaScript ಎಂಜಿನ್‌ಗಳು

4. ಇದಕ್ಕೆ ಬೇಕಾಗುವ Tools ಮತ್ತು Extensions ಯಾವುವು?

JavaScript ಕಲಿಯಲು ಅಥವಾ ಪ್ರೊಫೆಷನಲ್ ಆಗಿ ಕೆಲಸ ಮಾಡಲು ನಿಮಗೆ ದುಬಾರಿ ಸಾಫ್ಟ್‌ವೇರ್ ಬೇಕಾಗಿಲ್ಲ. ಕೇವಲ ಎರಡು ಪ್ರಮುಖ ಟೂಲ್‌ಗಳು ಸಾಕು:

1. ವೆಬ್ ಬ್ರೌಸರ್ (Web Browser):

ಕೋಡ್ ರನ್ ಮಾಡಿ ನೋಡಲು Google Chrome ಅತ್ಯುತ್ತಮವಾಗಿದೆ. ಇದರಲ್ಲಿರುವ 'Developer Tools' (F12 ಒತ್ತಿದರೆ ಬರುತ್ತದೆ) ಕೋಡ್‌ನಲ್ಲಿರುವ ತಪ್ಪುಗಳನ್ನು ಹುಡುಕಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

2. ಕೋಡ್ ಎಡಿಟರ್ (Code Editor):

ಕೋಡ್ ಬರೆಯಲು ಇರುವ ಅತ್ಯಂತ ಜನಪ್ರಿಯ ಮತ್ತು ಉಚಿತ ಸಾಫ್ಟ್‌ವೇರ್ ಎಂದರೆ VS Code (Visual Studio Code).

VS Code ನಲ್ಲಿ ಬೇಕಾಗುವ ಪ್ರಮುಖ Extensions (ಎಕ್ಸ್‌ಟೆನ್ಶನ್‌ಗಳು):

  • Live Server: ನೀವು ಕೋಡ್ ಬರೆದು ಸೇವ್ ಮಾಡಿದ ತಕ್ಷಣ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಆಟೋಮ್ಯಾಟಿಕ್ ಆಗಿ ಬದಲಾವಣೆಗಳನ್ನು ತೋರಿಸುತ್ತದೆ (ಪೇಜ್ ರಿಫ್ರೆಶ್ ಮಾಡುವ ಅಗತ್ಯವಿಲ್ಲ).
  • Prettier - Code formatter: ನೀವು ಬರೆದ ಕೋಡ್ ಅನ್ನು ಸುಂದರವಾಗಿ, ಓದಲು ಸುಲಭವಾಗುವಂತೆ ಜೋಡಿಸುತ್ತದೆ.
  • JavaScript (ES6) code snippets: ಕೋಡ್ ಅನ್ನು ವೇಗವಾಗಿ ಟೈಪ್ ಮಾಡಲು ಶಾರ್ಟ್‌ಕಟ್‌ಗಳನ್ನು ನೀಡುತ್ತದೆ.
ಚಿತ್ರ 4: JavaScript ಕೋಡಿಂಗ್‌ಗೆ ಬೇಕಾಗುವ ಬ್ರೌಸರ್ ಮತ್ತು VS Code ಎಕ್ಸ್‌ಟೆನ್ಶನ್‌ಗಳು

5. ES6 ಎಂದರೇನು?

ನಿಮ್ಮ ಮೊಬೈಲ್‌ನಲ್ಲಿ ಸಾಫ್ಟ್‌‌ವೇರ್ ಅಪ್‌ಡೇಟ್ (ಉದಾಹರಣೆಗೆ Android 13 ರಿಂದ Android 14) ಬರುವಂತೆ, JavaScript ಭಾಷೆಗೂ ಅಪ್‌ಡೇಟ್‌ಗಳು ಬರುತ್ತವೆ.

ES6 (ECMAScript 2015) ಎನ್ನುವುದು JavaScript ನ 2015 ರ ಅತಿ ದೊಡ್ಡ ಅಪ್‌ಡೇಟ್.

ಇದಕ್ಕೂ ಮುನ್ನ ಕೋಡ್ ಬರೆಯುವುದು ಸ್ವಲ್ಪ ಕಷ್ಟವಿತ್ತು. ES6 ಬಂದ ಮೇಲೆ ಕೋಡ್ ಬರೆಯುವುದು ತುಂಬಾ ಸುಲಭವಾಯಿತು. ಇದರಲ್ಲಿ ಹೊಸ ಫೀಚರ್‌ಗಳನ್ನು ಪರಿಚಯಿಸಲಾಯಿತು:

  • ವೇರಿಯೇಬಲ್ (Variables) ಮಾಡಲು var ಬದಲಿಗೆ ಹೊಸದಾಗಿ let ಮತ್ತು const ತರಲಾಯಿತು.
  • ಫಂಕ್ಷನ್‌ಗಳನ್ನು (Functions) ಚಿಕ್ಕದಾಗಿ ಬರೆಯಲು Arrow Functions (=>) ತರಲಾಯಿತು.
ಚಿತ್ರ 5: ES6 (ECMAScript 2015) ತಂದ ಪ್ರಮುಖ ಬದಲಾವಣೆಗಳು

6. HTML ಗೆ ಯಾವ ರೀತಿ JavaScript Connect ಮಾಡುವುದು?

JavaScript ಅನ್ನು HTML ಜೊತೆ ಸೇರಿಸಲು ಮುಖ್ಯವಾಗಿ 3 ವಿಧಾನಗಳಿವೆ. ಪ್ರೊಫೆಷನಲ್ ಡೆವಲಪರ್‌ಗಳು ಯಾವಾಗಲೂ 3ನೇ ವಿಧಾನವನ್ನು ಬಳಸುತ್ತಾರೆ.

ಚಿತ್ರ 6: HTML ಜೊತೆಗೆ JavaScript ಜೋಡಿಸುವ 3 ವಿಧಾನಗಳು

ವಿಧಾನ 1: Inline (ಸಾಲಿನೊಳಗೆ - ಇದನ್ನು ಹೆಚ್ಚಾಗಿ ಬಳಸಬಾರದು)

HTML ಟ್ಯಾಗ್‌ನ ಒಳಗೇ ನೇರವಾಗಿ ಬರೆಯುವುದು.

1. HTML 
<button onclick="alert('ಹಲೋ, ಸ್ವಾಗತ!')">ಕ್ಲಿಕ್ ಮಾಡಿ</button>

ವಿಧಾನ 2: Internal (ಒಳಗಿನ ಫೈಲ್ - ಕಲಿಯಲು ಮಾತ್ರ ಸೂಕ್ತ)

HTML ಫೈಲ್‌ನ ತಳಭಾಗದಲ್ಲಿ (body ಮುಗಿಯುವ ಮುನ್ನ) <script> ಟ್ಯಾಗ್ ಬಳಸಿ ಬರೆಯುವುದು.

HTML 
<!DOCTYPE html>
<html>
<body>
    <h1>ನನ್ನ ವೆಬ್‌ಸೈಟ್</h1>

    <!-- ಇಲ್ಲಿ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಸೇರಿಸಲಾಗಿದೆ -->
    <script>
        console.log("ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಕೆಲಸ ಮಾಡುತ್ತಿದೆ!");
    </script>
</body>
</html>

ವಿಧಾನ 3: External (ಹೊರಗಿನ ಫೈಲ್ - ಪ್ರೊಫೆಷನಲ್ ವಿಧಾನ 🏆)

JavaScript ಕೋಡ್ ಅನ್ನು ಬೇರೆಯದೇ ಆದ ಒಂದು ಫೈಲ್‌ನಲ್ಲಿ (ಉದಾಹರಣೆಗೆ: script.js) ಬರೆದು, ಅದನ್ನು HTML ಗೆ ಲಿಂಕ್ ಮಾಡುವುದು. ಇದು ಅತ್ಯಂತ ಶುದ್ಧ ಮತ್ತು ಉತ್ತಮ ವಿಧಾನ.

index.html ಫೈಲ್‌ನಲ್ಲಿ ಹೀಗೆ ಬರೆಯಿರಿ:

1. HTML (index.html) 
<!DOCTYPE html>
<html>
<body>
    <h1>ನನ್ನ ಪ್ರೊಫೆಷನಲ್ ವೆಬ್‌ಸೈಟ್</h1>

    <!-- ಹೊರಗಿನ JS ಫೈಲ್ ಅನ್ನು ಇಲ್ಲಿ ಕನೆಕ್ಟ್ ಮಾಡಲಾಗಿದೆ -->
    <script src="script.js"></script>
</body>
</html>

script.js ಫೈಲ್‌ನಲ್ಲಿ ಹೀಗೆ ಬರೆಯಿರಿ:

1. JavaScript (script.js) 
// ಇದು ಪ್ರತ್ಯೇಕ ಫೈಲ್
alert("ಹೊರಗಿನ ಫೈಲ್‌ನಿಂದ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಕನೆಕ್ಟ್ ಆಗಿದೆ!");
