1. JavaScript (ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್) ಎಂದರೇನು?

HTML (ಮೂಳೆಗಳು): ಆಕಾರ ಮತ್ತು ರಚನೆ (Structure).
CSS (ಚರ್ಮ ಮತ್ತು ಬಟ್ಟೆ): ಬಣ್ಣ ಮತ್ತು ವಿನ್ಯಾಸ (Style).
JavaScript (ಮೆದುಳು ಮತ್ತು ಸ್ನಾಯುಗಳು): ವೆಬ್‌ಸೈಟ್‌‌ಗೆ ಜೀವ ತುಂಬುತ್ತದೆ! ಇಂಟರಾಕ್ಟಿವ್ ಆಗಿ ಮಾಡುತ್ತದೆ.

2. ಅದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ?

  1. ಡೌನ್‌ಲೋಡ್: HTML, CSS, JS ಬ್ರೌಸರ್‌ಗೆ ಬರುತ್ತದೆ.
  2. ಓದುವುದು (Parsing): ಎಂಜಿನ್ ಕೋಡ್ ಓದುತ್ತದೆ.
  3. ಅನುವಾದ (Compilation): 0 ಮತ್ತು 1 (ಮಷಿನ್ ಭಾಷೆ) ಗೆ ಬದಲಾಗುತ್ತದೆ.
  4. ಕಾರ್ಯಾಚರಣೆ (Execution): ತಕ್ಷಣವೇ ಕೋಡ್ ರನ್ ಆಗುತ್ತದೆ.

3. JavaScript ಎಂಜಿನ್ (Engines)

Chrome: V8 Engine (ಅತಿ ವೇಗ, Node.js ಗೆ ಆಧಾರ).
Firefox: SpiderMonkey (ಮೊಟ್ಟಮೊದಲ JS ಎಂಜಿನ್).
Safari: JavaScriptCore.

4. Tools ಮತ್ತು Extensions

ಬ್ರೌಸರ್: Google Chrome (Developer Tools - F12).
ಎಡಿಟರ್: VS Code.
Extensions: Live Server (Auto refresh), Prettier (Code formatter), ES6 Snippets.

5. ES6 ಎಂದರೇನು? (ECMAScript 2015)

ಇದು JS ನ ಅತಿ ದೊಡ್ಡ ಅಪ್‌ಡೇಟ್. ಇದರಲ್ಲಿ let ಮತ್ತು const ವೇರಿಯೇಬಲ್‌ಗಳನ್ನು, ಹಾಗೂ ಚಿಕ್ಕದಾದ Arrow Functions (=>) ಗಳನ್ನು ತರಲಾಯಿತು.

6. HTML ಗೆ JS Connect ಮಾಡುವುದು

1. Inline (ಟ್ಯಾಗ್ ಒಳಗೆ) ⚠️
2. Internal (<script> ಟ್ಯಾಗ್) 📄
3. External (ಪ್ರತ್ಯೇಕ .js ಫೈಲ್ - ಪ್ರೊಫೆಷನಲ್ ವಿಧಾನ 🏆)
