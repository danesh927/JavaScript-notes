Event Object (e / event)

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಯಾವುದೇ ಈವೆಂಟ್ (ಉದಾ: ಕ್ಲಿಕ್, ಟೈಪಿಂಗ್, ಮೌಸ್ ಮೂವ್‌ಮೆಂಟ್) ನಡೆದಾಗ, ಬ್ರೌಸರ್ ಆ ಘಟನೆಯ ಸಂಪೂರ್ಣ ಜಾತಕವನ್ನು ಒಂದು ಆಬ್ಜೆಕ್ಟ್ ರೂಪದಲ್ಲಿ ನಮಗೆ ನೀಡುತ್ತದೆ. ಇದನ್ನೇ Event Object ಎನ್ನುತ್ತಾರೆ. ಇದನ್ನು ಸಾಮಾನ್ಯವಾಗಿ ಫಂಕ್ಷನ್‌ನೊಳಗೆ e ಅಥವಾ event ಎಂದು ಕರೆಯುತ್ತೇವೆ.

ಇದರಲ್ಲಿನ ಪ್ರತಿಯೊಂದು ಪ್ರಾಪರ್ಟಿ ಮತ್ತು ಮೆಥಡ್‌ಗಳನ್ನು Beginner ಹಂತದಿಂದ Pro ಹಂತದವರೆಗೆ ವರ್ಗೀಕರಿಸಿ, ಸಂಪೂರ್ಣ ವಿವರಣೆಯೊಂದಿಗೆ ಕೆಳಗೆ ನೀಡಲಾಗಿದೆ.

1. ಸಾಮಾನ್ಯ ಪ್ರಾಪರ್ಟಿಗಳು

Core Event Properties

ಇವು ನೀವು ಕ್ಲಿಕ್ ಮಾಡಲಿ, ಟೈಪ್ ಮಾಡಲಿ ಅಥವಾ ಸ್ಕ್ರಾಲ್ ಮಾಡಲಿ, ಪ್ರತಿಯೊಂದು Event ನಲ್ಲೂ ಕಡ್ಡಾಯವಾಗಿ ಇರುತ್ತವೆ.

e.type

ಯಾವ ರೀತಿಯ ಈವೆಂಟ್ ನಡೆಯಿತು ಎಂದು ಹೇಳುತ್ತದೆ.
(ಉದಾ: "click", "keydown", "submit").

e.target ಮುಖ್ಯ

ನಿಖರವಾಗಿ ಯಾವ ಎಲಿಮೆಂಟ್‌ನ ಮೇಲೆ ಈವೆಂಟ್ ನಡೆಯಿತು ಎಂದು ತೋರಿಸುತ್ತದೆ.

e.currentTarget

ನಾವು addEventListener ಅನ್ನು ಯಾವ ಪೇರೆಂಟ್ ಎಲಿಮೆಂಟ್‌ಗೆ ಹಾಕಿದ್ದೇವೋ ಆ ಎಲಿಮೆಂಟ್ ಅನ್ನು ತೋರಿಸುತ್ತದೆ (Event Delegation ನಲ್ಲಿ ಉಪಯುಕ್ತ).

e.timeStamp

ವೆಬ್‌ಪುಟ ಲೋಡ್ ಆದ ಸಮಯದಿಂದ ಈ ಘಟನೆ ನಡೆಯಲು ಎಷ್ಟು ಮಿಲಿಸೆಕೆಂಡ್‌ಗಳು ಬೇಕಾಯಿತು ಎಂದು ಹೇಳುತ್ತದೆ.

e.isTrusted Pro Level / Security

ಇದು ಭದ್ರತೆಗೆ ಬಹಳ ಮುಖ್ಯ. ಮನುಷ್ಯನೇ ಸ್ವತಃ ಮೌಸ್/ಕೀಬೋರ್ಡ್ ಮೂಲಕ ಈವೆಂಟ್ ಮಾಡಿದ್ದಾನಾ? ಅಥವಾ ಯಾವುದಾದರೂ ಬಾಟ್/ಸ್ಕ್ರಿಪ್ಟ್ (ಉದಾ: button.click()) ಮೂಲಕ ನಕಲಿಯಾಗಿ ಮಾಡಲಾಗಿದೆಯಾ ಎಂದು ಪತ್ತೆಹಚ್ಚುತ್ತದೆ. ಮನುಷ್ಯ ಮಾಡಿದ್ದರೆ true ಬರುತ್ತದೆ.

ಉದಾಹರಣೆ ಕೋಡ್
document.getElementById("myBtn").addEventListener("click", function(e) {
  console.log(e.type);      // "click"
  console.log(e.target);    // <button id="myBtn">
  console.log(e.isTrusted); // true (ಮನುಷ್ಯನೇ ಕ್ಲಿಕ್ ಮಾಡಿದ್ದರೆ)
});

2. ಮೌಸ್ ಈವೆಂಟ್ ಪ್ರಾಪರ್ಟಿಗಳು

Mouse Event Object

ನೀವು ಮೌಸ್ ಕ್ಲಿಕ್ ಅಥವಾ ಮೂವ್ ಮಾಡಿದಾಗ, Event Object ನಲ್ಲಿ ಈ ಕೆಳಗಿನ ಹೆಚ್ಚುವರಿ ಮಾಹಿತಿಗಳು ಬರುತ್ತವೆ. ವಿಶೇಷವಾಗಿ ಕೋ-ಆರ್ಡಿನೇಟ್ಸ್ (X ಮತ್ತು Y ಕಕ್ಷೆಗಳು).

A. ಕಕ್ಷೆಗಳು (Coordinates)

e.clientX / e.clientY

ಬ್ರೌಸರ್‌ನ ಪ್ರಸ್ತುತ ಕಾಣುತ್ತಿರುವ ವಿಂಡೋ (Viewport) ಆಧಾರದ ಮೇಲೆ X ಮತ್ತು Y ಜಾಗ. (ಪೇಜ್ ಸ್ಕ್ರಾಲ್ ಆಗಿದ್ದರೂ ಇದು ಬದಲಾಗುವುದಿಲ್ಲ).

e.pageX / e.pageY

ಇಡೀ ವೆಬ್‌ಪುಟದ (Document) ಆಧಾರದ ಮೇಲೆ X ಮತ್ತು Y ಜಾಗ. (ಪೇಜ್ ಸ್ಕ್ರಾಲ್ ಆಗಿದ್ದರೆ ಸ್ಕ್ರಾಲ್ ಆದ ಜಾಗವನ್ನು ಸೇರಿಸಿ ಲೆಕ್ಕ ಹಾಕುತ್ತದೆ).

e.offsetX / e.offsetY

ನೀವು ಕ್ಲಿಕ್ ಮಾಡಿದ ನಿರ್ದಿಷ್ಟ HTML ಎಲಿಮೆಂಟ್‌ನ ಒಳಗೆ, ಅದರ ಮೂಲೆಯಿಂದ ಲೆಕ್ಕ ಹಾಕಿದ X ಮತ್ತು Y ಜಾಗ.

e.screenX / e.screenY

ನಿಮ್ಮ ಲ್ಯಾಪ್‌ಟಾಪ್/ಮಾನಿಟರ್‌ನ ಇಡೀ ಸ್ಕ್ರೀನ್ ಆಧಾರದ ಮೇಲೆ ಎಲ್ಲಿ ಕ್ಲಿಕ್ ಆಗಿದೆ ಎಂದು ಹೇಳುತ್ತದೆ.

B. ಮೌಸ್ ಬಟನ್ ಮತ್ತು ಕೀಬೋರ್ಡ್ ಸಹಾಯ

e.button

ಮೌಸ್‌ನ ಯಾವ ಬಟನ್ ಒತ್ತಲಾಗಿದೆ?

  • 0 = ಎಡ (Left)
  • 1 = ಮಧ್ಯ (Wheel)
  • 2 = ಬಲ (Right)

e.ctrlKey, e.shiftKey, e.altKey

ಮೌಸ್ ಕ್ಲಿಕ್ ಮಾಡುವಾಗ ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ Ctrl, Shift ಅಥವಾ Alt ಕೀ ಒತ್ತಿ ಹಿಡಿಯಲಾಗಿತ್ತೇ? (ಇದು true ಅಥವಾ false ಕೊಡುತ್ತದೆ. Multiple selection ಮಾಡುವಾಗ ಇದು ಉಪಯುಕ್ತ).

ಮೌಸ್ ಈವೆಂಟ್ ಉದಾಹರಣೆ
document.body.addEventListener("click", function(e) {
  console.log(`ಕ್ಲಿಕ್ ಜಾಗ: X = ${e.clientX}, Y = ${e.clientY}`);
  
  if (e.shiftKey) {
    console.log("ಶಿಫ್ಟ್ (Shift) ಕೀ ಒತ್ತಿ ಹಿಡಿದು ಕ್ಲಿಕ್ ಮಾಡಿದ್ದೀರಿ!");
  }
});

3. ಕೀಬೋರ್ಡ್ ಈವೆಂಟ್ ಪ್ರಾಪರ್ಟಿಗಳು

Keyboard Event Object

keydown, keyup ನಂತಹ ಈವೆಂಟ್‌ಗಳಲ್ಲಿ ಕೀಬೋರ್ಡ್‌ನ ಮಾಹಿತಿಯನ್ನು ಪಡೆಯಲು ಇವುಗಳನ್ನು ಬಳಸಲಾಗುತ್ತದೆ.

e.key

ನೀವು ಟೈಪ್ ಮಾಡಿದ ನಿಖರವಾದ ಅಕ್ಷರ.
(ಉದಾ: ನೀವು 'A' ಒತ್ತಿದರೆ "a" ಬರುತ್ತದೆ. ಶಿಫ್ಟ್ ಒತ್ತಿ ಹಿಡಿದು ಒತ್ತಿದರೆ "A" ಬರುತ್ತದೆ. Enter ಒತ್ತಿದರೆ "Enter" ಬರುತ್ತದೆ).

e.code

ಕೀಬೋರ್ಡ್ ಮೇಲಿನ ಭೌತಿಕ (Physical) ಕೀಯ ಹೆಸರು.
(ಉದಾ: "KeyA", "Space", "Enter").

ಸೂಚನೆ: ಹಳೆಯ ಕೋಡ್‌ಗಳಲ್ಲಿ e.keyCode ಅನ್ನು ಬಳಸುತ್ತಿದ್ದರು, ಆದರೆ ಈಗ ಅದು ಹಳೆಯದಾಗಿದೆ (Deprecated), ಹಾಗಾಗಿ e.key ಬಳಸುವುದು ಸೂಕ್ತ. 

window.addEventListener("keydown", function(e) {
  if (e.key === "Escape") {
    console.log("ಎಸ್ಕೇಪ್ ಕೀ ಒತ್ತಲಾಗಿದೆ. ಪಾಪ್-ಅಪ್ ಕ್ಲೋಸ್ ಮಾಡಿ!");
  }
});
Pro Level

Event Object ಮೆಥಡ್‌ಗಳು (Methods)

ಈವೆಂಟ್‌ಗಳ ನೈಸರ್ಗಿಕ ನಡವಳಿಕೆಯನ್ನು ನಿಯಂತ್ರಿಸಲು ಈ ಮೆಥಡ್‌ಗಳನ್ನು ಬಳಸಲಾಗುತ್ತದೆ.

A. e.preventDefault() (ಡೀಫಾಲ್ಟ್ ತಡೆಯುವುದು)

HTML ಎಲಿಮೆಂಟ್‌ಗಳ ನೈಸರ್ಗಿಕ ಕೆಲಸವನ್ನು ತಡೆಯುತ್ತದೆ. (ಉದಾ: ಫಾರ್ಮ್ ಸಬ್ಮಿಟ್ ಆದಾಗ ಪೇಜ್ ರಿಫ್ರೆಶ್ ಆಗುವುದು, ಲಿಂಕ್ ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ಬೇರೆ ಪೇಜ್‌ಗೆ ಹೋಗುವುದು). 

document.getElementById("myForm").addEventListener("submit", function(e) {
  e.preventDefault(); // ಪೇಜ್ ರಿಫ್ರೆಶ್ ಆಗುವುದನ್ನು ನಿಲ್ಲಿಸುತ್ತದೆ
  // ಈಗ ನಾವು AJAX/Fetch ಮೂಲಕ ಡೇಟಾ ಕಳುಹಿಸಬಹುದು
});

B. e.stopPropagation() (ಬಬ್ಲಿಂಗ್ ತಡೆಯುವುದು)

ನಾವು ಹಿಂದಿನ ಹಂತದಲ್ಲಿ ಚರ್ಚಿಸಿದಂತೆ, ಮಗುವಿನ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿದರೆ ಅದು ಪೇರೆಂಟ್‌ಗೂ ಹೋಗುತ್ತದೆ (Event Bubbling). ಇದನ್ನು ಇಲ್ಲಿಗೇ ನಿಲ್ಲಿಸಲು (Stop) ಇದನ್ನು ಬಳಸುತ್ತಾರೆ.

C. e.stopImmediatePropagation()

The Ultimate Pro Method

ಇದು stopPropagation() ಗಿಂತಲೂ ಶಕ್ತಿಶಾಲಿ.

ಒಂದು ವೇಳೆ ನೀವು ಒಂದೇ ಬಟನ್‌ಗೆ 3 ಬೇರೆ ಬೇರೆ Event Listener ಗಳನ್ನು ಹಾಕಿದ್ದೀರಿ ಅಂದುಕೊಳ್ಳಿ. ಮೊದಲನೇ ಲಿಸನರ್‌ನಲ್ಲಿ ನೀವು e.stopImmediatePropagation() ಹಾಕಿದರೆ, ಅದು Event Bubbling ಅನ್ನು ತಡೆಯುವುದಷ್ಟೇ ಅಲ್ಲದೆ, ಅದೇ ಎಲಿಮೆಂಟ್ ಮೇಲಿರುವ ಉಳಿದ 2 ಲಿಸನರ್‌ಗಳು ಕೆಲಸ ಮಾಡದಂತೆಯೂ ತಡೆಯುತ್ತದೆ!

Super Block Example
const btn = document.getElementById("myBtn");

btn.addEventListener("click", function(e) {
  console.log("ಲಿಸನರ್ 1 ರನ್ ಆಯ್ತು");
  e.stopImmediatePropagation(); // ಇಲ್ಲಿ ಎಲ್ಲವನ್ನೂ ಬ್ಲಾಕ್ ಮಾಡಿದೆ!
});

// ಈ ಕೆಳಗಿನ ಕೋಡ್ ಎಂದಿಗೂ ರನ್ ಆಗುವುದಿಲ್ಲ!
btn.addEventListener("click", function(e) {
  console.log("ಲಿಸನರ್ 2 ರನ್ ಆಯ್ತು");
});
