JavaScript window Object

ಶೂನ್ಯದಿಂದ ವೃತ್ತಿಪರ ಹಂತದವರೆಗೆ (Beginner to Pro) ಸಂಪೂರ್ಣ ಕೈಪಿಡಿ.

Concept ಎಂದರೇನು? (Definition)

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ window ಆಬ್ಜೆಕ್ಟ್ ಎಂದರೆ ಬ್ರೌಸರ್‌ನ ಒಂದು ಟ್ಯಾಬ್ (Tab) ಅಥವಾ ಪರದೆ. ನೀವು ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಓಪನ್ ಮಾಡುವ ಪ್ರತಿಯೊಂದು ಟ್ಯಾಬ್‌ಗೂ ಅದರದೇ ಆದ ಒಂದು window ಆಬ್ಜೆಕ್ಟ್ ಇರುತ್ತದೆ. ಇದು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನ "ಗ್ಲೋಬಲ್ ಆಬ್ಜೆಕ್ಟ್" (Global Object) ಆಗಿದ್ದು, ಎಲ್ಲವೂ ಇದರ ಒಳಗೇ ಇರುತ್ತದೆ.

ನೈಜ ಜೀವನದ ಉದಾಹರಣೆ (Real-World Analogy):

window ಎಂದರೆ ಒಂದು ದೊಡ್ಡ ಮನೆ (House) ಇದ್ದಂತೆ. ಆ ಮನೆಯೊಳಗೆ ಇರುವ ಟಿವಿ, ಫ್ರಿಡ್ಜ್, ಫ್ಯಾನ್ ಎಲ್ಲವೂ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನ ಫಂಕ್ಷನ್‌ಗಳು ಮತ್ತು ವೇರಿಯೇಬಲ್‌ಗಳು. ಮನೆಯೇ ಇಲ್ಲದೆ (ಅಂದರೆ ವಿಂಡೋ ಇಲ್ಲದೆ) ಒಳಗಿನ ವಸ್ತುಗಳಿಗೆ ಅಸ್ತಿತ್ವವಿಲ್ಲ!

ಬ್ರೌಸರ್‌ನ "Big Boss" (The Root Object)

ನೀವು ಬಳಸುವ document (DOM), alert(), console ಎಲ್ಲವೂ window ಆಬ್ಜೆಕ್ಟ್‌ನ ಮಕ್ಕಳೇ (Properties/Methods). window.alert() ಎಂದು ಬರೆಯುವ ಬದಲು ನಾವು ಕೇವಲ alert() ಎಂದು ಬರೆಯುತ್ತೇವೆ, ಏಕೆಂದರೆ ಬ್ರೌಸರ್‌ನಲ್ಲಿ window ಡಿಫಾಲ್ಟ್ (Default) ಆಗಿರುತ್ತದೆ.

1. Alerts & Dialogs (ಬಳಕೆದಾರರೊಂದಿಗೆ ಸಂವಾದ)

ಬಳಕೆದಾರರಿಗೆ ಮೆಸೇಜ್ ತೋರಿಸಲು ಅಥವಾ ಅವರಿಂದ ಮಾಹಿತಿ ಪಡೆಯಲು window ನಮಗೆ 3 ಪ್ರಮುಖ ಫಂಕ್ಷನ್‌ಗಳನ್ನು ನೀಡುತ್ತದೆ.

JavaScript - Dialogs 
// 1. alert: ಕೇವಲ ಮೆಸೇಜ್ ತೋರಿಸುತ್ತದೆ (OK ಬಟನ್ ಮಾತ್ರ ಇರುತ್ತದೆ)
window.alert("ನಿಮ್ಮ ಬ್ಯಾಟರಿ ಕಡಿಮೆ ಇದೆ!");

// 2. confirm: ಸರಿ ಅಥವಾ ತಪ್ಪು (Yes/No) ಕೇಳುತ್ತದೆ. ಇದು true/false ರಿಟರ್ನ್ ಮಾಡುತ್ತದೆ.
let isReady = window.confirm("ನೀವು ಈ ಫೈಲ್ ಡಿಲೀಟ್ ಮಾಡಲು ಸಿದ್ಧರಿದ್ದೀರಾ?");
if(isReady) { console.log("ಡಿಲೀಟ್ ಆಯಿತು!"); }

// 3. prompt: ಬಳಕೆದಾರರಿಂದ ಟೆಕ್ಸ್ಟ್ (Text input) ಪಡೆಯುತ್ತದೆ.
let userName = window.prompt("ನಿಮ್ಮ ಹೆಸರೇನು?", "ಅತಿಥಿ");
console.log("ಹಲೋ " + userName);
ಗಮನಿಸಿ: ಪ್ರತೀ ಬಾರಿ window. ಎಂದು ಬರೆಯುವ ಅಗತ್ಯವಿಲ್ಲ. alert() ಎಂದು ಬರೆದರೂ ಬ್ರೌಸರ್ ಅದನ್ನು window.alert() ಎಂದೇ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುತ್ತದೆ.

2. Timers (ಸಮಯ ನಿಯಂತ್ರಣ)

ಒಂದು ನಿರ್ದಿಷ್ಟ ಸಮಯದ ನಂತರ ಕೋಡ್ ರನ್ ಮಾಡಲು, ಅಥವಾ ಮತ್ತೆ ಮತ್ತೆ ರನ್ ಮಾಡಲು ವಿಂಡೋ ಆಬ್ಜೆಕ್ಟ್ ನಮಗೆ ಟೈಮರ್‌ಗಳನ್ನು ನೀಡುತ್ತದೆ.

JavaScript - Timers 
// 1. setTimeout: ಸ್ವಲ್ಪ ಸಮಯದ ನಂತರ 'ಒಮ್ಮೆ' ಮಾತ್ರ ರನ್ ಆಗುತ್ತದೆ.
// ಉದಾ: 3000ms (3 ಸೆಕೆಂಡ್) ಕಾದ ನಂತರ ಫಂಕ್ಷನ್ ರನ್ ಆಗುತ್ತದೆ.
let timerId = setTimeout(() => {
    console.log("3 ಸೆಕೆಂಡ್ ಮುಗಿಯಿತು!");
}, 3000);

// ಬೇಡವಾದರೆ ನಿಲ್ಲಿಸಬಹುದು:
// clearTimeout(timerId);

// 2. setInterval: ನಿರ್ದಿಷ್ಟ ಸಮಯದ ಅಂತರದಲ್ಲಿ 'ಮತ್ತೆ ಮತ್ತೆ' ರನ್ ಆಗುತ್ತದೆ. (ಉದಾ: ಸ್ಟಾಪ್‌ವಾಚ್)
let intervalId = setInterval(() => {
    console.log("ಪ್ರತಿ 1 ಸೆಕೆಂಡಿಗೆ ನಾನು ಬರುತ್ತೇನೆ!");
}, 1000);

// ಇದನ್ನು ನಿಲ್ಲಿಸಲು clearInterval ಬಳಸಿ:
// clearInterval(intervalId);

3. BOM (Browser Object Model)

ಬ್ರೌಸರ್‌ನ ಪರದೆ (Screen), ಈಗಿರುವ ಲಿಂಕ್ (URL), ಮತ್ತು ಹಿಸ್ಟರಿಯನ್ನು (History) ನಿಯಂತ್ರಿಸುವ ಫಂಕ್ಷನ್‌ಗಳ ಗುಂಪನ್ನು BOM ಎನ್ನುತ್ತಾರೆ. ಇವೂ ಕೂಡ window ಒಳಗೇ ಇವೆ.

JavaScript - BOM Properties 
// 1. Location (URL ಮಾಹಿತಿ)
console.log(window.location.href); // ಈಗಿರುವ ಸಂಪೂರ್ಣ ಲಿಂಕ್ (URL)
// window.location.href = "https://google.com"; // ಈ ಕೋಡ್ ರನ್ ಮಾಡಿದರೆ ಗೂಗಲ್ ಓಪನ್ ಆಗುತ್ತದೆ!

// 2. History (ಹಿಂದಕ್ಕೆ/ಮುಂದಕ್ಕೆ ಹೋಗಲು)
// window.history.back(); // ಬ್ರೌಸರ್‌ನ 'Back' ಬಟನ್ ಒತ್ತಿದಂತೆ
// window.history.forward(); // ಬ್ರೌಸರ್‌ನ 'Forward' ಬಟನ್ ಒತ್ತಿದಂತೆ

// 3. Screen / Window Size (ಸ್ಕ್ರೀನ್ ಅಳತೆ)
console.log("ಅಗಲ: " + window.innerWidth);  // ಪರದೆಯ ಒಟ್ಟು ಅಗಲ (Width)
console.log("ಎತ್ತರ: " + window.innerHeight); // ಪರದೆಯ ಒಟ್ಟು ಎತ್ತರ (Height)

4. Storage (ಡೇಟಾ ಸೇವ್ ಮಾಡುವುದು - Pro Level)

ನೀವು ಅಮೆಜಾನ್‌ನಲ್ಲಿ ಲಾಗಿನ್ ಆದಾಗ, ಬ್ರೌಸರ್ ಕ್ಲೋಸ್ ಮಾಡಿದರೂ ಮರುದಿನ ನಿಮ್ಮ ಹೆಸರು ಹಾಗೆಯೇ ಇರುತ್ತದೆ! ಇದು ಹೇಗೆ? ಇದಕ್ಕಾಗಿ window.localStorage ಬಳಸುತ್ತಾರೆ.

  • localStorage: ಬ್ರೌಸರ್ ಕ್ಲೋಸ್ ಮಾಡಿದರೂ ಡೇಟಾ ಶಾಶ್ವತವಾಗಿ ಉಳಿಯುತ್ತದೆ.
  • sessionStorage: ಟ್ಯಾಬ್ (Tab) ಕ್ಲೋಸ್ ಮಾಡಿದ ತಕ್ಷಣ ಡೇಟಾ ಅಳಿಸಿಹೋಗುತ್ತದೆ.
JavaScript - Local Storage 
// 1. ಡೇಟಾ ಸೇವ್ ಮಾಡುವುದು (Key-Value ಜೋಡಿಯಾಗಿ)
localStorage.setItem("username", "Raju");
localStorage.setItem("theme", "dark");

// 2. ಡೇಟಾ ಓದುವುದು (ಬ್ರೌಸರ್ ರೀಸ್ಟಾರ್ಟ್ ಮಾಡಿದ ಮೇಲೂ ಸಿಗುತ್ತದೆ)
let savedName = localStorage.getItem("username");
console.log("ಲಾಗಿನ್ ಆಗಿರುವವರು: " + savedName); // Raju

// 3. ಡೇಟಾ ಡಿಲೀಟ್ ಮಾಡುವುದು
localStorage.removeItem("username");

// 4. ಎಲ್ಲವನ್ನೂ ಅಳಿಸಿಹಾಕುವುದು (Clear All)
// localStorage.clear();
