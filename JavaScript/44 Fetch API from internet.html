API & Fetch in JavaScript

API (Application Programming Interface) ಎಂದರೆ ಅಂತರ್ಜಾಲದಲ್ಲಿ ಎರಡು ಬೇರೆ-ಬೇರೆ ಸಾಫ್ಟ್‌ವೇರ್‌ಗಳು ಅಥವಾ ಅಪ್ಲಿಕೇಶನ್‌ಗಳು ಪರಸ್ಪರ ಮಾತನಾಡಿಕೊಳ್ಳಲು (ಮಾಹಿತಿ ವಿನಿಮಯ ಮಾಡಿಕೊಳ್ಳಲು) ಬಳಸುವ ಒಂದು ಸೇತುವೆ.

ಇದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಒಂದು ಅತ್ಯುತ್ತಮ ಉದಾಹರಣೆ ಎಂದರೆ ರೆಸ್ಟೋರೆಂಟ್‌ನ ವೇಟರ್:

  • ನೀವು (ಕ್ಲೈಂಟ್/ಆಪ್): ಟೇಬಲ್ ಮೇಲೆ ಕುಳಿತು ಆಹಾರ ಆರ್ಡರ್ ಮಾಡುತ್ತೀರಿ. ನಿಮಗೆ ಅಡುಗೆಮನೆಯೊಳಗೆ ಹೋಗಿ ಆಹಾರ ತರಲು ಅವಕಾಶವಿಲ್ಲ.
  • ಅಡುಗೆಮನೆ (ಸರ್ವರ್/ಡೇಟಾಬೇಸ್): ಅಲ್ಲಿ ಆಹಾರ (ಮಾಹಿತಿ/Data) ತಯಾರಾಗುತ್ತದೆ ಮತ್ತು ಶೇಖರಣೆಯಾಗಿರುತ್ತದೆ.
  • ವೇಟರ್ (API): ನಿಮ್ಮ ಆರ್ಡರ್ ಅನ್ನು ತೆಗೆದುಕೊಂಡು ಅಡುಗೆಮನೆಗೆ ತಿಳಿಸುತ್ತಾನೆ, ಅಲ್ಲಿಂದ ತಯಾರಾದ ಆಹಾರವನ್ನು ತಂದು ನಿಮಗೆ ಕೊಡುತ್ತಾನೆ.

ಇದೇ ರೀತಿ, ನಿಮ್ಮ ಮೊಬೈಲ್ ಆಪ್ (ಉದಾ: Swiggy) ನೇರವಾಗಿ Google ನ ಸರ್ವರ್‌ಗೆ ನುಗ್ಗಿ ಮ್ಯಾಪ್ ತರಲು ಸಾಧ್ಯವಿಲ್ಲ. ಬದಲಾಗಿ, ಅದು Google ನ ವೇಟರ್‌ಗೆ (API) ವಿನಂತಿ (Request) ಮಾಡುತ್ತದೆ, ವೇಟರ್ ಮ್ಯಾಪ್ ಅನ್ನು ತಂದು ಆಪ್‌ಗೆ ಕೊಡುತ್ತಾನೆ.

1. API ಎಲ್ಲಿಂದ ಬರುತ್ತದೆ? (ಯಾರು ಮಾಡುತ್ತಾರೆ?)

API ಗಳನ್ನು ಆಯಾ ಮಾಹಿತಿಯನ್ನು ಹೊಂದಿರುವ ದೊಡ್ಡ ಕಂಪನಿಗಳು, ಸರ್ಕಾರಿ ಸಂಸ್ಥೆಗಳು ಅಥವಾ ಸಾಫ್ಟ್‌ವೇರ್ ಡೆವಲಪರ್‌ಗಳು ಸ್ವತಃ ನಿರ್ಮಿಸುತ್ತಾರೆ.

  • ಕಾರಣ: ತಮ್ಮ ಬಳಿ ಇರುವ ಕೋಟ್ಯಾಂತರ ಡೇಟಾವನ್ನು ಇತರರಿಗೆ ಸುರಕ್ಷಿತವಾಗಿ ನೀಡಲು. ಅವರು ತಮ್ಮ ಇಡೀ ಡೇಟಾಬೇಸ್ ಅನ್ನು ಯಾರಿಗೂ ಕೊಡುವುದಿಲ್ಲ, ಬದಲಾಗಿ ಕೇವಲ ನೀವು ಕೇಳಿದ ಮಾಹಿತಿಯನ್ನು ಮಾತ್ರ API ಮೂಲಕ ಕೊಡುತ್ತಾರೆ.
  • ಉದಾಹರಣೆ:
    • Google Maps API: ಇದನ್ನು ಗೂಗಲ್ ಸೃಷ್ಟಿಸಿದೆ. Uber, Ola, Swiggy ಆಪ್‌ಗಳು ಇದನ್ನು ಬಳಸುತ್ತವೆ.
    • Weather API: ಹವಾಮಾನ ಇಲಾಖೆಗಳು ಸೃಷ್ಟಿಸುತ್ತವೆ. ನಿಮ್ಮ ಮೊಬೈಲ್‌ನಲ್ಲಿರುವ ಹವಾಮಾನ ಆಪ್ ಈ API ಇಂದ ಡೇಟಾ ಪಡೆಯುತ್ತದೆ.

2. API ಗಳು ಎಲ್ಲಿ ಸಿಗುತ್ತವೆ?

ನಿಮಗೆ ಯಾವುದೇ ರೀತಿಯ ಡೇಟಾ ಬೇಕಿದ್ದರೂ ಅದಕ್ಕೊಂದು API ಅಂತರ್ಜಾಲದಲ್ಲಿ ಸಿಗುತ್ತದೆ.

1. RapidAPI (rapidapi.com)

ಇದು API ಗಳ ಅತಿದೊಡ್ಡ ಮಾರುಕಟ್ಟೆ. ಇಲ್ಲಿ ಹವಾಮಾನ, ಕ್ರಿಕೆಟ್ ಸ್ಕೋರ್, ಸಿನಿಮಾ ಮಾಹಿತಿ ಸೇರಿದಂತೆ ಲಕ್ಷಾಂತರ API ಗಳು ಸಿಗುತ್ತವೆ.

2. Public APIs (GitHub)

ಗಿಟ್‌ಹಬ್‌ನಲ್ಲಿ "Public APIs" ಎಂದು ಹುಡುಕಿದರೆ, ಉಚಿತವಾಗಿ ಸಿಗುವ ಸಾವಿರಾರು API ಗಳ ಪಟ್ಟಿ ಸಿಗುತ್ತದೆ (ಉದಾ: ನಾಯಿಗಳ ಫೋಟೋ, ಜೋಕ್ಸ್, ದೇಶಗಳ ಮಾಹಿತಿ).

3. ಕಂಪನಿಗಳ ಪೋರ್ಟಲ್

Twitter API ಬೇಕಿದ್ದರೆ ಟ್ವಿಟರ್‌ನ ಡೆವಲಪರ್ ವೆಬ್‌ಸೈಟ್‌ಗೆ ಹೋಗಬೇಕು, ಗೂಗಲ್ ಸೇವೆಗಳಿಗೆ Google Developer Console ಗೆ ಹೋಗಬೇಕು.

ಸೂಚನೆ: ಕೆಲವು API ಗಳು ಸಂಪೂರ್ಣ ಉಚಿತ (Free), ಇನ್ನು ಕೆಲವು ಬಳಸಲು ಹಣ ಕಟ್ಟಬೇಕು (Paid), ಮತ್ತು ಹೆಚ್ಚಿನವುಗಳನ್ನು ಬಳಸಲು API Key (ಪಾಸ್‌ವರ್ಡ್ ಅಥವಾ ಐಡಿ ಕಾರ್ಡ್ ಇದ್ದಂತೆ) ಬೇಕಾಗುತ್ತದೆ.

3. API ಅನ್ನು ಹೇಗೆ ಬಳಸುವುದು? (ಉದಾಹರಣೆಯೊಂದಿಗೆ)

ಒಂದು API ಅನ್ನು ಬಳಸಲು ನಮಗೆ ಮುಖ್ಯವಾಗಿ ಬೇಕಾಗಿರುವುದು Endpoint (URL). ಎಂಡ್‌ಪಾಯಿಂಟ್ ಎಂದರೆ ಸರ್ವರ್‌ನಲ್ಲಿ ಮಾಹಿತಿ ಇರುವ ನಿರ್ದಿಷ್ಟ ವಿಳಾಸ.

ಈಗ ನಾವು ಒಂದು ಉಚಿತವಾದ 'Joke API' (ಇದಕ್ಕೆ API Key ಬೇಕಾಗಿಲ್ಲ) ಬಳಸಿ ಇಂಟರ್ನೆಟ್‌ನಿಂದ ಒಂದು ತಮಾಷೆಯ ಸಾಲನ್ನು (Joke) ತರೋಣ.

API Endpoint: https://official-joke-api.appspot.com/random_joke

ಉದಾಹರಣೆ ಕೋಡ್ (JavaScript fetch ಬಳಸಿ):

JavaScript 
// ಒಂದು ಅಸಿಂಕ್ರೋನಸ್ ಫಂಕ್ಷನ್ ರಚಿಸುತ್ತಿದ್ದೇವೆ
async function getRandomJoke() {
  try {
    console.log("ಜೋಕ್ ತರಲು ಸರ್ವರ್‌ಗೆ ಹೋಗುತ್ತಿದ್ದೇನೆ... ದಯವಿಟ್ಟು ಕಾಯಿರಿ.");

    // 1. API Endpoint ಗೆ ರಿಕ್ವೆಸ್ಟ್ (ವಿನಂತಿ) ಕಳುಹಿಸುವುದು
    let response = await fetch('https://official-joke-api.appspot.com/random_joke');
    
    // 2. ಸರ್ವರ್‌ನಿಂದ ಸರಿಯಾದ ಉತ್ತರ ಬಂದಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸುವುದು
    if (!response.ok) {
      throw new Error("ಸರ್ವರ್‌ನಲ್ಲಿ ಏನೋ ಸಮಸ್ಯೆಯಿದೆ!");
    }
    
    // 3. ಬಂದಂತಹ ಡೇಟಾವನ್ನು JSON ರೂಪಕ್ಕೆ ಬದಲಾಯಿಸುವುದು
    let jokeData = await response.json();
    
    // 4. API ಯಿಂದ ಬಂದ ಡೇಟಾವನ್ನು ಬಳಸುವುದು (ಪ್ರಿಂಟ್ ಮಾಡುವುದು)
    console.log("ಪ್ರಶ್ನೆ: " + jokeData.setup);
    console.log("ಉತ್ತರ: " + jokeData.punchline);
    
  } catch (error) {
    // ಏನಾದರೂ ತಪ್ಪಾದರೆ ಅದನ್ನು ಹಿಡಿಯುವುದು
    console.log("ದೋಷ ಕಂಡುಬಂದಿದೆ: ", error);
  }
}

// ಫಂಕ್ಷನ್ ಅನ್ನು ಕರೆಯುವುದು
getRandomJoke();

ಪ್ರತಿಸಾಲಿನ ಸಂಪೂರ್ಣ ವಿವರಣೆ:

  • 1. async function getRandomJoke() {: ಇದೊಂದು ಅಸಿಂಕ್ರೋನಸ್ ಫಂಕ್ಷನ್. ಇಂಟರ್ನೆಟ್‌ನಿಂದ ಡೇಟಾ ಬರಲು ಸ್ವಲ್ಪ ಸಮಯ ಹಿಡಿಯುವುದರಿಂದ, ಬ್ರೌಸರ್‌ಗೆ ಕಾಯಲು ಸೂಚಿಸುತ್ತದೆ.
  • 2. try {: ನೆಟ್‌ವರ್ಕ್ ಸಮಸ್ಯೆ ಬಂದರೆ ಪ್ರೋಗ್ರಾಮ್ ಕ್ರಾಶ್ ಆಗದಂತೆ ನೋಡಿಕೊಳ್ಳಲು ಸುರಕ್ಷತಾ ಕವಚ (Error handling).
  • 3. console.log(...): ಬಳಕೆದಾರನಿಗೆ ಡೇಟಾ ತರುತ್ತಿರುವುದಾಗಿ ಸಂದೇಶ ತೋರಿಸುವುದು.
  • 4. let response = await fetch('URL');: ಇಲ್ಲಿ fetch ಎನ್ನುವುದು ನಮ್ಮ ವೇಟರ್. ನಾವು ಕೊಟ್ಟ API URL ಗೆ ಹೋಗಿ, ಡೇಟಾವನ್ನು ತರಲು await (ಕಾಯುತ್ತದೆ). ತಂದ ಡೇಟಾವನ್ನು response ನಲ್ಲಿ ಇಡುತ್ತದೆ.
  • 5. if (!response.ok) { ... }: ವೇಟರ್ ಬರಿಗೈಯಲ್ಲಿ ಬಂದರೆ (ಉದಾ: ವೆಬ್‌ಸೈಟ್ ಡೌನ್ ಇದ್ದರೆ), ತಪ್ಪು (Error) ಎಂದು ಘೋಷಿಸಲು ಈ ಸಾಲು ಬಳಸುತ್ತೇವೆ.
  • 6. let jokeData = await response.json();: ಸರ್ವರ್‌ನಿಂದ ಬಂದ ಡೇಟಾ ಕಂಪ್ಯೂಟರ್ ಭಾಷೆಯಲ್ಲಿರುತ್ತದೆ. ಅದನ್ನು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ಗೆ ಅರ್ಥವಾಗುವ JSON (ಆಬ್ಜೆಕ್ಟ್) ರೂಪಕ್ಕೆ json() ಮೂಲಕ ಬದಲಾಯಿಸುತ್ತೇವೆ.
  • 7. console.log("ಪ್ರಶ್ನೆ: " + jokeData.setup);: API ಕಳುಹಿಸಿದ JSON ಡೇಟಾದ ಒಳಗೆ setup (ಪ್ರಶ್ನೆ) ಮತ್ತು punchline (ಉತ್ತರ) ಎಂಬ ಎರಡು ಭಾಗಗಳಿರುತ್ತವೆ. ಅದರಲ್ಲಿ ಮೊದಲು setup ಅನ್ನು ಪ್ರಿಂಟ್ ಮಾಡುತ್ತಿದ್ದೇವೆ.
  • 8. console.log("ಉತ್ತರ: " + jokeData.punchline);: ನಂತರ ಜೋಕ್‌ನ ಅಂತಿಮ ಸಾಲನ್ನು ಪ್ರಿಂಟ್ ಮಾಡುತ್ತಿದ್ದೇವೆ.
  • 9. } catch (error) {: ಇಂಟರ್ನೆಟ್ ಕಟ್ ಆದರೆ ಅಥವಾ ಲಿಂಕ್ ತಪ್ಪಾಗಿದ್ದರೆ, ಪ್ರೋಗ್ರಾಮ್ ನಿಲ್ಲಿಸದೆ ಇಲ್ಲಿರುವ ಕೋಡ್ ಮೂಲಕ ತಪ್ಪನ್ನು (error) ಪ್ರಿಂಟ್ ಮಾಡುತ್ತದೆ.

ಸಾರಾಂಶ:

API ಎನ್ನುವುದು ಮಾಹಿತಿಯನ್ನು ಒದಗಿಸುವ ಒಂದು ವ್ಯವಸ್ಥೆ. fetch ಎನ್ನುವುದು ಆ ವ್ಯವಸ್ಥೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ ಮಾಹಿತಿಯನ್ನು ನಮ್ಮ ವೆಬ್‌ಸೈಟ್‌ಗೆ ತರುವ ಒಂದು ಸಾಧನ.

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ fetch ಎಂದರೆ ಇಂಟರ್ನೆಟ್‌ನಿಂದ (ಅಥವಾ ಸರ್ವರ್‌ನಿಂದ) ಮಾಹಿತಿಯನ್ನು (Data) ನಮ್ಮ ವೆಬ್‌ಸೈಟ್‌ಗೆ ತರುವ ಒಂದು ಸಾಧನ.

ಇದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಒಂದು ಸರಳ ಉದಾಹರಣೆ: ನೀವು ರೆಸ್ಟೋರೆಂಟ್‌ಗೆ ಹೋಗಿ ವೇಟರ್‌ಗೆ (fetch) ಆರ್ಡರ್ ನೀಡುತ್ತೀರಿ. ವೇಟರ್ ಅಡುಗೆಮನೆಗೆ (Server) ಹೋಗಿ, ನೀವು ಕೇಳಿದ ಆಹಾರವನ್ನು (Data) ತರುತ್ತಾನೆ. ಆ ಆಹಾರವನ್ನು ನೀವು ತಿನ್ನುತ್ತೀರಿ (ನಮ್ಮ ಕೋಡ್‌ನಲ್ಲಿ ಬಳಸುವುದು).

ಒಬ್ಬ Non-IT ವಿದ್ಯಾರ್ಥಿಯಿಂದ ಹಿಡಿದು ವೃತ್ತಿಪರ (Professional) ಡೆವಲಪರ್ ಹಂತದವರೆಗೆ fetch ಅನ್ನು ಹೇಗೆ ಬಳಸಲಾಗುತ್ತದೆ ಮತ್ತು ಬೇರೆ ಬೇರೆ ರೀತಿಯ ಡೇಟಾವನ್ನು (Text, JSON, Image/Blob) ಹೇಗೆ ತರಲಾಗುತ್ತದೆ ಎಂಬುದನ್ನು ಹಂತ-ಹಂತವಾಗಿ ನೋಡೋಣ.

ಹಂತ 1: Text Data ತರುವುದು (Beginner Level)

ಯಾವುದೇ ಒಂದು ಸಾಮಾನ್ಯ ಪಠ್ಯವನ್ನು (Text) ಇಂಟರ್ನೆಟ್‌ನಿಂದ ತರುವ ಮೂಲ ವಿಧಾನ ಇದು.

JavaScript 
fetch('https://example.com/hello.txt')
  .then(response => response.text())
  .then(data => console.log(data));

ಪ್ರತಿಸಾಲಿನ ವಿವರಣೆ:

  • fetch('https://example.com/hello.txt'): ವೇಟರ್‌ಗೆ ಆರ್ಡರ್ ಕೊಟ್ಟಂತೆ. "ಈ ವಿಳಾಸಕ್ಕೆ ಹೋಗಿ ಅಲ್ಲಿರುವ ಡೇಟಾವನ್ನು ತೆಗೆದುಕೊಂಡು ಬಾ" ಎಂದು ಬ್ರೌಸರ್‌ಗೆ ಆದೇಶ ನೀಡುತ್ತದೆ.
  • .then(response => response.text()): ಸರ್ವರ್‌ನಿಂದ ಉತ್ತರ (response) ಬಂದ ತಕ್ಷಣ (ವೇಟರ್ ವಾಪಸ್ ಬಂದ ತಕ್ಷಣ), ಆ ಡೇಟಾವನ್ನು 'ಸಾಮಾನ್ಯ ಪಠ್ಯ' (Text) ರೂಪಕ್ಕೆ ಬದಲಾಯಿಸು ಎಂದು ಹೇಳುತ್ತದೆ.
  • .then(data => console.log(data)): ಆ ಪಠ್ಯ (data) ಸಂಪೂರ್ಣವಾಗಿ ರೆಡಿಯಾದ ಮೇಲೆ, ಅದನ್ನು ನಮ್ಮ ಸ್ಕ್ರೀನ್ ಮೇಲೆ (console ನಲ್ಲಿ) ತೋರಿಸು.

ಹಂತ 2: JSON Data ತರುವುದು (Intermediate Level)

ಇಂಟರ್ನೆಟ್‌ನಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ಬಳಸುವ ಡೇಟಾ ಫಾರ್ಮ್ಯಾಟ್ ಎಂದರೆ JSON (JavaScript Object Notation). ಪ್ರೊಫೆಷನಲ್ ಡೆವಲಪರ್‌ಗಳು .then() ಬದಲಿಗೆ ಆಧುನಿಕವಾದ async / await ಅನ್ನು ಬಳಸುತ್ತಾರೆ.

JavaScript 
async function getUserData() {
  let response = await fetch('https://jsonplaceholder.typicode.com/users/1');
  let jsonData = await response.json();
  console.log("ಬಳಕೆದಾರನ ಹೆಸರು: " + jsonData.name);
}

getUserData();

ಪ್ರತಿಸಾಲಿನ ವಿವರಣೆ:

  • async function getUserData() {: ಇದೊಂದು ಅಸಿಂಕ್ರೋನಸ್ (Asynchronous) ಫಂಕ್ಷನ್. ಇದರರ್ಥ "ಈ ಫಂಕ್ಷನ್ ಒಳಗೆ ಕೆಲವು ಕೆಲಸಗಳು ಸ್ವಲ್ಪ ಸಮಯ ತೆಗೆದುಕೊಳ್ಳುತ್ತವೆ, ಆದ್ದರಿಂದ ಕಾಯುವ (await) ಅವಕಾಶ ಕೊಡು" ಎಂದು ಬ್ರೌಸರ್‌ಗೆ ತಿಳಿಸುವುದು.
  • let response = await fetch('URL');: ಇಂಟರ್ನೆಟ್‌ನಿಂದ ಡೇಟಾ ಬರುವವರೆಗೆ ಕೋಡ್ ಅನ್ನು ಇಲ್ಲಿಯೇ ತಡೆದು ಕಾಯಿ (await). ಬಂದ ಡೇಟಾವನ್ನು response ಎಂಬ ಡಬ್ಬದಲ್ಲಿ (variable) ಹಾಕು.
  • let jsonData = await response.json();: ಬಂದಂತಹ ಉತ್ತರವನ್ನು ಕೇವಲ ಟೆಕ್ಸ್ಟ್ ಮಾಡದೆ, JSON (ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವ ಆಬ್ಜೆಕ್ಟ್) ರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸಲು ಕಾಯಿ (await). ನಂತರ ಅದನ್ನು jsonData ದಲ್ಲಿ ಸೇವ್ ಮಾಡು.
  • console.log("ಬಳಕೆದಾರನ ಹೆಸರು: " + jsonData.name);: ಆ JSON ಡೇಟಾದಲ್ಲಿರುವ ಬಳಕೆದಾರನ ಹೆಸರನ್ನು (name) ಕನ್ಸೋಲ್‌ನಲ್ಲಿ ಪ್ರಿಂಟ್ ಮಾಡು.
  • }: ಫಂಕ್ಷನ್ ಮುಕ್ತಾಯ.
  • getUserData();: ನಾವು ಮೇಲ್ಗಡೆ ಬರೆದ ಫಂಕ್ಷನ್ ಅನ್ನು ರನ್ (execute) ಮಾಡಲು ಕರೆಯುವುದು.

ಹಂತ 3: Professional Level (Error Handling & Other Data - Blob)

ಕೇವಲ ಡೇಟಾ ತರುವುದು ಮಾತ್ರ ಪ್ರೊಫೆಷನಲ್ ಅಲ್ಲ. ಒಂದು ವೇಳೆ ಇಂಟರ್ನೆಟ್ ಇಲ್ಲದಿದ್ದರೆ? ಅಥವಾ ಸರ್ವರ್ ಕೆಟ್ಟಿದ್ದರೆ? ಅದನ್ನು ನಿಭಾಯಿಸುವುದೇ (Error Handling) ಅಸಲಿ ವೃತ್ತಿಪರತೆ. ಜೊತೆಗೆ, ಪಠ್ಯದ ಬದಲು ಇಮೇಜ್, ಆಡಿಯೋ, ಅಥವಾ ಫೈಲ್‌ಗಳನ್ನು (Blob - Binary Large Object) ತರುವುದು ಹೇಗೆ ಎಂದು ನೋಡೋಣ.

JavaScript 
async function fetchImageProf() {
  try {
    let response = await fetch('https://via.placeholder.com/150');
    
    if (!response.ok) {
      throw new Error("ನೆಟ್‌ವರ್ಕ್ ಅಥವಾ ಸರ್ವರ್ ದೋಷ! Status: " + response.status);
    }
    
    let imageBlob = await response.blob();
    let imageURL = URL.createObjectURL(imageBlob);
    console.log("ಚಿತ್ರದ ತಾತ್ಕಾಲಿಕ ಲಿಂಕ್: " + imageURL);
    
  } catch (error) {
    console.error("ಕ್ಷಮಿಸಿ, ಏನೋ ತಪ್ಪಾಗಿದೆ: ", error);
  }
}

fetchImageProf();
