JS Promises

ಪರಿವಿಡಿ

ಪೀಠಿಕೆ ಉದಾಹರಣೆ ಫಂಕ್ಷನ್ 1. Promise.all() 2. Promise.allSettled() 3. Promise.race() 4. Promise.any() ಸಾರಾಂಶ

ಖಂಡಿತ, ನೀವು ನೀಡಿದ ಮಾಹಿತಿಯು ಅತ್ಯಂತ ಸುಂದರವಾಗಿದೆ ಮತ್ತು ಉದಾಹರಣೆಗಳು ತುಂಬಾ ಸರಳವಾಗಿವೆ. ನಿಮ್ಮ ಕೋರಿಕೆಯಂತೆ, ನೀವು ನೀಡಿದ ಒಂದೇ ಒಂದು ಅಕ್ಷರವನ್ನೂ ಬಿಡದೆ, ಪ್ರತಿಯೊಂದು ವಿಷಯ ಮತ್ತು ಕೋಡ್‌ ಅನ್ನು ಮತ್ತಷ್ಟು ಆಳವಾಗಿ, ಪ್ರತಿಯೊಬ್ಬರಿಗೂ ಅರ್ಥವಾಗುವಂತೆ ಹೆಚ್ಚುವರಿ ವಿವರಣೆಯೊಂದಿಗೆ ಕೆಳಗೆ ನೀಡುತ್ತಿದ್ದೇನೆ:

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ 'ಪ್ರಾಮಿಸ್' (Promise) ಎಂದರೆ ಒಂದು ಭರವಸೆ. ನೀವೊಂದು ಕೆಲಸ ಕೊಟ್ಟಾಗ, ಅದು "ನಾನು ಕೆಲಸ ಮುಗಿಸಿ ಫಲಿತಾಂಶ ಕೊಡುತ್ತೇನೆ" ಎಂದು ಹೇಳುತ್ತದೆ.

'Parallel' (ಸಮಾನಾಂತರ) ಎಂದರೆ ಒಂದೇ ಬಾರಿಗೆ ಹಲವು ಕೆಲಸಗಳನ್ನು ಒಟ್ಟಿಗೆ ಮಾಡುವುದು.

ಇದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಒಂದು ಸುಲಭವಾದ ಕಥೆ ನೋಡೋಣ:

ನಿಮ್ಮ ಮನೆಯಲ್ಲಿ ಒಂದು ಪಾರ್ಟಿ ಇದೆ. ನಿಮಗೆ 3 ವಸ್ತುಗಳು ಬೇಕು:

  • 1 ಸ್ನೇಹಿತ 1: ಕೇಕ್ ತರಬೇಕು (2 ನಿಮಿಷ ಆಗುತ್ತೆ)
  • 2 ಸ್ನೇಹಿತ 2: ಬಲೂನ್ ತರಬೇಕು (3 ನಿಮಿಷ ಆಗುತ್ತೆ)
  • 3 ಸ್ನೇಹಿತ 3: ಜ್ಯೂಸ್ ತರಬೇಕು (1 ನಿಮಿಷ ಆಗುತ್ತೆ)

ನೀವು ಒಬ್ಬೊಬ್ಬರಿಗೇ ಫೋನ್ ಮಾಡಿ, ಅವರು ತಂದ ಮೇಲೆ ಇನ್ನೊಬ್ಬರಿಗೆ ಫೋನ್ ಮಾಡಿದರೆ ಒಟ್ಟು 6 ನಿಮಿಷ (2+3+1) ಬೇಕಾಗುತ್ತದೆ. ಆದರೆ, ನೀವು ಮೂವರಿಗೂ ಒಟ್ಟಿಗೆ (Parallel ಆಗಿ) ಫೋನ್ ಮಾಡಿದರೆ, ಕೇವಲ 3 ನಿಮಿಷದಲ್ಲಿ (ಯಾರು ಹೆಚ್ಚು ಸಮಯ ತೆಗೆದುಕೊಳ್ಳುತ್ತಾರೋ ಅಷ್ಟು) ಎಲ್ಲವೂ ಬರುತ್ತದೆ! ಇದನ್ನೇ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ Parallel Promises ಎನ್ನುತ್ತಾರೆ. ಇದು ಸಮಯವನ್ನು ಉಳಿಸುತ್ತದೆ.

Visual Concept: Parallel Execution

ಹೆಚ್ಚುವರಿ ವಿವರಣೆ (ಮೂಲ ಪರಿಕಲ್ಪನೆ):

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಒಂದೇ ಬಾರಿಗೆ ಕೇವಲ ಒಂದು ಕೆಲಸವನ್ನು ಮಾತ್ರ ಮಾಡುವ ಭಾಷೆ (Single-threaded). ಆದರೆ ಸರ್ವರ್‌ನಿಂದ ಡೇಟಾ ತರುವುದು, ಫೈಲ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡುವುದು ಮುಂತಾದ ಕೆಲಸಗಳಿಗೆ ಹೆಚ್ಚು ಸಮಯ ಬೇಕಾಗುತ್ತದೆ. ಇಂತಹ ಸಮಯದಲ್ಲಿ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಸುಮ್ಮನೆ ಕಾಯುತ್ತಾ ಕುಳಿತರೆ ಇಡೀ ವೆಬ್‌ಸೈಟ್ ಹ್ಯಾಂಗ್ ಆದಂತೆ ಆಗುತ್ತದೆ. ಇದನ್ನು ತಡೆಯಲು ಈ ಕೆಲಸಗಳನ್ನು ಹಿನ್ನೆಲೆಯಲ್ಲಿ (Background) ರನ್ ಮಾಡಲು ನಾವು 'Promises' ಅನ್ನು ಬಳಸುತ್ತೇವೆ. ಇದೇ ಕೆಲಸಗಳನ್ನು ಒಂದೇ ಬಾರಿಗೆ ಒಟ್ಟಿಗೆ ಶುರು ಮಾಡಿದರೆ ಅದು 'Parallel Promises' ಆಗುತ್ತದೆ.

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ಸಮಾನಾಂತರವಾಗಿ ಕೆಲಸ ಮಾಡಲು 4 ಮುಖ್ಯ ವಿಧಾನಗಳಿವೆ. ಬನ್ನಿ, ಪ್ರತಿಯೊಂದನ್ನು ಉದಾಹರಣೆ ಸಮೇತ ಹಂತ-ಹಂತವಾಗಿ ಕಲಿಯೋಣ.

ಉದಾಹರಣೆಗಳಿಗಾಗಿ, ಮೊದಲು ನಾವು ಒಂದು ಚಿಕ್ಕ ಫಂಕ್ಷನ್ (Function) ಬರೆಯೋಣ. ಇದು ನಮ್ಮ ಸ್ನೇಹಿತರ ಕೆಲಸವನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತದೆ:

// ಇದು ಒಂದು ಕೆಲಸವನ್ನು ಪ್ರತಿನಿಧಿಸುವ ಫಂಕ್ಷನ್
function doTask(taskName, time, willSuccess = true) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (willSuccess) {
        resolve(`${taskName} ಯಶಸ್ವಿಯಾಗಿದೆ! ✅`);
      } else {
        reject(`${taskName} ವಿಫಲವಾಗಿದೆ! ❌`);
      }
    }, time);
  });
}

ಕೋಡ್‌ನ ವಿವರವಾದ ವಿವರಣೆ:

  • function doTask(taskName, time, willSuccess = true): ನಾವು 3 ಮಾಹಿತಿಗಳನ್ನು (Parameters) ತೆಗೆದುಕೊಳ್ಳುವ ಒಂದು ಫಂಕ್ಷನ್ ಬರೆದಿದ್ದೇವೆ. ಯಾವ ಕೆಲಸ (taskName), ಎಷ್ಟು ಸಮಯ ಬೇಕು (time), ಮತ್ತು ಆ ಕೆಲಸ ಯಶಸ್ವಿಯಾಗುತ್ತದೆಯೇ ಅಥವಾ ಇಲ್ಲವೇ (willSuccess = true ಅಂದರೆ ಡೀಫಾಲ್ಟ್ ಆಗಿ ಯಶಸ್ವಿಯಾಗುತ್ತದೆ ಎಂದರ್ಥ).
  • return new Promise((resolve, reject) => { ... }): ಪ್ರತಿಯೊಬ್ಬ ಸ್ನೇಹಿತನಿಗೂ ನಾವು ಕರೆ ಮಾಡಿದಾಗ, ಅವರು ನಮಗೆ ಒಂದು "ಭರವಸೆ" (Promise) ನೀಡುತ್ತಾರೆ. ಈ ಪ್ರಾಮಿಸ್ ಎರಡು ರೀತಿಯಲ್ಲಿ ಅಂತ್ಯವಾಗಬಹುದು: ಒಂದು resolve (ಕೆಲಸ ಯಶಸ್ವಿಯಾದಾಗ ಕೊಡುವ ಉತ್ತರ) ಮತ್ತು ಇನ್ನೊಂದು reject (ಕೆಲಸ ವಿಫಲವಾದಾಗ ಕೊಡುವ ಉತ್ತರ).
  • setTimeout(() => { ... }, time): ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ ನೈಜ ಸಮಯವನ್ನು (Time delay) ಅನುಕರಿಸಲು (simulate) ಇದನ್ನು ಬಳಸಲಾಗುತ್ತದೆ. ನೀವು ನೀಡಿದ ಸಮಯದ ನಂತರ ಇದರ ಒಳಗಿರುವ ಕೋಡ್ ರನ್ ಆಗುತ್ತದೆ. 1000 ಎಂದರೆ 1 ಸೆಕೆಂಡ್.
  • if (willSuccess): ನಾವು ಕೆಲಸ ಯಶಸ್ವಿಯಾಗುತ್ತದೆ ಎಂದು ಹೇಳಿದ್ದರೆ, ಅದು resolve() ಮೂಲಕ ಶುಭ ಸಂದೇಶ ಕಳಿಸುತ್ತದೆ. ಇಲ್ಲದಿದ್ದರೆ reject() ಮೂಲಕ ಕೆಲಸ ಆಗಿಲ್ಲ ಎಂಬ ದೋಷದ ಸಂದೇಶ (Error) ಕಳಿಸುತ್ತದೆ.

1. Promise.all() - "ಎಲ್ಲರೂ ಗೆಲ್ಲಬೇಕು" (All or Nothing)

ಕಥೆ: ಪಾರ್ಟಿಗೆ ಕೇಕ್, ಬಲೂನ್ ಮತ್ತು ಜ್ಯೂಸ್ ಮೂರೂ ಕಡ್ಡಾಯವಾಗಿ ಬೇಕೇ ಬೇಕು. ಮೂವರಲ್ಲಿ ಒಬ್ಬ ಬರದೇ ಇದ್ದರೂ ಪಾರ್ಟಿ ಕ್ಯಾನ್ಸಲ್ (ವಿಫಲ)!

ವೃತ್ತಿಪರ ಅರ್ಥ: ನೀವು ನೀಡಿದ ಎಲ್ಲಾ ಪ್ರಾಮಿಸ್‌ಗಳು (ಕೆಲಸಗಳು) ಯಶಸ್ವಿಯಾದರೆ ಮಾತ್ರ ಇದು ಯಶಸ್ವಿಯಾಗುತ್ತದೆ. ಯಾವುದಾದರೂ ಒಂದು ವಿಫಲವಾದರೂ, ಇಡೀ ಪ್ರಕ್ರಿಯೆ ವಿಫಲವಾಗುತ್ತದೆ (Catch ಬ್ಲಾಕ್ ಗೆ ಹೋಗುತ್ತದೆ).

ಉದಾಹರಣೆ:

const task1 = doTask("ಕೇಕ್ 🎂", 2000, true);
const task2 = doTask("ಬಲೂನ್ 🎈", 3000, true);
const task3 = doTask("ಜ್ಯೂಸ್ 🧃", 1000, true);

// ಮೂರು ಕೆಲಸಗಳನ್ನು ಒಟ್ಟಿಗೆ ಶುರು ಮಾಡುವುದು
Promise.all([task1, task2, task3])
  .then((results) => {
    console.log("ಪಾರ್ಟಿ ಶುರು! ಎಲ್ಲವೂ ಸಿಕ್ಕಿತು:", results);
    // ಔಟ್‌ಪುಟ್: ["ಕೇಕ್ 🎂 ಯಶಸ್ವಿಯಾಗಿದೆ! ✅", "ಬಲೂನ್ 🎈 ಯಶಸ್ವಿಯಾಗಿದೆ! ✅", "ಜ್ಯೂಸ್ 🧃 ಯಶಸ್ವಿಯಾಗಿದೆ! ✅"]
  })
  .catch((error) => {
    console.log("ಅಯ್ಯೋ! ಪಾರ್ಟಿ ಕ್ಯಾನ್ಸಲ್. ಕಾರಣ:", error);
  });

ಒಂದು ವೇಳೆ task2 ವಿಫಲವಾದರೆ, ಕೇವಲ catch ಬ್ಲಾಕ್ ರನ್ ಆಗುತ್ತದೆ ಮತ್ತು "ಬಲೂನ್ 🎈 ವಿಫಲವಾಗಿದೆ!" ಎಂದು ತೋರಿಸುತ್ತದೆ.

ಕೋಡ್‌ನ ವಿವರವಾದ ವಿವರಣೆ:

  • const task1, task2, task3: ಇಲ್ಲಿ ನಾವು ನಮ್ಮ ಫಂಕ್ಷನ್ ಬಳಸಿ 3 ಪ್ರತ್ಯೇಕ ಪ್ರಾಮಿಸ್‌ಗಳನ್ನು (ಭರವಸೆಗಳನ್ನು) ಸೃಷ್ಟಿಸಿದ್ದೇವೆ.
  • Promise.all([task1, task2, task3]): ಈ ಮೂರೂ ಕೆಲಸಗಳನ್ನು ಒಂದು ಪಟ್ಟಿಯಲ್ಲಿ (Array []) ಸೇರಿಸಿ Promise.all ಗೆ ನೀಡುತ್ತಿದ್ದೇವೆ. ಇದು ಮೂರೂ ಕೆಲಸಗಳನ್ನು ಏಕಕಾಲದಲ್ಲಿ (ಒಂದೇ ಬಾರಿಗೆ) ಶುರು ಮಾಡುತ್ತದೆ.
  • .then((results) => { ... }): ಮೂರೂ ಕೆಲಸಗಳು ಯಶಸ್ವಿಯಾಗಿ ಮುಗಿದ ನಂತರವೇ ಈ ಬ್ಲಾಕ್ ರನ್ ಆಗುತ್ತದೆ. ಇಲ್ಲಿ results ಎಂಬುದು ಮೂರೂ ಕೆಲಸಗಳ ಫಲಿತಾಂಶಗಳನ್ನು ಒಳಗೊಂಡ ಒಂದು Array ಆಗಿರುತ್ತದೆ. ಇಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ಸಮಯ ತೆಗೆದುಕೊಳ್ಳುವುದು task2 (3 ಸೆಕೆಂಡ್). ಹಾಗಾಗಿ 3 ಸೆಕೆಂಡ್‌ಗಳ ನಂತರ ಒಟ್ಟಿಗೆ ಮೂರರ ಫಲಿತಾಂಶ ಬರುತ್ತದೆ.
  • .catch((error) => { ... }): ಮೂರರಲ್ಲಿ ಯಾವುದಾದರೂ ಒಂದು ಕೆಲಸ ವಿಫಲವಾದರೂ (ಉದಾ: ಬಲೂನ್ ತರುವಲ್ಲಿ ವಿಳಂಬ/ದೋಷ), ಉಳಿದ ಕೆಲಸಗಳು ಮುಗಿಯುವುದನ್ನು ಇದು ಕಾಯುವುದಿಲ್ಲ. ತಕ್ಷಣವೇ (Fail-fast) .catch ಬ್ಲಾಕ್‌ಗೆ ಬಂದು ದೋಷವನ್ನು ತೋರಿಸುತ್ತದೆ.

2. Promise.allSettled() - "ಏನಾಯ್ತು ಅಂತ ಹೇಳಿ" (Wait for all, don't care if pass/fail)

ಕಥೆ: ಪಾರ್ಟಿಗೆ ಮೂವರೂ ಬರಬೇಕು. ಒಬ್ಬ ತರದೇ ಇದ್ದರೂ ಪರವಾಗಿಲ್ಲ, ಪಾರ್ಟಿ ನಡೆಯುತ್ತದೆ. ಆದರೆ ಕೊನೆಯಲ್ಲಿ ನನಗೆ ಯಾರು ಏನು ತಂದರು, ಯಾರು ತರಲಿಲ್ಲ ಎಂಬ ಪೂರ್ಣ ರಿಪೋರ್ಟ್ ಬೇಕು.

ವೃತ್ತಿಪರ ಅರ್ಥ: ಇದು ಎಲ್ಲಾ ಪ್ರಾಮಿಸ್‌ಗಳು ಮುಗಿಯುವವರೆಗೆ ಕಾಯುತ್ತದೆ. ಅವು ಯಶಸ್ವಿಯಾಗಲಿ ಅಥವಾ ವಿಫಲವಾಗಲಿ, ಪ್ರತಿಯೊಂದರ ಸ್ಥಿತಿಯನ್ನು (status) ಒಂದು ಪಟ್ಟಿಯಾಗಿ (Array) ನೀಡುತ್ತದೆ.

ಉದಾಹರಣೆ:

const t1 = doTask("ಕೇಕ್ 🎂", 2000, true); // ಯಶಸ್ಸು
const t2 = doTask("ಬಲೂನ್ 🎈", 3000, false); // ವಿಫಲ (ಬಲೂನ್ ಒಡೆದುಹೋಯ್ತು!)
const t3 = doTask("ಜ್ಯೂಸ್ 🧃", 1000, true); // ಯಶಸ್ಸು

Promise.allSettled([t1, t2, t3])
  .then((results) => {
    console.log("ಪಾರ್ಟಿಯ ರಿಪೋರ್ಟ್:");
    console.log(results);
  });

/* 
ಔಟ್‌ಪುಟ್:
[
  { status: 'fulfilled', value: 'ಕೇಕ್ 🎂 ಯಶಸ್ವಿಯಾಗಿದೆ! ✅' },
  { status: 'rejected', reason: 'ಬಲೂನ್ 🎈 ವಿಫಲವಾಗಿದೆ! ❌' },
  { status: 'fulfilled', value: 'ಜ್ಯೂಸ್ 🧃 ಯಶಸ್ವಿಯಾಗಿದೆ! ✅' }
]
*/

ಯಾವ ಕೆಲಸವೂ ಅರ್ಧಕ್ಕೆ ನಿಲ್ಲುವುದಿಲ್ಲ, ಎಲ್ಲದರ ಪೂರ್ಣ ಮಾಹಿತಿ ಸಿಗುತ್ತದೆ.

ಕೋಡ್‌ನ ವಿವರವಾದ ವಿವರಣೆ:

  • ಇಲ್ಲಿ t2 (ಬಲೂನ್) ಕೆಲಸವನ್ನು ಬೇಕೆಂತಲೇ false (ವಿಫಲ) ಎಂದು ನೀಡಿದ್ದೇವೆ.
  • Promise.allSettled([...]): Promise.all ನಂತೆ ಇದು ಯಾವುದಾದರೂ ಒಂದು ವಿಫಲವಾದ ತಕ್ಷಣವೇ ಓಡಿಹೋಗುವುದಿಲ್ಲ. ಬದಲಾಗಿ, ಕೊಟ್ಟಿರುವ ಎಲ್ಲಾ ಕೆಲಸಗಳು ಮುಗಿಯುವವರೆಗೂ (ಅದು ಯಶಸ್ಸಾಗಲಿ, ವಿಫಲವಾಗಲಿ) ಕಾಯುತ್ತದೆ.
  • .then((results) => { ... }): ಇಲ್ಲಿ catch ಬ್ಲಾಕ್‌ನ ಅವಶ್ಯಕತೆಯೇ ಬರುವುದಿಲ್ಲ, ಏಕೆಂದರೆ ವಿಫಲವಾದರೂ ಅದು .then ನಲ್ಲೇ ರಿಪೋರ್ಟ್ ನೀಡುತ್ತದೆ!
  • results ನಲ್ಲಿ ಬರುವ ರಿಪೋರ್ಟ್ ಹೀಗಿರುತ್ತದೆ:
    • ಯಶಸ್ವಿಯಾದ ಪ್ರಾಮಿಸ್‌ಗಳಿಗೆ: status: 'fulfilled' ಮತ್ತು value: '...' ಎಂದು ಬರುತ್ತದೆ.
    • ವಿಫಲವಾದ ಪ್ರಾಮಿಸ್‌ಗಳಿಗೆ: status: 'rejected' ಮತ್ತು reason: '...' (ಏಕೆ ವಿಫಲವಾಯ್ತು ಎಂಬ ಕಾರಣ) ಎಂದು ಬರುತ್ತದೆ. ಇದನ್ನು ನೀವು ಪ್ರತ್ಯೇಕವಾಗಿ ಪರಿಶೀಲಿಸಿ ಮುಂದಿನ ಕ್ರಮ ಕೈಗೊಳ್ಳಬಹುದು.

3. Promise.race() - "ಯಾರು ಮೊದಲು ಬರ್ತಾರೋ ಅವರು" (First to finish wins)

ಕಥೆ: ನಿಮಗೆ ತುಂಬಾ ಹಸಿವಾಗಿದೆ. ನೀವು 3 ಬೇರೆ ಬೇರೆ ಅಂಗಡಿಗಳಿಗೆ ಪಿಜ್ಜಾ ಆರ್ಡರ್ ಮಾಡುತ್ತೀರಿ. ಯಾವ ಅಂಗಡಿಯ ಡೆಲಿವರಿ ಬಾಯ್ ಮೊದಲು ಬರುತ್ತಾನೋ, ಅವನಿಂದ ಪಿಜ್ಜಾ ತೆಗೆದುಕೊಳ್ಳುತ್ತೀರಿ (ಉಳಿದವರನ್ನು ವಾಪಸ್ ಕಳಿಸುತ್ತೀರಿ). ಆ ಮೊದಲು ಬಂದವನು ಪಿಜ್ಜಾ ತಂದರೂ ಸರಿ, ಅಥವಾ "ಪಿಜ್ಜಾ ಇಲ್ಲ" ಅಂತ ಹೇಳಿದರೂ ಸರಿ, ಅವನದೇ ಅಂತಿಮ.

ವೃತ್ತಿಪರ ಅರ್ಥ: ಕೊಟ್ಟಿರುವ ಪ್ರಾಮಿಸ್‌ಗಳಲ್ಲಿ ಯಾವುದು ಮೊದಲು ಮುಗಿಯುತ್ತದೆಯೋ (ಅದು ಯಶಸ್ಸಾಗಲಿ ಅಥವಾ ವಿಫಲವಾಗಲಿ), ಅದರ ಫಲಿತಾಂಶವನ್ನು ಮಾತ್ರ ಇದು ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ.

ಉದಾಹರಣೆ:

const shop1 = doTask("ಅಂಗಡಿ 1", 3000, true);
const shop2 = doTask("ಅಂಗಡಿ 2", 1000, false); // ಇದು ಬೇಗ ಬರುತ್ತೆ, ಆದರೆ ವಿಫಲ
const shop3 = doTask("ಅಂಗಡಿ 3", 2000, true);

Promise.race([shop1, shop2, shop3])
  .then((result) => {
    console.log("ಮೊದಲು ಬಂದದ್ದು:", result);
  })
  .catch((error) => {
    console.log("ಮೊದಲು ಬಂದದ್ದು ವಿಫಲವಾಯ್ತು:", error); 
    // ಔಟ್‌ಪುಟ್: "ಮೊದಲು ಬಂದದ್ದು ವಿಫಲವಾಯ್ತು: ಅಂಗಡಿ 2 ವಿಫಲವಾಗಿದೆ! ❌"
  });

ಇಲ್ಲಿ 'ಅಂಗಡಿ 2' ಕೇವಲ 1 ಸೆಕೆಂಡಿನಲ್ಲಿ ಬಂದಿದ್ದರಿಂದ, ಅದು ವಿಫಲವಾದರೂ ಅದನ್ನೇ ಪರಿಗಣಿಸಲಾಗುತ್ತದೆ.

ಕೋಡ್‌ನ ವಿವರವಾದ ವಿವರಣೆ:

  • ಇಲ್ಲಿ ಮೂರು ಅಂಗಡಿಗಳಿವೆ. ಸಮಯ ಗಮನಿಸಿ: shop1 (3 ಸೆಕೆಂಡ್), shop2 (1 ಸೆಕೆಂಡ್), shop3 (2 ಸೆಕೆಂಡ್).
  • Promise.race([...]): ರೇಸ್ (ಓಟದ ಸ್ಪರ್ಧೆ) ಇದ್ದಂತೆ. ಯಾರು ಫಿನಿಶ್ ಲೈನ್ ಅನ್ನು ಮೊದಲು ಮುಟ್ಟುತ್ತಾರೋ ಅವರೇ ಇಲ್ಲಿ ವಿನ್ನರ್.
  • ಇಲ್ಲಿ shop2 ಕೇವಲ 1 ಸೆಕೆಂಡಿನಲ್ಲಿ ಸ್ಪಂದಿಸುತ್ತದೆ. ಆದರೆ ಅದು false (ವಿಫಲ) ಆಗಿದೆ. ಆದರೂ ಇದು Promise.race ಆಗಿರುವುದರಿಂದ, ಮೊದಲು ಬಂದ ಉತ್ತರ ವಿಫಲವಾದ ಕಾರಣ ನೇರವಾಗಿ .catch() ಬ್ಲಾಕ್‌ಗೆ ಹೋಗಿ ದೋಷವನ್ನು ಪ್ರಿಂಟ್ ಮಾಡುತ್ತದೆ.
  • ಒಂದು ವೇಳೆ shop2 ಯಶಸ್ವಿಯಾಗಿದ್ದರೆ, ನೇರವಾಗಿ .then() ಬ್ಲಾಕ್ ರನ್ ಆಗುತ್ತಿತ್ತು. ಉಳಿದ shop1 ಮತ್ತು shop3 ಏನಾಯಿತು ಎಂಬುದನ್ನು ಇದು ಸಂಪೂರ್ಣವಾಗಿ ನಿರ್ಲಕ್ಷಿಸುತ್ತದೆ.

4. Promise.any() - "ಯಾರು ಮೊದಲು ಯಶಸ್ವಿಯಾಗ್ತಾರೋ ಅವರು" (First success wins)

ಕಥೆ: ನೀವು ಆಸ್ಪತ್ರೆಗೆ ಹೋಗಲು 3 ಟ್ಯಾಕ್ಸಿಗಳಿಗೆ ಕರೆ ಮಾಡುತ್ತೀರಿ. ಮೊದಲು ಬಂದ ಟ್ಯಾಕ್ಸಿಯವನು "ನಾನು ಬರಲ್ಲ" (ವಿಫಲ) ಎಂದರೆ ನೀವು ಸುಮ್ಮನಾಗುವುದಿಲ್ಲ, ಮುಂದಿನ ಟ್ಯಾಕ್ಸಿಗಾಗಿ ಕಾಯುತ್ತೀರಿ. ಯಾವ ಟ್ಯಾಕ್ಸಿ ಮೊದಲು "ಬರುತ್ತೇನೆ" (ಯಶಸ್ಸು) ಎಂದು ನಿಮ್ಮ ಬಳಿ ಬರುತ್ತದೆಯೋ ಅದರಲ್ಲಿ ಹೋಗುತ್ತೀರಿ.

ವೃತ್ತಿಪರ ಅರ್ಥ: ಇದು ಮೊದಲ ಯಶಸ್ವಿ ಪ್ರಾಮಿಸ್‌ಗಾಗಿ ಕಾಯುತ್ತದೆ. ಮೊದಲು ಮುಗಿದ ಕೆಲಸ ವಿಫಲವಾದರೆ, ಅದು ಮುಂದಿನ ಕೆಲಸಕ್ಕಾಗಿ ಕಾಯುತ್ತದೆ. ಎಲ್ಲಾ ಕೆಲಸಗಳೂ ವಿಫಲವಾದರೆ ಮಾತ್ರ ಇದು ವಿಫಲವಾಗುತ್ತದೆ.

ಉದಾಹರಣೆ:

const taxi1 = doTask("ಟ್ಯಾಕ್ಸಿ 1", 1000, false); // ಬೇಗ ಬಂತು, ಆದ್ರೆ ಬರಲ್ಲ ಅಂದ!
const taxi2 = doTask("ಟ್ಯಾಕ್ಸಿ 2", 2000, true);  // 2 ಸೆಕೆಂಡ್‌ಗೆ ಬಂತು, ಯಶಸ್ಸು!
const taxi3 = doTask("ಟ್ಯಾಕ್ಸಿ 3", 3000, true);

Promise.any([taxi1, taxi2, taxi3])
  .then((result) => {
    console.log("ನಮಗೆ ಸಿಕ್ಕ ಟ್ಯಾಕ್ಸಿ:", result);
    // ಔಟ್‌ಪುಟ್: "ನಮಗೆ ಸಿಕ್ಕ ಟ್ಯಾಕ್ಸಿ: ಟ್ಯಾಕ್ಸಿ 2 ಯಶಸ್ವಿಯಾಗಿದೆ! ✅"
  })
  .catch((error) => {
    console.log("ಯಾವ ಟ್ಯಾಕ್ಸಿಯೂ ಸಿಗಲಿಲ್ಲ!", error);
  });

ಇಲ್ಲಿ 'ಟ್ಯಾಕ್ಸಿ 1' ಮೊದಲು ಬಂದರೂ ವಿಫಲವಾದ ಕಾರಣ, ಪ್ರೋಗ್ರಾಮ್ 'ಟ್ಯಾಕ್ಸಿ 2' ಗಾಗಿ ಕಾಯುತ್ತದೆ ಮತ್ತು ಅದನ್ನು ಸ್ವೀಕರಿಸುತ್ತದೆ.

ಕೋಡ್‌ನ ವಿವರವಾದ ವಿವರಣೆ:

  • ಇಲ್ಲಿ taxi1 (1 ಸೆಕೆಂಡ್) ಮೊದಲು ಬರುತ್ತದೆ, ಆದರೆ ಅದು ವಿಫಲ (false).
  • Promise.any([...]): ಇದು ಕೇವಲ "ರೇಸ್" ಅಲ್ಲ, ಬದಲಾಗಿ "ಯಶಸ್ಸಿನ ರೇಸ್". ಮೊದಲು ಬಂದ ಉತ್ತರ ವಿಫಲವಾದರೂ ಇದು ಸುಮ್ಮನಾಗುವುದಿಲ್ಲ. ಇದು ಮೊದಲ ಯಶಸ್ಸಿಗಾಗಿ (Success) ಹುಡುಕುತ್ತಾ ಕಾಯುತ್ತದೆ.
  • taxi1 ವಿಫಲವಾದರೂ, ಅದು ಪಕ್ಕಕ್ಕಿಟ್ಟು, ಮುಂದಿನ ಟ್ಯಾಕ್ಸಿಗಾಗಿ ಕಾಯುತ್ತದೆ. 2ನೇ ಸೆಕೆಂಡಿನಲ್ಲಿ taxi2 ಬಂದು ಯಶಸ್ವಿಯಾಗುತ್ತದೆ (true). ತಕ್ಷಣವೇ ಅದು .then() ಬ್ಲಾಕ್ ಅನ್ನು ರನ್ ಮಾಡಿ "ನಮಗೆ ಸಿಕ್ಕ ಟ್ಯಾಕ್ಸಿ: ಟ್ಯಾಕ್ಸಿ 2" ಎಂದು ಪ್ರಿಂಟ್ ಮಾಡುತ್ತದೆ.
  • ಒಂದು ವೇಳೆ ಮೂರೂ ಟ್ಯಾಕ್ಸಿಗಳು ವಿಫಲವಾದರೆ ಮಾತ್ರ ಇದು .catch() ಬ್ಲಾಕ್‌ಗೆ ಹೋಗುತ್ತದೆ (ಆಗ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ AggregateError: All promises were rejected ಎಂಬ ವಿಶೇಷ ದೋಷವನ್ನು ನೀಡುತ್ತದೆ).

ಸಾರಾಂಶ (ನೆನಪಿಡಲು ಸುಲಭವಾದ ಟಿಪ್ಸ್)

ಮೆಥಡ್ ನಿಯಮ (Rule) ಯಾವಾಗ ಬಳಸಬೇಕು?
Promise.all ಎಲ್ಲರೂ ಪಾಸ್ ಆಗಬೇಕು. ಎಲ್ಲಾ ಡೇಟಾ ಕಡ್ಡಾಯವಾಗಿ ಬೇಕಿದ್ದಾಗ.
Promise.allSettled ಪಾಸ್/ಫೇಲ್ ಏನೇ ಆದರೂ ರಿಪೋರ್ಟ್ ಕೊಡು. ಯಾರು ಏನೇ ಮಾಡಿದರೂ ಪೂರ್ಣ ಲೆಕ್ಕ ಬೇಕಿದ್ದಾಗ.
Promise.race ಯಾರು ಮೊದಲು ಬರ್ತಾರೋ ಅವರೇ ವಿನ್ನರ್ (ಪಾಸ್ ಅಥವಾ ಫೇಲ್). ಯಾರು ಅತಿ ವೇಗವಾಗಿ ಪ್ರತಿಕ್ರಿಯಿಸುತ್ತಾರೆ ಎಂದು ನೋಡಲು (ಉದಾ: Timeout).
Promise.any ಯಾರು ಮೊದಲು ಪಾಸ್ ಆಗ್ತಾರೋ ಅವರೇ ವಿನ್ನರ್. ಯಾವುದಾದರೂ ಒಂದು ಯಶಸ್ವಿಯಾದರೂ ಸಾಕು ಎಂದಾಗ.

ಕೊನೆಯ ಮಾತು:

ಒಂದೇ ಬಾರಿಗೆ (Parallel) ಕೆಲಸಗಳನ್ನು ಮಾಡಿದಾಗ ಪ್ರೋಗ್ರಾಮ್‌ನ ವೇಗ (Performance) ಅಗಾಧವಾಗಿ ಹೆಚ್ಚಾಗುತ್ತದೆ. ನಿಮ್ಮ ಅಗತ್ಯಕ್ಕೆ ತಕ್ಕಂತೆ ಈ ನಾಲ್ಕರಲ್ಲಿ ಸೂಕ್ತವಾದದ್ದನ್ನು ಆರಿಸಿಕೊಳ್ಳುವುದು ಉತ್ತಮ ಡೆವಲಪರ್‌ನ ಲಕ್ಷಣ.
