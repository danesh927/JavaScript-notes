ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ (JavaScript) ಸಿಂಕ್ರೊನಸ್ ಮತ್ತು ಅಸಿಂಕ್ರೊನಸ್

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ (JavaScript) ನ ಸಿಂಕ್ರೊನಸ್ (Synchronous) ಮತ್ತು ಅಸಿಂಕ್ರೊನಸ್ (Asynchronous) ಪರಿಕಲ್ಪನೆಗಳನ್ನು ನಾನ್-ಐಟಿ (Non-IT) ಹಿನ್ನೆಲೆಯ ವ್ಯಕ್ತಿಗೆ ಅರ್ಥವಾಗುವ ದೈನಂದಿನ ಉದಾಹರಣೆಗಳಿಂದ ಶುರುಮಾಡಿ, ಒಬ್ಬ ಸಾಫ್ಟ್‌ವೇರ್ ವೃತ್ತಿಪರ (Professional) ಅರ್ಥಮಾಡಿಕೊಳ್ಳಬೇಕಾದ ಆಳವಾದ ತಾಂತ್ರಿಕ ವಿವರಗಳವರೆಗೆ (Event Loop, Call Stack) ಹಂತ-ಹಂತವಾಗಿ ಕಲಿಯೋಣ.

ಹಂತ 1: ನಾನ್-ಐಟಿ (Non-IT) ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ ದೈನಂದಿನ ಉದಾಹರಣೆ

1. ಸಿಂಕ್ರೊನಸ್ (Synchronous) ಎಂದರೆ ಏನು?

ಇದನ್ನು "ಒಂದಾದ ಮೇಲೆ ಮತ್ತೊಂದು ಕೆಲಸ ಮಾಡುವುದು" ಎಂದು ಕರೆಯಬಹುದು.

ಉದಾಹರಣೆ: ನೀವು ಒಂದು ಸಣ್ಣ ಕಾಫಿ ಶಾಪ್‌ಗೆ ಹೋಗುತ್ತೀರಿ. ಅಲ್ಲಿ ಕೌಂಟರ್‌ನಲ್ಲಿ ಆರ್ಡರ್ ಮಾಡುತ್ತೀರಿ. ಕಾಫಿ ತಯಾರಾಗುವವರೆಗೆ ನೀವು ಅಲ್ಲೇ ನಿಂತು ಕಾಯಬೇಕು. ನಿಮ್ಮ ಕಾಫಿ ಸಿಕ್ಕ ಮೇಲೆ ಮಾತ್ರ ನಿಮ್ಮ ಹಿಂದಿರುವ ವ್ಯಕ್ತಿ ಆರ್ಡರ್ ಮಾಡಬಹುದು.

ಅರ್ಥ: ಇಲ್ಲಿ ಒಂದು ಕೆಲಸ ಮುಗಿಯುವವರೆಗೂ ಮುಂದಿನ ಕೆಲಸ ಶುರುವಾಗುವುದಿಲ್ಲ. ಇದು ಇತರ ಕೆಲಸಗಳನ್ನು ಬ್ಲಾಕ್ (Block) ಮಾಡುತ್ತದೆ.

2. ಅಸಿಂಕ್ರೊನಸ್ (Asynchronous) ಎಂದರೆ ಏನು?

ಇದನ್ನು "ಒಂದು ಕೆಲಸ ನಡೆಯುತ್ತಿರುವಾಗಲೇ, ಕಾಯದೆ ಬೇರೆ ಕೆಲಸ ಮಾಡುವುದು" ಎಂದು ಕರೆಯಬಹುದು.

ಉದಾಹರಣೆ: ನೀವು ಒಂದು ದೊಡ್ಡ ರೆಸ್ಟೋರೆಂಟ್‌ಗೆ ಹೋಗಿ ಆರ್ಡರ್ ಮಾಡುತ್ತೀರಿ. ಅವರು ನಿಮಗೆ ಒಂದು 'ಟೋಕನ್' ಕೊಟ್ಟು ಟೇಬಲ್ ಬಳಿ ಕೂರಲು ಹೇಳುತ್ತಾರೆ. ನಿಮ್ಮ ಅಡುಗೆ ತಯಾರಾಗುವಾಗ, ನೀವು ಫೋನ್ ನೋಡಬಹುದು ಅಥವಾ ಸ್ನೇಹಿತರ ಜೊತೆ ಮಾತನಾಡಬಹುದು. ಅಡುಗೆ ತಯಾರಾದ ತಕ್ಷಣ ವೇಟರ್ ಅದನ್ನು ತಂದು ಕೊಡುತ್ತಾರೆ.

ಅರ್ಥ: ಇಲ್ಲಿ ಯಾವುದಕ್ಕೂ ಕಾಯುವ (Block ಆಗುವ) ಅಗತ್ಯವಿಲ್ಲ. ಎಲ್ಲವೂ ಸಮಾನಾಂತರವಾಗಿ ನಡೆಯುತ್ತದೆ.

ಹಂತ 2: ಐಟಿ (IT) ವಿದ್ಯಾರ್ಥಿ ಹಂತ – ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ?

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಒಂದು "ಸಿಂಗಲ್-ಥ್ರೆಡೆಡ್" (Single-Threaded) ಭಾಷೆ. ಎಂದರೆ, ಅದರ ಬಳಿ ಕೆಲಸ ಮಾಡಲು ಇರುವುದು ಕೇವಲ ಒಬ್ಬನೇ ಕೆಲಸಗಾರ (Main Thread).

ಒಬ್ಬನೇ ಕೆಲಸಗಾರನಿದ್ದರೆ, ಅವನು ಸಿಂಕ್ರೊನಸ್ ಆಗಿ ಕೆಲಸ ಮಾಡಿದರೆ ಸಿಸ್ಟಮ್ ಹ್ಯಾಂಗ್ ಆಗುತ್ತದೆ (ಉದಾಹರಣೆಗೆ: ಇಂಟರ್ನೆಟ್‌ನಿಂದ ದೊಡ್ಡ ಫೈಲ್ ಡೌನ್‌ಲೋಡ್ ಆಗುವವರೆಗೆ ಇಡೀ ವೆಬ್‌ಸೈಟ್ ಸ್ತಬ್ಧವಾಗುತ್ತದೆ). ಇದನ್ನು ತಡೆಯಲು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಅಸಿಂಕ್ರೊನಸ್ (Asynchronous) ವಿಧಾನವನ್ನು ಬಳಸುತ್ತದೆ. ಸಮಯ ತೆಗೆದುಕೊಳ್ಳುವ ಕೆಲಸಗಳನ್ನು (ಉದಾ: ಡೇಟಾಬೇಸ್‌ನಿಂದ ಮಾಹಿತಿ ತರುವುದು, ಟೈಮರ್‌ಗಳು) ಹಿನ್ನೆಲೆಯಲ್ಲಿ (Background) ನಡೆಯಲು ಬಿಟ್ಟು, ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ತನ್ನ ಮುಂದಿನ ಕೆಲಸಗಳನ್ನು ಮುಂದುವರಿಸುತ್ತದೆ.

ಹಂತ 3: ವೃತ್ತಿಪರ (Professional) ಹಂತ – Under the Hood (ಆಳವಾದ ವಿವರ)

ಒಬ್ಬ ಪ್ರೊಫೆಷನಲ್ ಡೆವಲಪರ್ ಆಗಿ, ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಬಿಹೈಂಡ್ ದಿ ಸೀನ್ಸ್ (Behind the scenes) ಹೇಗೆ ಅಸಿಂಕ್ರೊನಸ್ ಕೆಲಸಗಳನ್ನು ನಿಭಾಯಿಸುತ್ತದೆ ಎಂದು ತಿಳಿಯಲು Event Loop Architecture ಅನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಬೇಕು. ಇದರಲ್ಲಿ 4 ಪ್ರಮುಖ ಭಾಗಗಳಿವೆ:

1. ಕಾಲ್ ಸ್ಟ್ಯಾಕ್ (Call Stack):

ಇದು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನ ಮುಖ್ಯ ಕಾರ್ಯಕ್ಷೇತ್ರ. ಇದೊಂದು "Last In, First Out" (LIFO) ವ್ಯವಸ್ಥೆ. ಯಾವುದೇ ಫಂಕ್ಷನ್ ರನ್ ಆಗಬೇಕಾದರೂ ಮೊದಲು ಕಾಲ್ ಸ್ಟ್ಯಾಕ್‌ಗೆ ಬರುತ್ತದೆ. ಕೆಲಸ ಮುಗಿದ ತಕ್ಷಣ ಅಲ್ಲಿಂದ ಹೊರಹೋಗುತ್ತದೆ.

2. ವೆಬ್ ಎಪಿಐ ಗಳು (Web APIs / Node APIs):

ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಎಂಜಿನ್‌ನ ಹೊರಗಿರುವ ಬ್ರೌಸರ್‌ನ ಫೀಚರ್‌ಗಳು (ಮತ್ತು DOM ಜೊತೆಗಿನ ಸಂಪರ್ಕಗಳು). ಉದಾಹರಣೆಗೆ: setTimeout(), fetch() (ಇಂಟರ್ನೆಟ್‌ನಿಂದ ಡೇಟಾ ತರುವುದು), DOM Events ಮುಂತಾದವು. ಸಮಯ ತೆಗೆದುಕೊಳ್ಳುವ ಕೆಲಸಗಳನ್ನು ಕಾಲ್ ಸ್ಟ್ಯಾಕ್ ಇವುಗಳಿಗೆ ಒಪ್ಪಿಸಿಬಿಡುತ್ತದೆ.

3. ಟಾಸ್ಕ್ ಕ್ಯೂಗಳು (Task Queues):

ವೆಬ್ ಎಪಿಐಗಳು ತಮ್ಮ ಹಿನ್ನೆಲೆ ಕೆಲಸವನ್ನು ಮುಗಿಸಿದ ನಂತರ, ಅದರ ಫಲಿತಾಂಶಗಳನ್ನು ಕಾಲ್ ಸ್ಟ್ಯಾಕ್‌ಗೆ ವಾಪಸ್ ಕಳುಹಿಸಲು ಕ್ಯೂ (ಸರತಿ ಸಾಲು) ನಲ್ಲಿ ನಿಲ್ಲಿಸುತ್ತವೆ. ಇದರಲ್ಲಿ 2 ವಿಧಗಳಿವೆ:

  • ಮೈಕ್ರೋಟಾಸ್ಕ್ ಕ್ಯೂ (Microtask Queue): ಅತಿ ಹೆಚ್ಚು ಆದ್ಯತೆ (High Priority) ಇರುವ ಕ್ಯೂ. ಭವಿಷ್ಯದ ಫಲಿತಾಂಶಗಳನ್ನು ನಿಭಾಯಿಸುವ Promises (.then, .catch), async/await ಗಳು ಇಲ್ಲಿಗೆ ಬರುತ್ತವೆ.
  • ಮ್ಯಾಕ್ರೋಟಾಸ್ಕ್ ಕ್ಯೂ (Macrotask Queue / Callback Queue): ಕಡಿಮೆ ಆದ್ಯತೆ ಇರುವ ಕ್ಯೂ. setTimeout, setInterval ಗಳು ಇಲ್ಲಿ ಬರುತ್ತವೆ.

4. ಈವೆಂಟ್ ಲೂಪ್ (Event Loop):

ಇದೊಂದು ಕಾವಲುಗಾರನಿದ್ದಂತೆ. ಇದರ ಕೆಲಸ ಒಂದೇ: ಕಾಲ್ ಸ್ಟ್ಯಾಕ್ ಖಾಲಿ ಇದೆಯೇ ಎಂದು ನಿರಂತರವಾಗಿ ಪರಿಶೀಲಿಸುವುದು.

  • ಕಾಲ್ ಸ್ಟ್ಯಾಕ್ ಸಂಪೂರ್ಣವಾಗಿ ಖಾಲಿಯಾದಾಗ, ಈವೆಂಟ್ ಲೂಪ್ ಮೊದಲು ಮೈಕ್ರೋಟಾಸ್ಕ್ ಕ್ಯೂ ನಲ್ಲಿರುವ ಎಲ್ಲಾ ಕೆಲಸಗಳನ್ನು ಸ್ಟ್ಯಾಕ್‌ಗೆ ಕಳುಹಿಸುತ್ತದೆ.
  • ಮೈಕ್ರೋಟಾಸ್ಕ್ ಕ್ಯೂ ಖಾಲಿಯಾದ ಮೇಲೆ ಮಾತ್ರ, ಮ್ಯಾಕ್ರೋಟಾಸ್ಕ್ ಕ್ಯೂ ನಲ್ಲಿರುವ ಕೆಲಸಗಳನ್ನು ಸ್ಟ್ಯಾಕ್‌ಗೆ ಕಳುಹಿಸುತ್ತದೆ.

ಹಂತ 4: ಕೋಡ್ ಉದಾಹರಣೆ ಮತ್ತು ಇಂಟರ್ವ್ಯೂ ಪ್ರಶ್ನೆ

ಈ ಕೆಳಗಿನ ಕೋಡ್ ಅನ್ನು ಗಮನಿಸಿ. ಇದು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಡೆವಲಪರ್ ಸಂದರ್ಶನಗಳಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆ:

script.js 
console.log("Start");

setTimeout(() => {
    console.log("Macrotask (setTimeout)");
}, 0);

Promise.resolve().then(() => {
    console.log("Microtask (Promise)");
});

console.log("End");

ಔಟ್‌ಪುಟ್ (Output) ಬರುವ ಸರಿಯಾದ ಕ್ರಮ:

  1. Start (ಇದು ಸಿಂಕ್ರೊನಸ್, ನೇರವಾಗಿ ಕಾಲ್ ಸ್ಟ್ಯಾಕ್‌ನಲ್ಲಿ ರನ್ ಆಗುತ್ತದೆ)
  2. End (ಇದು ಕೂಡ ಸಿಂಕ್ರೊನಸ್, ಕಾಲ್ ಸ್ಟ್ಯಾಕ್‌ನಲ್ಲೇ ರನ್ ಆಗುತ್ತದೆ)
  3. Microtask (Promise) (ಸ್ಟ್ಯಾಕ್ ಖಾಲಿಯಾದ ಕೂಡಲೇ, ಈವೆಂಟ್ ಲೂಪ್ ಮೊದಲು ಮೈಕ್ರೋಟಾಸ್ಕ್ ಕ್ಯೂ ಅನ್ನು ರನ್ ಮಾಡುತ್ತದೆ)
  4. Macrotask (setTimeout) (ಮೈಕ್ರೋಟಾಸ್ಕ್ ಖಾಲಿಯಾದ ಮೇಲೆ ಕೊನೆಯದಾಗಿ ಮ್ಯಾಕ್ರೋಟಾಸ್ಕ್ ರನ್ ಆಗುತ್ತದೆ, ಸಮಯ 0 ಇದ್ದರೂ ಸಹ!)
